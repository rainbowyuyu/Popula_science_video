# 权利、来源与再利用

[返回首页](../README.md) · [素材指引](ASSETS.md)

本仓库用于私有保存与继续制作。没有用一份新的总许可证，把不同来源的视频、源码、论文、声音、字体和模型统一授权。私有可见性不会改变各素材的权利归属，也不能替代公开发布或再分发所需许可。

## 原有代码许可

原 `manim_extend_rainbow` 工程的 Apache-2.0 许可证保留在 [manim-extend-original-LICENSE](licenses/manim-extend-original-LICENSE)。该文件用于保留原项目的授权记录，适用范围依据原有版权与许可声明；不自动扩展到本仓库新增作品、个人品牌、第三方媒体或商业插件。已有文件头、NOTICE 与依赖许可证继续保留。

新整理的项目中，若没有明确的授权声明，不从“可以看到源码”推导出允许任意商业再发布、商标使用或素材转售。如需公开发布某部分，应先明确其原作者与实际授权范围。

## 素材如何判断

| 内容 | 需要保留 / 核对 |
|---|---|
| rainbow鱼 Logo、品牌图形 | 原品牌归属；项目内展示不授予第三方品牌使用权 |
| 原创场景、模型与程序图形 | 作者、生成脚本、版本与必要的引用来源 |
| 第三方 GLB / Blend / 贴图 | 原始来源、作者、下载或购买记录、具体许可及署名 |
| 论文页、官方插图、网页截图 | 题名、作者、年份、来源与使用限制；能公开下载不等于允许任意再分发 |
| 音乐与音效 | 曲名、作者、授权范围与署名；个人音乐库不能直接作为公共素材包 |
| 个人旁白与参考音色 | 本人授权、参考的本地保存范围；不分发私有音色模型与克隆用参考录音 |
| 字体及字体子集 | 字体许可证、是否允许嵌入 / 子集 / 再分发及其必要声明 |
| AI 生成图片、视频或模型 | 使用的工具、模型、生成记录与服务条款；不得写成实拍、实验或扫描证据 |
| 开源依赖与手动编辑器 | 各自许可证；安装器下载和本仓库再分发是不同动作 |

## 未随源码分发的内容

个人凭据、私人会话、TTS 参考、模型权重、音乐库、未核实再分发权利的原始媒体及商业工具运行时不进入本次源码包。WaterPro 相关商业运行时与需要授权审查的适配源码作为本地依赖记录，不能通过其他目录重新带入仓库。

部分小型图形、封面预览与品牌资产用于呈现项目，仍保留原有权利。最终视频中可能包含第三方素材；成片能够在私有 Release 下载，不表示可以脱离作品抽取其中素材另行传播。

## 来源台账与资产清单的分工

`assets.manifest.json` 负责说明文件在哪里、是否在 Git / Release / 本地备份中；它不是权利授予文件。具体署名、许可与用途限制查各项目 `research/`、`references/`、`docs/`、模型清单或字体许可证。

旧台账记录的是当时的制作依据；未给出许可的条目应标为待确认，不把“来源链接存在”当作授权完成。对外发布前，核对成片实际使用的素材，保留所需署名，并替换不适合公开传播的内容。

## 添加新素材时

记录源链接 / 本地来源、作者、许可文本或许可页面、取得日期、文件哈希、修改方式和使用镜头。来源与许可记录不要包含密钥、签名下载参数或私人账号信息。若只能用于本地研究，就明确登记为本地依赖，保留制作说明而非上传受限原件。
