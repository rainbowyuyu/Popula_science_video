# Rainbow Atlas · 人体结构可视化原型

这是一个无需构建工具的 Three.js 单页原型，面向人体器官、肌肉与骨骼的交互讲解。页面视觉采用深海蓝底、薄荷荧光、珊瑚与淡紫色层级色，保留 rainbow 鱼系列的电影感和信息密度，同时把模型编辑入口放在右侧检查器中。

## 启动

Three.js 使用 CDN ES module，因此建议通过本地静态服务器打开，而不是直接双击 HTML：

```powershell
cd anatomy_atlas_web
python -m http.server 4173
```

打开 `http://localhost:4173/` 即可。也可以替换 `app.js` 中的几何体为真实 GLB/GLTF 模型，当前分层对象的命名与 `skeleton / muscles / organs / vessels / nerves` 对齐，方便接入 BodyParts3D 或 Human Atlas 资源。

## 交互

- 左侧切换男性/女性教学参考外形、骨骼/肌肉/器官/血管/神经层。
- 拖动模型旋转，滚轮缩放；顶部可切换透视、正面、侧面。
- 右侧可调当前层或单个结构的透明度、颜色、可见性，打开 X-Ray 和线框；点击模型部件查看结构名称和笔记，搜索框可定位心脏、肌肉等对象。
- 底部截图按钮导出当前视口 PNG。

当前模型是教学用的轻量占位几何，男女按钮用于演示不同外形与皮肤色；实际发布时应替换为带授权的高精度 GLB 资产，并把女性模型数据单独懒加载。页面不用于诊断或手术决策。
