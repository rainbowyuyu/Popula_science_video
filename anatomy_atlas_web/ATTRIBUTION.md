# 数据与模型说明

当前网页中的几何体是面向教学交互的轻量代理模型，用来演示骨骼、肌肉、器官、血管和神经的分层、选取、透明度、线框与 X-Ray 操作；它不宣称是临床级人体模型。

如需接入真实数据，项目已有兼容的 BodyParts3D 4.0 图谱：The Database Center for Life Science，CC BY 4.0，论文 Mitsuhashi et al. (2009), DOI: https://doi.org/10.1093/nar/gkn613。

女性参考模型可按需接入 Human Reference Atlas / HuBMAP 3D Reference Organ Set for Female v1.5，CC BY 4.0，DOI: https://doi.org/10.48539/HBM352.BTSQ.586。该资源包含全身表面和选定器官，骨骼与肌肉覆盖不完整，首次加载约 202 MB，因此不在首屏自动下载。

本页面仅用于人体结构科普与教学展示，不用于诊断、治疗或手术决策。
