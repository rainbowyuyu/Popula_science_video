# 独立学习与固定导航（2.8.0）

顶部“创作工作台 / 学习与参考”在两个页面保持同一位置，当前标签页内切换。桌面为一行，窄屏保留完整双入口。工作表面滑入、选中标签过渡，尊重系统减少动态效果设置；浏览器跳过原生转场时使用轻量进入动画。保留浏览器前进/后退和页面离开时的草稿保存。

## 使用

1. 打开顶部“学习与参考”。无需创建或选择视频工程。
2. 输入公开视频 HTTPS 链接，或这台电脑上的视频完整路径。
3. 可选填写想学的构图、光照、材质或镜头方法；默认学习前 15 秒，也可展开设置起止时间。
4. 点击“开始学习”，自动建立独立学习集合并加入后台队列。
5. 在参考库、学习成果、队列记录中查看样片和复核结论。需要重新尝试时使用任务记录的“重新加入队列”。

切回创作页或关闭浏览器标签不会停止队列；本地工作台服务必须保持运行。服务退出/重启后保留中间结果并标记中断，不自动重新发起模型调用。开始学习使用 CC Switch 配置的 ChatGPT 与 Claude；未配置时显示具体原因。打不开的链接、登录受限视频或无法处理的媒体会报告失败，不伪造观察结论。

## 真正执行的步骤

导入/下载指定视频区间 → 至少三个时间点实际抽帧观察 → 制作短样片 → ffprobe 与完整解码核验 → 参考和样片各至少两帧对照 → 根据问题继续改进 → 保存可复用方法。当前验证是画面抽样与文件解码，不等同于全片连续观看、完整试听或自动语音转录。

独立集合保存在工作台状态目录 learning/workspace.json，素材、样片、技能位于 creator_workbench/work/learning-workspaces/<collection-id>。这些内部空间不会出现在视频作品栏，也不会自动改写其他作品、全局技能或系列。旧的关联作品学习集合仍可用，新建集合中的作品关联为可选。

## 提交恢复

快速学习请求使用 clientRequestId 与参数摘要去重。相同输入发生网络重试或刷新后重试，恢复同一任务；改变来源、片段或学习方向生成新请求。相同请求 ID 携带不同参数会被拒绝。提交成功但列表更新失败时明确显示“任务已提交”，避免误报未开始。没有用户点击时，不会自动提交付费学习任务。
