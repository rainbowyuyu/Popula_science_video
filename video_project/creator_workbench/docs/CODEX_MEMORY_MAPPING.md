# 创作记忆的本地映射

发布仓库保留导入与归属算法，不附带任何人的 Codex 对话、会话数据库、截图附件或线程 ID。启动工作台不会触发历史导入或模型请求。

1. 在本机使用 Codex 并保留自己的历史；工作台从当前用户目录发现可读取的历史。
2. 先选择目标作品，再手动执行创作记忆同步，核对逐条归属。
3. 工程显示名、真实目录及主题别名用于匹配；引用其他工程仅作为参考，不能据此移交对话归属。
4. 用户本次要求优先。旧答复是待核验的实现记录，不能证明新版本已完成。
5. 记录与索引只写入本机 `work/` 和工程 `.studio/`，已从版本控制中排除。

详见 [创作记忆](CREATIVE_MEMORY.md)。
