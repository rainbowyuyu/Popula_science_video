# rainbow鱼 · 视频创作工作台使用指南

> 源码仓库首次启动与最新默认值以 [工程 README](../README.md) 和 [本机配置](PORTABLE_SETUP.md) 为准。下文保留功能操作说明；EXE、个人音色和第三方编辑器需自行准备。

本地视频创作工作台把 `video_project` 工程、已有技能、插件清单、工具入口和作品预览放在同一页面。中间与 ChatGPT/OpenAI 或 Claude 协作，右侧播放当前工程的成片、封面和音频。无需 DeepSeek，也不会安装或配置 DeepSeek。

## 启动

双击 `output/RainbowVideoWorkbench.exe`，浏览器会打开本地页面。EXE 包含 Python 运行时、工作台代码、网页、技能与说明文档；运行工作台本身不需要另装 Python。视频工程、TTS、Blender、Node 与素材继续使用本机已有安装和目录，不会把模型权重、音色、API 密钥打包进启动器。

也可在工程目录用 Python 3.11 或更新版本启动：

```powershell
Set-Location './video_project/creator_workbench'
python launcher.py
```

默认在 `127.0.0.1` 的空闲端口启动，重复打开会优先复用正在运行的工作台。自行选择工程根目录或固定端口：

```powershell
python launcher.py --video-root '..' --port 8765
```

`--no-browser` 只启动服务、不自动打开浏览器；`--no-reuse` 启动独立服务。页面使用本次启动生成的本地会话，从启动器打开即可，不需要在网页填写 API 密钥。启动先读取工程列表，选择工程后再加载最新媒体；完整历史、技能和插件按打开相应面板的需要加载，避免每次进入页面都扫描所有历史。

## 开始创作

### 迭代后刷新即可

当前 EXE 是稳定启动器，优先从旁边的 `creator_workbench/app/`、`web/`、`skills/` 目录读取工作台代码和界面。保留这个目录结构；不要只移动 EXE 后删除源码目录。

- **视频工程**：创造模式修改脚本后，需要执行对应视频渲染；生成新成片后刷新作品预览即可，不需要重新编译 EXE。同文件名覆盖也会读取新版本。
- **页面与技能**：保存文件后按 F5，或点顶部刷新；界面、索引和外部技能随之更新。
- **工作台后端**：修改 `app/` 下 Python 文件后刷新即可加载新版本，地址和登录会话保持不变。有任务运行时保留当前代码，任务完成后再刷新加载。代码有语法或导入错误时继续运行上一版，并显示失败原因。
- 只有修改启动器 `launcher.py`、`runtime_loader.py`、EXE内嵌图标，或为独立运行包增加新的底层依赖时，才需要重新构建 EXE。一般视频制作、提示词、布局、工具逻辑迭代不需要打包。

刷新会更新当前工程索引，并为同路径新视频生成版本 URL，避免预览一直显示旧内容。最新媒体与历史媒体分开分页；历史列表在请求时读取。当前素材还在时尽量保留播放位置，刷新页面后不会自动发声。本次2.2更新启动器内嵌图标；后续工作台迭代仍通过刷新读取外部代码。

1. 左侧选择工程，或点“＋”新建独立工程。新建目录包含 `README.md`、`project.json`、`output/` 和 `work/`，空工程也会进入列表。
2. 在输入框选择 ChatGPT 或 Claude，再选“创造模式”或“审阅模式”。创造模式可以写入当前工程源码、文案和配置并运行工具；审阅模式只提供读取工具。
3. 需要特定规范时，在技能列表打开详情并选“用于这次创作”。其他技能可由代理按需读取；无需一次勾选整个技能库。
4. 输入具体目标，例如“保留当前旁白，重做开头 20 秒；先输出三个关键帧和低清预览，检查字幕遮挡后再渲染”。查看过程中的工具结果、修改记录和最终回复。
5. 右侧“作品预览”选择视频、封面或音频。生成结束后刷新工程素材。支持播放、拖动视频进度和独立标签页打开；视频服务支持 HTTP Range 分段读取，长片不用等全部下载后才能拖动。

工程名称使用中文显示名，系列内的集数显示为 `E01 · 主题`。日常科普放入“每天5分钟科普”，科研、产品和其他独立作品保留为独立工程。重命名、改集数或切换系列只更新 `.studio/project.json`，不移动目录、不破坏现有导入路径。关闭“参考系列风格”后，本工程可以自由设计。

封面、文案、声音、字幕和镜头属于当前工程。学习工作室为独立页面，拥有自己的学习工程栏，每个学习工程关联目标作品。主智能体可用 `project_state` 读取最新记录和实际文件路径，在创造阶段通过 `project_action` 保存文案/镜头/字幕、生成个人配音、混音或替换片段。审阅阶段不开放这些写入工具。操作固定在当前工程，不能靠工具参数切换到另一个工程；选段任务先写独立版本，不直接写回原工程模块。模块活动记录在 `.studio/activity.jsonl`，便于后续对话接续。

子模块也按需加载：进入创作页只取项目与系列摘要；打开封面页才取布局记录，文案编辑再读完整正文；进入声音页才查询个人TTS与音乐库；镜头页查询相机和Wan；学习页读取参考，整理页读取后台任务。切换工程不会顺带读取全部历史音频和模板图层。

运行中的任务可点“停止”；已生成的文件与日志保留。上下文旋钮旁标示「持续完成 · 可随时停止」。当前执行器一次运行一个创作任务，持续接续计划、实现、协作和验证，不再按本地阶段轮数、总调用数、整轮时长、看图次数或协作次数硬停；仍按实际工具结果判断完成，不把未完成工作标为完成。

每次执行持续保存消息、工具结果与协作位置。旧版因调用预算、运行时限或输出长度暂停的任务，在点击「继续任务」后进入持续完成；刷新页面本身不会重新启动模型请求。旧任务依据已有日志、阶段记录与实际文件恢复，恢复后先核对产物和未完成项，不直接重放旧写入或渲染操作。模型请求仍可能产生提供商计费；可以随时停止。API错误不会自动切换服务或反复重试计费。

本机 `run_process` 不设置任务时限，不再因180秒或600秒而终止正常渲染；运行到进程退出、失败或用户停止。旧调用携带的 timeout 也不再强制终止进程，停止按钮仍可终止本次工具进程。学习工作流等待智能体时也不再使用2600秒总计时。模型连接的600秒用于检测持续无数据的闲置连接，不是整个流式回复的总时长上限；有数据持续到达时继续接收。长正文按阶段和提供商保存分段并合并成完整稿，不再将阶段正文固定截成16000字符。

模型调用使用流式请求，边接收边读取，避免一直等待完整响应包。流式传输不能保证上游持续可用：HTTP 524 等响应超时、上游暂不可用、限流及网络中断，会分别标记原因并保存进度暂停。页面显示「上游响应超时 · 进度已保存」等状态与「继续任务」，不会把超时提示为密钥错误或任务完成。收到不完整回复时不执行其中的工具；已有完成记录保留。点击继续会沿用该任务的模型、上下文与 effort，不自动更换模型、降低推理强度或后台重试。旧版 524 失败记录也可在刷新后恢复。

### 单次输出上限与继续生成

1M 上下文控制一次请求能带入多少资料，单次输出预算控制模型这一次能生成多少内容，两者独立。部分模型的推理 token 也计入输出预算，因此高 effort 不适合沿用固定的 6000 token 上限。工作台按实际 effort 分配输出预算，遇到 `length`、`max_tokens` 等截断信号时保留已收到内容，按实际容量调整输出预算并分段接续，保持原模型和 effort，不再限制自动续写次数。下一次预算是目标值，实际输出额度还受可用上下文与接口上限限制。

持续完成不等于上游 API 没有容量、额度、连接或服务限制，无法承诺任何请求必定完整成功。真实接口错误仍保存进度并显示原因。半截工具调用不会执行，已完成的写入和工具结果不会重新重放。旧版“回复达到长度上限”记录保留原文件与日志，在刷新后显示继续入口；用户点击后才进入持续完成。

## 上下文、布局与右键操作

输入框工具栏的旋钮展开后可用旋转、滑动或数字输入调整16k–1M，默认1M，按工程保存。设置对新任务生效，包括GPT、Claude及双模型阶段；批量工作流使用各工程自己的设置。预算会预留该次请求的动态输出额度与估算余量，提高后会携带更多工程历史和技能/工具资料。旧工具调用与结果成组整理，当前要求和最新画面证据保留。必要内容超限会提示提高容量，原始日志始终保留。页面显示的是本地估算，上游实际窗口仍由所选接口和模型决定；滑块不会改变模型本身的窗口，接口超限不会自动重试。

桌面端有四处分隔条：系列栏宽度、预览区宽度、智能体输入区高度、画面预览高度。拖动后自动记住布局；方向键精调、Shift加速、双击或Enter恢复该处分隔条，工作区右键可恢复全部布局。窄屏自动采用纵向布局。

- 作品右键：打开、进入封面/文案、重命名显示标题、定位文件夹、复制路径。
- 系列右键：批量封面与文案入口、展开/收起系列。
- 素材右键：预览、交给智能体优化、定位和复制路径。
- 视频/时间线右键：播放、跳到时间点、设置入点/出点、循环选段、抓帧、复制时间码、将选段送入主智能体。
- 封面画布右键：布局优化、图层精修、保存封面、导出模板、管理发布文案。

菜单内用上下键选择，Esc关闭；预览/时间线可按Shift+F10打开。文本输入保留系统剪切/复制菜单。「交给智能体」先填写输入区，确认要求后再发送。

## 工作模块与独立学习页

### 创作：双模型与局部修改

选“双模型协作”，按联合计划、主导实现、协作完善、交叉验证接续同一个任务。在“协作偏好 · 优先主导”中选择各阶段首先使用的接口；默认GPT承担计划、实现与交叉验证，Claude承担协作完善。模型可以按实际问题跨建模、代码绘制、动效、叙事与验证补齐缺口，角色选择不限制能力或文件范围。

当前主导可通过 `request_collaboration` 请求另一模型处理一个限定问题，例如修复几何结构、实现某段动效或复核已有方案。请求需说明相关文件、已确认事实、待解决问题和验收条件。双方共享同一任务的上下文、实际工具结果和当前权限，串行执行；协作者给出文字结论后自动返回原主导，由原主导核对并继续。协作不允许嵌套委托，也不通过换模型扩大审阅权限；不能用两个模型的相互认可替代真实工具验证。

“先给三个方案”开启后，两模型先只读调查并给出三种路线和取舍。点击其中一张方案卡才开始实现；选择前不能写文件、运行进程或制作素材，协作请求也保持只读。这是三种创作方案，不是预先渲染的三条完整视频。方案选择与阶段结果保存在任务记录中。

右侧围绕实际成片交互。点「标记」会在当前时间创建一条意见；「文字」「遮挡」「亮度」「构图」会同时生成可拖动、可调整的即时预演。每条意见有独立起止时间和“采用此条”开关，时间线上的标点可跳回对应位置。点「区间与逐帧工具」才展开精确入点/出点；默认折叠，减少面板占用。

意见自动保存到当前工程 `.studio/reviews/`，以源路径、大小和修改时间区分视频版本；同一路径成片被替换后使用新的意见清单。坐标归一化，拖动工作区尺寸不会改变标记位置。多页面保存使用版本检查，旧页面不能覆盖新记录。离开页面前若仍在保存会提示。

点「整理意见，交给主智能体」先汇总所有采用的意见到总输入框；没有立即调用模型。发送时读取一个固定版本的清单，统一实现并生成新成片。实时预演只在播放器显示，不宣称已经改写MP4；三维模型、运镜、已有字幕等需要修改源工程并渲染。最新封面与音频已分别集中在上方模块，右侧仅显示成片版本。

模型旋钮同时提供GPT与Claude独立effort。每阶段把对应设置发送到实际模型接口，并记录请求强度、有效强度和来源；“跟随接口”读取CC Switch配置。已知不支持的设置在请求前明确报错，未知别名需使用默认，不自动降级重试。

### 封面：系列模板与手动图层

顶部选择系列与封面模板并应用。系列规范固定同画幅的Logo、品牌名、系列栏、标题锚点、字体与字号；系列栏采用颜色底白字，其文字锁定为当前系列名称，保存的 `layout.subtitle` 必须与 `coverSpec.badgeText` 完全一致。主体、视角、景深、材质和画面构图可以自由设计。开启参考系列风格时，这些固定项在界面和保存检查中保持一致；关闭后可自由调整文字与图层。后续模型任务携带同一份 `coverSpec` 及选中模板。

封面区可查看当前工程封面、添加实际素材，分别设计四种比例并导出JPG：

| 比例 | 输出尺寸 |
|---|---|
| 16:9 | 1920 × 1080 |
| 3:4 | 1440 × 1920 |
| 4:3 | 1920 × 1440 |
| 9:16 | 1080 × 1920 |

模板可导入/导出JSON，也可保存当前布局；在“已保存封面”中选择后可以继续编辑。JPG与layout保存在 `covers/<版本>/`，不覆盖旧封面。miniPaint内嵌图层编辑器支持接收当前画布并回传，回传时保存其可编辑JSON工程，重新打开后可恢复独立图层。模板仅保存布局规则，位图和图层工程单独保留。跨比例需要各自排版，不自动保证裁切后的美感。

系列总览集中查看各集最新封面和文案。可以先生成批次计划，核对工程ID与范围，再开始批量任务。批量封面采用**本机模板绘制**：从当前工程已有视频抽取真实帧（无视频时可使用已有图片），按固定品牌和字体分别排版四种比例。该操作不调用AI生成新主体；自动取帧和排版仍需检查主体、裁切、标题与视觉吸引力。版式数据及尺寸检查不等于每个像素均通过人工审美检查。

发布文案支持抖音、小红书、B站与微信视频号，分别保存标题、正文与标签到 `source/publish/<平台>.json` 和同名Markdown。批量文案会调用已配置模型读取各工程的实际资料，生成后写回对应工程；不会代替用户向平台发布。系列总览只显示摘要，编辑时读取完整文案。

### 音频：个人TTS、字幕和音乐库

TTS调用 `D:/python_project/tts` 中已有个人音色，支持小段试听、语速与发音替换。音色参考只在本机读取；原始/处理后声音、参数和参考哈希记录在输出中。字幕支持SRT/VTT/JSON，检查起止时间和重叠后另存。

导入音乐文件夹（默认可选 `D:/CloudMusic`），只登记位置，不把整库复制进每个工程。可搜索并试听MP3等音频，调配乐增益、旁白duck和循环，先生成短试听，再做完整混音。**源视频原声轨会被保留**；如果已经有旧配乐，应选择独立旁白或无旧BGM母片，工作台没有承诺分离混合音轨。

### 镜头：运镜预设、Wan与手动剪辑

环绕、下潜、前景遮挡、高空下降提供可编辑位置/目标/FOV关键帧和路径示意，保存后传给模型实现。路径图是相机轨迹示意，不是当前工程的完整三维渲染预览。

Wan面板提供无生成连接检查、主用/备用凭据来源、提示词、模型/尺寸/时长、一次提交与原任务查询。API密钥来自安全环境配置，下拉框仅显示安全别名，不在项目内保存；“已配置”不等于“生成可用”。任务绑定提交时的凭据来源，失败不隐式切换账户或重新计费。未实际生成的素材不会被标成成功。停止等待并不保证云端取消，原任务ID保留。

手动编辑器：

- [miniPaint](https://github.com/viliusle/miniPaint) 4.14.3：本地内嵌图层画布，MIT。
- [Shotcut](https://github.com/mltframework/shotcut) 26.9.27：本地便携剪辑器，可导出MLT时间线后继续编辑，GPL-3.0。
- [OpenCut](https://github.com/OpenCut-app/OpenCut)：独立在线编辑器入口；未自托管，媒体由用户手动导入，不自动上传。

安装来源、版本与下载哈希保存在 `output/editor-sources.json`，许可证随本地工具保留。工具位于 `tools/`，不打入稳定EXE，也不提交到代码仓库。

### 学习：参考区间到命名风格

可登记公开HTTPS视频链接或导入本地视频，指定观察区间。链接登记本身不表示读过画面。下载依赖本机yt-dlp及站点提供的可读取视频，不加载用户下载配置或登录cookies，不绕过访问限制；无法读取时改用本地文件。

自动学习流程先读取参考区间至少三个时点的实际帧，再用当前工程主体制作短样片。样片必须是实际视频，进行全片解码；之后分别抽取参考与样片的帧，交给双模型比较构图、材质、文字与遮挡。复核没有通过时，保留样片与具体改进意见并继续试做；检查通过后提炼规则并完成。用户可随时停止，实际接口错误仍保留进度，不自动宣布学会。

通过后，将实际提炼的规则写入当前工程 `source/skills/learned-*/SKILL.md`，登记到工程配置，并保留共享技能副本及 `.studio/learning/` 中的依据。全片解码只检查文件可解码；视觉结论覆盖实际抽查的帧，不声称完整连续观看。保存经验不会训练模型权重，也不修改全局模型配置。

### 整理：保留可用版本与重新制作所需文件

“建立标准目录”给新文件定义位置，保留旧入口路径。先选择已确认的成片并登记，后台执行全片解码与依赖记录。再扫描并勾选清理项；源码、模型、原音频、封面、共享依赖、引用素材与目录链接均保留。

清理仅覆盖选定工程中可识别且超过24小时的缓存，以及已登记有效新版之后的重复成片/明确版本族旧输出。删除前再次核验路径、文件状态、源码引用和活动任务，保留清理日志。无法证明安全的旧文件会保留，不按修改时间粗暴删除所有其他文件。此升级没有替你批量删除历史工程。

## 本机权限与回退

这是运行在当前 Windows 用户权限下的本机工具执行器，**不是操作系统沙箱**。文件工具限定当前选定工程，拒绝路径穿越、凭据路径、符号链接和目录联接；但通过 Python、Node、Blender 等执行的代码仍拥有当前用户的操作系统权限。先检查外部脚本，再执行可信的工程代码。

通过 `write_file`、`replace_text` 覆盖已有文件时会保存原文件备份并记录 diff；脚本自行写出的所有文件不保证都有自动备份。建议重要重构写入独立版本目录，保持一个可回退成片。

任务记录位于：

```text
creator_workbench/work/runs/<任务ID>/run.json
creator_workbench/work/runs/<任务ID>/backups/<序号>/<工程相对路径>
creator_workbench/work/runs/<任务ID>/process-<ID>.log
```

记录包括实际工具结果、模型用量、退出码、修改文件与备份路径。日志进行凭据脱敏；仍不要在任务提示、源码或命令参数中粘贴密钥。工作台关闭时的未完成任务在下次启动保留中断记录，不假装继续运行；用户点击「继续任务」后才恢复模型调用。已有断点接续消息与协作位置，旧任务依据记录恢复时会重新核对实际文件。恢复原文件前停止相关任务，再按记录中的工程相对路径复制所需备份。

## 资源索引的含义

索引登记本机路径，不批量复制所有模型、技能、付费素材与私人音色。技能正文按需加载；同名同内容去重，同名不同实现保留。详细扫描规则见 [capability-map.md](capability-map.md)。

工具的 `available` 表示可执行文件存在；`configured` 表示脚本、目录或依赖声明存在；`unverified` 表示服务未核实。插件安装清单不等于 MCP 已启动，Blender MCP、Lux3D、Qwen/Wan 等仍须在实际任务中检查。工作台不能仅凭登记自动获得 Codex、浏览器或第三方 MCP 的会话权限。
