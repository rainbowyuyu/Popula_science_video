# 工程协作流程 · 2.5.0

本版以工程为隔离单位：素材、草稿、时间段、标记、模型参数和后台任务都带工程编号。左栏用于选择作品与管理系列；中间为当前工程的工作台与总智能体；右侧持续保留该作品的成片预览。

## 1. 从看片到修改

1. 选择作品，默认只读最新成片与封面索引，历史版本按需展开。
2. 播放或逐帧查看，选时间段、标记位置，必要时添加文字/亮度/构图/遮挡预演。
3. 在修改清单中编辑意见，选择是否采用；删除及清空都可撤销。每条修改关联视频版本，自动保存状态可见。
4. 「联动工作台」将相同素材、时间段和意见编号传给字幕、声音、运镜或封面。中间上方显示当前联动选段，可解除。
5. 「整理意见，交给主智能体」填入工程草稿；用户检查后点击开始。若覆盖已有文案，提供恢复之前草稿的入口。
6. 总智能体修改工程并生成新版本。预演不是修改已经烘焙进 MP4 的像素；实际成片仍以新渲染文件为准。

意见状态：自动保存 → 已整理（prepared）→ 已冻结进智能体上下文（submitted）。submitted 不表示意见已全部执行或验收通过；意见继续保留供对照。换成片版本后不自动套用旧标记。

## 2. 多工程执行

- A 工程创作时，可以切到 B 写文案、做封面或启动另一个任务，也可以新建 C。
- 每个任务独立轮询。A 完成时只刷新 A 的缓存，不换走 B 的画面、不清 B 的草稿。
- 同一个工程只允许一个主模型任务；源文件修改和媒体生成共享工程锁。需要等待或冲突时说明原因，不全局阻止其他工程。
- 任务中心可打开对应工程、停止、继续。停止后保留进度；可恢复的任务提供继续入口。
- 主智能体草稿保存到本地浏览器存储；播放位置、封面草稿及修改撤销记录按工程/成片隔离。浏览器清理站点数据会清除本地草稿，已保存工程文件不受影响。

## 3. 中断处理

| 情况 | 用户看到的行为 | 恢复方式 |
|---|---|---|
| 页面刷新或关闭 | 服务中的任务继续；刷新重新连接 | 不重新提交模型请求 |
| 轮询短暂断线 | 保留画面和草稿，逐步延长重连间隔 | 自动重新获取任务状态 |
| 提交响应丢失 | 显示「发送状态待核对」 | 同一请求编号显式重试，服务器返回已有任务 |
| 模型超时/限流 | 清楚显示暂停原因，保留完整已收到部分 | 用户点击继续，沿用原模型和 effort |
| 服务重启或意外结束 | 标记中断，保留检查点和上一个有效备份 | 不自动重新计费；检查后继续 |
| 在工具批次中停止 | 不假装整批成功 | 核对实际文件与后台任务，不盲目重放工具 |
| 标记保存冲突 | 显示冲突与重试 | 合并双方意见，保留冲突意见供用户判断 |
| 同工程文件正在被写入 | 保存返回 409，草稿保留 | 当前写入结束后再保存 |

运行记录与检查点采用完整写入、fsync、原子替换，并保留上一个可读取 JSON。恢复能力依赖实际文件和检查点；上游服务容量、认证或额度问题仍可能需要处理后再继续。

## 4. 系列与功能

- 「管理系列」新建、改名、归档/恢复系列，批量给作品指定归属，不移动现有项目目录。
- 归档只隐藏日常选择入口，不删除作品、封面或模板。
- 「工程功能」控制封面、声音、字幕和镜头模块；剪辑和主智能体一直可用。关闭模块不删资源，可随时重新打开。
- 系列规范约束品牌、栏目、标题层级与画幅坐标；可选择取消参考，做独立封面。批量操作针对明确勾选的作品。

## 5. 封面操作

1. 在右侧找到最精彩的帧，点联动封面，或进入封面页点击「使用播放器当前帧」。
2. 写一个主标题，或从已保存的平台文案中选择标题。选择系列模板。
3. 分别选择 16:9、3:4、4:3、9:16，调整水平取景、垂直取景、主体放大。四比例并列缩略预览，当前比例显示大图。
4. 预览与最终导出使用同一个本地渲染器。导出当前比例或四比例 JPG/PNG，不需调用付费模型。
5. 在「已保存封面」重新打开，继续调整原素材、帧时间、模板和构图。旧完整封面可作为新素材使用，不能假装已恢复其原始图层。
6. 高级操作收在模板导入/保存、图层精修与发布文案页面中；普通制作不必遍历这些按钮。

## 6. 验证范围

使用临时工程、离线模型响应与色板视频验证并发、取消/恢复、保存冲突和跨工程竞态；封面验证包含真实视频取帧、实际像素尺寸、JPG/PNG 解码及元数据重开。桌面与窄屏进行点击操作、控制台和横向溢出检查。

不通过真实付费生成来验证调度，不恢复用户原先暂停的制作任务；已有成片和 EXE 保持原文件。
