# rainbow鱼 · 视频智能编辑器 2.7.0

刷新当前网页即可使用新版，EXE 无需重新编译。启动入口为 [RainbowVideoEditor.exe](output/RainbowVideoEditor.exe)，请保留它与 app、web、skills 的目录关系。

- 新增「制作简报」：把核心问题、受众、故事主线、视觉声音和保留项保存到工程。新任务与双模型自动参考，当前明确要求优先；编辑简报不会更改运行中任务。
- 主智能体改为创作工作板：集中展示步骤、当前事项、真实文件与核验范围。长回复和工具记录按需展开，模型本轮结束但步骤未完会明确显示待办。
- 封面、声音、镜头和创作记忆共用主输入框，自动携带当前工程及选段。成果更新只刷新列表，不打断正在播放的视频；点击成果才切换预览。
- 提供工作台、双栏协作、成片预览三种视图；窄窗口用工作台/预览切换。学习页同步整理了参考库、学习成果和后台任务筛选。
- 制作策略区分全片、局部修复与单项素材：完整片先建立故事与共用时间线、验证代表镜头后逐段制作；小修改直接定位检查。该策略是本项目新编写的制作协议，不是 Codex 内部系统提示词。

新版操作、核验含义及已知边界见 [创作工作台 2.7](docs/CREATIVE_WORKBENCH.md)。

- 新增「创作记忆」：按工程同步 Codex 对话与迭代，默认查看自己的修改意见；支持原文、截图、搜索、归属纠正、偏好与避坑标记。双模型按本次问题共用相关记录，后续工作台迭代自动归档。完整说明见 [创作记忆与双模型接力](docs/CREATIVE_MEMORY.md)。

- 多个工程可同时创作、切换和新建；任务中心按工程显示运行、停止和继续。相同工程的源码写入互斥，标记和草稿仍可编辑。
- 请求发送后断线时保留请求编号，点「核对并重试」不会重复创建任务。后台断连保存检查点；工作台重启后明确继续，避免重放未确认的工具操作。
- 成片修改清单支持删除、撤销、批量采用、失败重试及多窗口冲突合并。选段可联动字幕、声音、运镜和封面，最终统一交给主智能体。
- 封面工作台直接使用当前视频帧或图片，四种比例分别取景、预览、导出 JPG/PNG；保留素材和模板信息，可重新打开编辑。系列管理支持新建、重命名、归档、恢复和批量归属，工程功能可按需显示。

完整操作与状态设计见 [工程协作流程](docs/PROJECT_FLOW.md)。

- 输入框工具栏的旋钮展开后可设置16k–1M上下文、GPT和Claude各自的effort；按工程保存，新任务生效。
- 双模型按联合计划、主导实现、协作完善、交叉验证接续任务；可设置各阶段优先主导，遇到具体问题可请另一模型实现或复核，共享上下文与工具结果。
- 默认「持续完成 · 可随时停止」：不再因本地阶段轮数、总调用数、整轮时长、看图次数或协作次数而硬停；输出截断会保存内容并继续分段生成。旧暂停任务点击「继续任务」后进入持续完成。
- 右侧直接看片、标记、拖动文字和遮挡区域，实时预演亮度与构图。修改意见按成片版本、时间和位置保存，最后统一交给主智能体生成新版本。
- 最新封面在「封面与文案」、最新音频在「声音」中浏览，右侧仅保留成片版本。
- 顶部「学习工作室」打开独立页面，拥有自己的学习工程栏和后台队列；可关联目标作品并复用已经核验的风格规则。
- 23个既有工程已建立规范目录与真实旧路径索引；源码和素材保持原路径，后续创作会读取目录导航。

预演不会覆盖原视频；改模型、镜头与已有烘焙文字仍由主智能体修改源码后重新渲染。上下文容量是本地预算，模型与网关支持的上限仍适用。学习任务在本机服务运行时继续，关闭浏览器不影响队列；重启服务后由用户明确重新加入，避免重复计费。

恢复旧任务时会参考已保存记录并重新核对文件，不能凭旧摘要假定产物完整。接口错误不会自动换服务或反复重试计费；审阅与候选阶段始终只读。

模型请求采用流式接收，避免等待整包响应才读取结果。上游仍可能超时、限流或暂时断连：此时保存进度并暂停，页面区分原因并提供「继续任务」。HTTP 524 表示上游响应超时，不据此判定密钥失效；继续沿用原模型和 effort，不自动换模型、降低强度或重试。

单次回复长度与 1M 上下文容量分别计算。单次输出预算按所选 effort 分配，受到可用上下文和接口能力约束；回复被截断时保存内容并自动接续，不再设置“两次续写”限制，不降低 effort，不执行未完整收到的工具参数。持续完成不代表上游 API 没有容量、额度或可用性限制，也不能保证任何请求必定成功；真实接口故障仍保存进度，由用户继续。
