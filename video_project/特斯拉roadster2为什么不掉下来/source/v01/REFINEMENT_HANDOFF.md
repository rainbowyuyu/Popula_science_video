## 本阶段改了什么，以及为什么

1. **力箭头改画在实际作用点。** 之前 `悬停` 的推力画在质心，等于把“力作用在哪”讲错。现在 `悬停` 的推力落在车底教学喷口，`力偶` 的两股力分别落在左右喷口，`固定喷口` 的推力落在随车旋转的喷口上；重力始终画在质心。这样“绕质心的力矩”才有来源。
2. **共用相机驱动修好二维/三维错位。** 三维场景与SVG箭头现在都从 `cameraFor(state)` 取同一台正交相机，不再各算一次；米制正交范围不再被 R3F 改成像素范围。
3. **固定喷口机位从正侧视改为3/4后视。** 正侧视时车身绕x轴转90°后，横向推力正好指向镜头，被压缩成一个点——恰好把该段结论画没了。改机位后90°的横向力可读。
4. **标签改为避开车体包围盒。** 之前按箭头中点向外推，箭头短时标签压在车身上。现在先用车体8个角点投影出屏幕包围盒，把标签推到盒外，并做遮挡登记；“质心”槽位优先占用，力标签不再压住它。
5. **补喷流示意。** 喷流方向与车体受到的推力相反，用冷气风格虚线段表示，不画燃烧火焰。
6. **地面阴影改锚在世界上。** 阴影随相机缩放并固定在世界地面平面，原地旋转不会被误读成升力。
7. **动效与节奏。** 标题、信息栏、字幕分别缓入缓出；字幕加半透明底条；自由飞行段自转从约1.25圈降到约0.6圈，避免转动读成原地翻转。
8. **力偶段的阶段提示**改为“加速转动，约1.25圈 → 关闭喷口，转动继续 → 反向力矩，减速停转”，与数据一致。

## 重渲染命令（在 source/v01）

```text
npm run check
npm run stills
npm run preview
```

- `stills` 跳过同名图片，改布局后需把 `scripts/render.mjs` 里的 `preview-frame-r*` 前缀换成新编号，否则不会重出图。
- `preview` 在 `output/v01/roadster-mechanism-preview-v02.mp4` 已存在时会主动报错保护旧版；新一版请改 `OUTPUT_SUFFIX` 或新版本号，不要删除旧成片来绕过。
- Remotion 直接渲染出的MP4音轨会被AAC填充拖长约47毫秒。当前流程固定为“先渲染画面，再用 `audio/v01/preview-narration.wav` 重封装音轨并截到1160000采样”。不要跳过这一步，也不要重复跑TTS。
- 改物理或布局后需要重跑：`node source/v01/physics/build_preview_v3.mjs`（`Preview.tsx` 从 `preview-frames-v3.json` 读取）。`build_preview.mjs`(v1)、`build_preview_v2.mjs`(v2) 保留作追溯，不要删除，也不要让组件重新指向旧数据。
