# 《每天5分钟科普 · DNA 存储》发布文案

本章实际讲清一条可检查的链路：文件切片与地址 → A/T/C/G 编码 → GC 与同聚物约束 → DNA Fountain 冗余 → 合成与测序噪声 → 地址聚类、局部比对和共识恢复 → 大模型辅助候选筛选。画面里的红色错误字符是固定生成的教学样本；大模型只辅助筛选、质量预测、检索和工具调用，不能替代纠错码、合成仪或测序仪。资料目前只在本地工程，尚未同步 GitHub。

**标题**

把家庭视频写进 DNA：为什么算法比容量更关键？

**正文**

看到什么：文件先被切成带地址的小片，再翻译成 A、T、C、G；不合格的候选会被退回，丢掉几片也要能恢复。

为什么：合成和测序会带来替换、插入、缺失，甚至整片读不到。地址、GC 比例、同聚物约束和 DNA Fountain，都是给分子读写留下的余量。

## B站

**标题**

DNA 存储怎么把文件读回来？从地址、GC 约束到 DNA Fountain 与大模型辅助

**简介**

一条 5 分钟的生信算法故事：先把文件切片并加地址，再映射到 A/T/C/G；用 GC 比例与同聚物限制筛掉高风险序列，用 DNA Fountain 留下恢复关系。经过合成、保存和测序，读段会带着替换、插入、缺失和丢片回来，算法再用地址聚类、局部比对、质量加权共识和外层纠错找回文件。最后放进大模型：它能做候选评分、质量预测、文献检索和工具编排，但不能替代纠错码、合成仪或测序仪。
