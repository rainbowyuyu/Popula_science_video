# DNA 存储 V5 · 故事与画面升级

本版成片规格为1920×1080、30fps、321.8秒（9654帧）。

本版从“弄丢几块，还能找回吗”开始：家庭影像拆为图块，进入字母编码，经历候选筛选、冗余恢复和有错读段，最后回到同一幅画面。37句旁白重新编写，先解释遇到的麻烦，再介绍对应方法。使用用户本地 rainbow鱼 参考音色重新合成；不拉伸语速，不按旧章节长度填静音。

## 画面改动

- 手机中的图像来自真正完成字节编码与恢复验证的3秒教学短片；照片素材为既有生成情境图，不冒充实验室录像。
- 重建手机图块，连续展示分解与复原；片尾完成组装后再播放。
- 移除重复展台、背景立柱与悬空环境视频卡，改为连续浅色影棚、分层灯光和阴影。
- 按动作安排手机、液滴、喷嘴、错误读段、比对矩阵的推进与轻环绕；重要机理保持完整可读。
- 替换、插入、删除在旁白对应位置真实改变字母队列；“今天我们去看海”的漏字类比用于进入序列比对。
- 分数计算逐格显示，比对回溯到零，质量加权投票汇入共识链。论文页保持真实页面，作者年份放在卡片之外。

本地TTS工程：`D:/python_project/tts`；原始声音与处理记录保存在 `work/audio-v5/`。BGM为同一集《DNA档案微光》的故事时序重编，按新章节演奏、重新duck和混音，并未把其他集曲目改名复用。保存了音乐采样来源与许可。WAV实测−16.01 LUFS、−1.49 dBTP；编码前AAC预览为−16.04 LUFS、−1.38 dBTP。最终MP4的音轨另做解码测量，以research/encoded-audio-v5.json为准。

三句尾端能量异常的源句完整重录，新旧源及选择依据均留档。101条字幕最长23字，采用48px统一字号。字幕经过离线识别辅助对齐与逐句文本核对；自动识别不能证明声调、韵律或听感。没有把未完成的主观听审写成已完成。技术检查、代表帧目视检查和最终编码文件检查分别记录。

重新渲染：`npm run check`、`npm run render:v5`。母带采用静音画面渲染后直接mux验证过的WAV，避免分片AAC延迟。旧V4成片与源码保留作回退。
