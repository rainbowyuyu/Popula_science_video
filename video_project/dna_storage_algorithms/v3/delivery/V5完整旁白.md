# 把视频存进 DNA，弄丢几块还能找回来吗？

成片时长：321.8 秒。配音：本地 rainbow鱼 个人音色。

00:00  这段视频，我把它改成四种字母，删掉几段，再弄错几个字。最后，还能一帧不差地找回来吗？

00:08  二零一七年，研究者把《火车进站》等文件写进合成DNA，再读了回来。咱们就在电脑上，试一次编码和恢复。

00:18  视频是一长串零和一。先切成短段，安排位置线索，打乱以后，还能重新排队。

00:26  两位一组：零零，零一，一零，还有一一。四种组合，各配一个碱基字母，换一种记法。

00:35  字母是碱基的简写。合成仪照着顺序连接碱基，零和一就能用分子来记录。

00:42  但随手翻译未必好用。这串重复字母，是六个还是七个？写入和读取设备，也可能数错。

00:50  G和C合起来的比例，也要落在合适范围。偏得太多，会增加合成和读回的麻烦。

00:58  所以每个候选都要检查：重复太长、比例不合适，就换个组合；通过了，再往前走。

01:06  位置线索也得带上。短分子混进一管液体里，可不会按第一段、第二段站好。

01:13  现在捣乱：这几段，整段拿走。只存一份，信息就断了，得提前留下恢复线索。

01:21  喷泉码挑几个数据块，按规则混成一个包；再换一组，继续生成。包里保留着原始块之间的关系。

01:30  这一滴代表数据包。种子编号让解码器重做当初的选择，找到混进来的原始块。

01:38  混合用异或：两位一样得零，不同得一。同一份数据再异或一次，就能抵消自己。

01:46  找到甲，就能从甲乙组合里抵消掉甲，得到乙。再拿乙抵消乙丙组合，丙也出来了。一块解开，接着解下一块。

01:56  收到足够多、足够合适的组合，丢几个包，仍可能恢复文件。线索不够，解码就会停住。

02:04  合成仪把选好的序列做成短分子。数字文件跨过电脑屏幕，变成可以保存的材料。

02:11  信息留在碱基的排列中，分子却会受损。温度、水分和保存方式，都影响以后还能读回多少。

02:20  取回视频，就得测序，读出碱基字母。同一段分子，往往会得到多个读段。

02:28  给演示加三种错误：换掉一个，叫替换；多塞一个，叫插入；少掉一个，叫缺失。再扔掉一整条读段。

02:37  这些副本各有错漏，但出错的位置未必相同。这一张缺的字，另外几张也许还有。

02:44  换成一句话：今天我们去看海。几个人各抄一遍，有人漏了“去”，有人写错“海”。把几张纸摆在一起，原句就有了线索。

02:55  把同一段的读段分到一组。位置对不上、质量太差的，先放一旁，免得把不同的话越改越乱。

03:03  还不能直接投票。少一个字，后面的字就全往前挤一格。逐列比较，后半句好像处处都错。

03:12  给缺字的位置留个空格，后面就对上了。电脑比较不同摆法：相同字母得分，不同扣分，留空也有代价。

03:21  方格表记下对齐分数。从最高分格往回找，直到分数归零，就能追出匹配最好的一段局部片段。

03:30  这叫局部比对，用史密斯沃特曼算法。按评分规则寻找对应关系，把缺口放到更合理的位置。

03:39  排齐后，再逐列合并证据。更多副本支持的字母，通常更可信；质量好的，还能占更大权重。证据不够，就保留疑问。

03:49  短段里的错字修好了，整段缺失再交给冗余关系。最后拼回文件，核对校验值：亮起的画面，内容也得对得上。

04:00  这次找回视频，还能记下哪些序列总容易读错。下一轮，能不能提前绕开它们？

04:07  模型也能学习DNA序列。先把长串字母切成小片段，交给模型处理。

04:13  可以按固定长度切，也可以合并常见组合。但能接收序列，不等于会挑存储材料。

04:20  要预测某台设备容易在哪儿出错，得用它的实验数据训练和检验。分数要和实际结果对得上。

04:29  模型给出建议，还要过约束检查，再做实验。能否减少错误，让读回结果回答。

04:36  大语言模型可以查资料、调工具；文件来回这一趟，仍靠编码、合成、测序和解码。

04:45  回到这段视频。删掉的片段、弄错的字母，这次都找回来了。字母变回零和一，画面接着往下走。

04:53  要随手存一部电影，成本和读写速度还得改进。今天的DNA存储，更适合长期档案。

05:01  从零和一出发，借分子保存，再靠线索找回。这条路走通后，老照片、老电影，也许真能住进小瓶子。
