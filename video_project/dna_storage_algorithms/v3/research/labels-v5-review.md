# V5 标签与画面遮挡复核

审阅对象：`FilmV5.tsx`、当前 `CameraPathV5.ts`、真实程序化模型的逐时刻包围盒。2026-10-11。当前旁白时间 JSON 仍为临时版；最终本地 TTS 回填后必须再运行 `node scripts/qa_labels_v5.mjs`。

这是 CPU 投影检查：每个标签有效期内按 0.2 秒采样，投影当时的实际模型包围盒，与 Film 使用的标签宽度/位置规则比较。文字度量为近似；组合模型的包围盒会包含空隙，因此不把重叠率等同于真实像素遮挡。未检查外部 GLB、材质透明、遮挡层级和最终字幕渲染。

## 与字幕和语义相关的另外两点

- 共识链目前在 n27 开始后用四秒从 y=-7 升至 -1.95。约 204.77 秒投影下沿在 y≈990，仍经过字幕区。离开画外进入画面的过程本身连续，但关键字母在口播初段可能不可读。可把入场提前约 1.5–2 秒，或在旁白开始后约一秒内完成；随后保留足够时间看逐列投票。
- `连续重复 → 退回` 使用固定世界锚点 `[4,2,.7]`，真实退回链现在向高处离开。标签不遮挡，但后半段引线会指向原来位置。可将标签有效期结束于退回动作完成，或从同一事件计算锚点，跟随链到退出画面。

原始逐标签数字：`research/labels-v5-review.json`；替代配置试算：`research/labels-v5-options.json`。这些结果应作为修改建议，不能替代新代表帧目视验收。
