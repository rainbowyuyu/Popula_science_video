# DNA V3 首轮独立实帧审核

审核对象：1920×1080 JPG，帧 180（6 s）、930（31 s）、2910（97 s）、5640（188 s）、8925（297.5 s）。五张均使用图像查看工具逐张检查。这里只证明这些静帧的观察结果；没有观看连续视频，不能据此声称所有转场或全片遮挡通过。

## 优先修复的五项

1. **片尾行名出现不自然的 3+1 断行。** 帧 8925 的“序列质检”“冗余恢复”“共识恢复”均被拆成三字加一字，削弱专业排版。当前列宽145px不足以容纳38px四字。建议列宽180–190px、禁止换行，并保留行名与公式之间的间距。无需缩小文字。
2. **片尾钢笔遮住共识公式。** 帧 8925 中深色钢笔横穿 arg max / 求和区域。它是装饰物，应移出数学内容区或删除。不能把这项解释成艺术遮挡，因为会影响公式阅读。
3. **片尾两组底部文字挤到同一基线。** 第二条论文信息横向延伸到右侧 encode 流程开头，形成“2024 encode…”的视觉连写。建议论文元数据有明确限宽和独立排版，技术流程移到更低的一整行；论文名称、作者、年份仍置于纸页外。正文行名和元数据建议继续保持至少36px。
4. **矩阵路径盖住它要说明的分数。** 帧 5640 的橙色连线穿过4、6，终点球压住8。建议路径走字格边缘、数字保留在更靠前的一层；终点用角标或外环。矩阵轴字母已由主代理在源码补充，须在下一轮实帧确认。若增加“相同 +2 / 空位 −2”，应只在相应一步出现，利用上方空白，不再叠一张信息卡。
5. **回溯口播与轨迹方向需统一。** 这是源码/旁白契约发现，静帧本身不证明运动方向。当前 narration n25 说“沿着高分路径往回走”，而 ConsensusLab 的 spot 仅从 [1,1] 正向走到 [5,6]。建议先计算并点亮最高分8，再沿有效路径反向追溯；或把口播改成正向累计。不能为让动画看似单调而篡改得分。

## 数据独立检查

重新用匹配+2、不匹配−1、空位−2计算 Smith–Waterman：参考 GATTAC，查询 GATAC。全部42格与保存矩阵一致，最大分数8。

有效路径为：

`[0,0] → [1,1] → [2,2] → [2,3] → [3,4] → [4,5] → [5,6]`

累计分数为：`0 → 2 → 4 → 2 → 4 → 6 → 8`。其中 `[2,2]→[2,3]` 是空位−2；`[2,3]→[3,4]` 是 T/T 匹配+2。该路径正确，与先匹配另一个T再留空位的路径同分。完整可复核输出在 `matrix-independent-check.json`。
