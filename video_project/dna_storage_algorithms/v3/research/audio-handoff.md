# 一滴里的记忆 · 音频交接

最终旁白采用 rainbow鱼 本人参考声线，由阿里云官方 qwen-audio-3.0-tts-flash 合成。37句、1194字，原声256.08秒；保护后的完整句源264.96秒。自然停顿与观察时间约25秒，290–300秒留给证据片尾。无变速、变调、截断。

BGM《一滴里的记忆》为本次新编排，80 BPM、4/4、E minor/G major，钢琴、竖琴、弦乐与轻击。1064个音符事件可重新生成，CC0样本原始许可及哈希随附。水滴/滑动转场声为原创固定种子示意音效。

master.wav：300秒，48000 Hz，双声道24bit PCM。响度 -16.01 LUFS，真峰值 -1.50 dBTP；预编码AAC -16.02 LUFS，真峰值 -1.49 dBTP。母带SHA256：80e592330890a490d93b900cb1e1b4a892f41067b6fb1d52c2c84ea6c5fa274f

字幕84条，每条至多23字符，最短1秒。Whisper-small无提示、无VAD自动审计并依据词时间标记校对字幕；所有句子的活跃语音字幕覆盖率≥95%。统一简繁体和数字书写后，仅甲乙丙被识别成近音字留下审核提示。字头字尾有80/160毫秒保护，处理延迟实际测量补偿，原句和整轨采样匹配检查通过。

**未进行主观听审**；自动指标及ASR不能证明发音声调或音色一定合格。已提供 raw/clean 同响度A/B与含音乐分段试听。

- 26.55–33.03秒｜n04｜encode：两个二进制位一组：零零、零一、一零、一一，正好四种组合。

## 复现顺序

`python scripts/voice_cloud_v3.py synth`（只在确需新句时调用；缓存不重复请求）。随后执行 install_cloud_voice_v3.py → prepare_voice_v3.py → asr_captions_v3.py → mix_v3.py → qa_audio_v3.py。音频处理与ASR使用 D:/python_project/tts/.venv/Scripts/python.exe。配乐重新生成使用 score_v3.py。

所有凭据从环境 QWEN_API_KEY_BACKUP 运行时读取，未写入工程；克隆参考保留于本地TTS工程，音频数据只发给授权的阿里云语音服务。实际服务用量见 audio-source-manifest.json，未访问计费账单时不声称费用已核实。
