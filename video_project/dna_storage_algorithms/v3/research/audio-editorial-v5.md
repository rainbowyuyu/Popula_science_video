# V4 口播节奏独立诊断与 V5 建议

本记录基于文本、真实 WAV 时长、时间线与离线 ASR 词锚，不声称完成了人耳试听。

V4 的 36 处句间空档合计 41.423 秒，均值 1.151 秒，19 处超过 1 秒。片头 n01→n02 的完整片段间隔为 3.14 秒；按 ASR 末词/首词估计，实际语音之间约 3.86 秒。多处章节边界还有 1.9 秒片段间隔。全片原声 237.92 秒，其余被固定章节窗、护音静音和片尾占用，因此画面在动，故事却会反复停下来等它。

新编排以完整句源的实际长度为主，每句后只增加 0.2–0.5 秒的自然间隔。章节边界放在这段间隔的中间，不再额外叠加前一章 tail 和后一章 lead。总长不足约 300 秒时，把差额交给编剧补一个真实的难题、试验或结果，不把差额分摊成句间长静音。片尾保留单独的明确停留。

建议把“介绍功能”的句式改成“遇到什么麻烦→做一次试验→看见结果→出现下一个问题”：

| 位置 | V4 的节奏问题 | 建议 |
| --- | --- | --- |
| 开场 | 两个抽象问题之间停近4秒，随后“科学家已经在试这件事”信息很泛 | 从一段具体录像或手机存储提醒开始，紧接着把它变成分子；标题出现在同一段动作上。两句间约0.3秒，不留空等标题。 |
| 地址与约束 | “挑食”“照顾比例”“质检口”连续三个比喻，因果容易稀释 | 只留一次质检比喻。让一串重复字母先读错，再明确说明换排法；先看失败，后说规则。 |
| Fountain | “喷泉码会从原文件里挑几块”像术语定义 | 先故意丢掉一段录像，再问能否救回。先让观众看一次找回过程，随后补充“这种组合办法叫喷泉码”。 |
| 比对/共识 | 每句都“接下来”“这叫”“这里用”，像逐页讲解 | 保留抄字条这个例子，在同一条字母线上连续移动。缺字导致错位→允许留空→找得分更高的排法→多份读数互相作证。算法名作为贴物标签，不必每次口播铺垫。 |
| 大模型 | “模型学习片段联系”“给候选打分”等抽象动作连排 | 从“刚才哪些序列总出错”切入。让模型利用已做实验的结果筛下一批候选，再真实读回核对；用同一份失败清单把前后串起来。 |
| 结尾 | 把整套规则再总结一次，节奏趋于宣传词 | 只回到开头的录像。播放恢复后的同一帧，然后留一句当前成本/读取速度的局限，最后进入证据页。 |

开头可选自然句式（供最终稿取舍，不自动进入配音）：

“这段生日录像，十年后还找得到吗？手机换了，硬盘也换了，文件得跟着一次次搬家。有人想给它找个小得多的住处：一滴液体。”

这段写法的重点是“录像搬家”的具体动作。无需重复“未来将会改变一切”“小小分子蕴含巨大能量”等空泛评价，也不用旁白指挥观众看镜头。家庭画面仍是虚构示意，不把它说成一次已经完成的真实数据恢复实验。

发音方面保留 V4 已验证的做法：二进制四组之间留标点停顿；DNA、Fountain、k-mer、BPE 的标准拼写留在画面，口播用中文含义；甲乙丙与异或的 ASR 同音误写只触发复核，不自动判成错读。生成后按实际句长重建字幕，原始句源与清理源均留档。
