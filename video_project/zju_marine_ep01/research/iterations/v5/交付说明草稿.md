# V5 交付说明

- 成片：`marine_energy_episode01_v5.mp4`
- 规格：1920×1080、30fps、367.17s；H.264 + AAC 48kHz。
- 主题：浙江大学·海洋新能源·第一期《海洋风电总览》。

## 本轮重点

- 海面使用固定种子波谱、WaterPro licensed WebGL 兼容适配器、太阳高光、反射、折射和设备尾流。
- 片头/片尾为世界空间玻璃铭牌，与海面反射同帧更新；字幕和Logo保留安全区。
- 主风机采用分件机舱、轴系、发电机、变流器、基础和海缆的连续透明剖切。
- 风章节增加雾状风路线，转子章节增加跟随轮毂的方向弧线；所有动画由绝对秒数驱动。
- 校园陆地加入 Poly Haven CC0 HDRI、草地PBR和轻量真实树木LOD；不改变岸线和相机轨道。
- 水下段包含低通旁白、早期反射、进出水冲击和确定性气泡床。

## 验证边界

`npm run check`、运动数值审计、代表帧抽查、ffprobe、响度、黑帧、长静音和AAC包连续性均已执行。未完成全片正常速度主观观看和完整主观听审，交付QA中已明确记录。水面是 licensed WebGL compatibility adapter 与自写固定波谱的教育渲染，不代表原生FFT/SSR/WebGPU或CFD海况结果；模型也不是浙大官方CAD、场址设计或工程认证。

素材来源、哈希、许可证、WaterPro provenance、源码和可恢复V4回退见 `delivery-manifest.json` 与 `source-v5.zip`。
