# V7 制作记录（待最终编码验收）

本次修订沿用现有 89 段解说和字幕时序，总长 14 分 14.033 秒，包含 12 秒来源页。重点是人物动作、道具避让、解剖定位、机制可读性、跨尺度镜头和同一首钢琴曲的编排。

## 本轮修改

- 人物：固定骨长的手臂及腿部姿态；与手腕一致的握叉手；独立短裤；坐姿、起坐、步行及回到解剖姿态的过渡；扶手接触与松手。
- 道具：甜饮与水依次进入/退出；餐桌从手臂前方避让后再侧移；测量道具退场与人体归位分开控制。
- 定位：器官只在人体恢复解剖基准后显现；胰岛固定在胰腺内部；小动脉固定在实际股直肌内部，先显示母组织位置，再进入局部。最终抽样另发现肾上腺标签误指双侧中心，已定位到 FJ3129 左肾上腺真实表面顶点并单独重渲染 h054。
- 机制：同一肌肉细胞膜连续演示摄糖、抵抗和收缩信号；同一 β 细胞演示信号衰减与持续作用；胃内容变化、脂蛋白运输/回收、肾脏水钠与钾的方向示意。
- 血栓：在同一毫米级血管中显示斑块、破口、聚集、阻塞及剩余血流通道；心房局部显示减速与凝血变化；抗血小板/抗凝处理减少新增过程，保留已有血栓。
- 音乐：保留指定的 Lemon Tree 钢琴录音、原速和原调，调整乐句衔接与较慢的章节音量包络；旁白时间未移动。

## 表达范围

人体与器官来自现有 Human Atlas / BodyParts3D 参考资产；细胞、血管和肾单位局部为带长度单位的代表性教学模型。方向箭头、信号点、表面脂肪变化与凝血聚集是机制示意，不是按患者测量得到的组织浓度、血流 CFD 或个体用药预测。压力动画沿用保存的 0D Windkessel 教学计算。

完整研究来源与资产许可继续见项目现有 `delivery/制作与来源-v5.md`。人物动作采用确定性骨架姿态与独立服装几何；没有声称使用动作捕捉或真实布料动力学。本轮不改变解说中的医学结论：抗凝药不能降血压，也不把抗凝或抗血小板药画成直接溶解既有血栓。

## 检查口径

先后逐句查看 89 段的三时点抽帧，再对重点动作和运镜以每 2–10 帧的采样间隔检查中间过程；独立人物检查包括正、侧视角及非顺序定位。具体查看范围、旧问题与修复证据保存在本目录的各 review JSON 中。

最终 MP4 仍须完成全片解码、黑帧/长冻结扫描、最终编码抽帧复核，以及实际 AAC 相对已安装母带的全程 5 秒窗口时移检查。抽帧与数值检查不等同于人工逐帧观看或完整主观听审；验收时按实际完成情况记录。

## 重现入口

项目根目录执行 `npm run check`，再运行 `node scripts/run_v7.mjs --mode=full --out=tmp/新的输出目录`。源文件、素材、包锁和实际渲染脚本会保存到输出目录的 `frozen`，同时生成 `source-lock.json`。

从 `frozen` 单独重现时，安装锁定依赖并使用 `--replay=true`。需可用的 Node.js、FFmpeg 和 Remotion 浏览器；不同显卡与编码器版本可能改变像素和文件哈希。重现不会自动覆盖交付文件或旧版标记。
