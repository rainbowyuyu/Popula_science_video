## 口播医学核对

| 内容 | 核对结论与限制 |
| --- | --- |
| 胰岛素与运动 | 肌肉GLUT4转位与收缩相关路线分开解释；胰岛素抵抗不等于胰岛素完全缺失，运动相关信号不画成取代全部胰岛素作用。运动综述只读可用摘要。 |
| GLP-1研究 | 口服与静脉葡萄糖比较建立在相近血糖水平；活性片段研究来自灌流大鼠胰腺，不能变成当代人用药物疗效实验。GLP-1促胰岛素强调血糖依赖性，研究到药物的工程示意不冒充原子动力学。 |
| LDL与他汀 | LDL是颗粒，LDL-C是其中胆固醇的测量，不把两者数量直接等同。肝脏脂蛋白的回收分支与逐步形成LDL均保留；LDL滞留发生在动脉内膜，非血管外壁贴油。 |
| 水钠、RAAS与交感 | 水和小分子滤液与血管内红细胞分路。RAAS由灌注不足等情境引入，不画成“盐越多循环RAAS必定越高”；交感功能联系不复用迷走神经冒充精确结构。 |
| 常见药物 | 他汀、CCB、ARB与噻嗪／噻嗪样利尿剂各解释相应环节；提醒肌肉症状、罕见严重警示、高钾、低钾等具体观察。无个人剂量、排名和自行联用指引。 |
| 血栓 | 血小板和凝血过程协同，口播用“同时”避免描述成完全独立的先后程序；抗血小板和抗凝有所区别，不等同降压，不演示溶解已有血块。 |
| 睡眠与CPAP | 打鼾、憋醒和困倦提示需考虑睡眠呼吸暂停，未把所有打鼾都确诊为缺氧；确诊阻塞性睡眠呼吸暂停后按需要使用正压支持。 |

## 数据与仿真的实际边界

BodyParts3D/Human Atlas来自参考解剖数据；外表姿态为教学变形。真实网格坐标、源ID和许可保留，局部教学几何不因放在器官上就成为该人体实测组织。气道、GLUT4、血栓、肾单位、脂蛋白与脂质滞留采用代表尺寸和机制动画，箭头／点状标记不承担分子实测尺寸。

`public/cardio/physics.json`保存两元0D Windkessel数值解，方程为`C dP/dt = Qin - (P-Pv)/R`。模型有给定入流、集中阻力与顺应性，未使用人体三维几何作网格；没有局部CFD、血管应力、波反射、自调节或患者预测。气道CPAP展示没有运行流体求解器。

5VAI是单一活化复合物实验结构坐标；兔受体、人GLP-1与混合物种G蛋白的来源不改称纯人源。分子档案数据CC0与原论文的版权／许可区分。人体数据CC BY 4.0、Human Atlas应用MIT、字体SIL OFL；早期音乐采样为CC0，当前Lemon Tree录音不在此许可内，完整署名见交付来源说明。
