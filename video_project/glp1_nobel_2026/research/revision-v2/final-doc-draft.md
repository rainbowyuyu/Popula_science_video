# V2 来源说明最终验收段落草稿

本文件仅供主流程在最终编码文件检查完成后填充并采用。它没有修改 `delivery/制作与来源.md`，也不构成 V2 已验收声明。所有 `【待填】` 必须由同一个最终 MP4 的实际记录替换；未完成的项目应保留为未完成，不能删掉后改写为通过。

## 可替换“验收记录入口”末尾临时段落的文字

以下记录对应最终交付文件 `【待填：相对路径】`：SHA256 `【待填】`，文件大小 `【待填】` 字节，编码后时长 `【待填】` 秒，画面 `【待填：分辨率】`，帧率 `【待填：ffprobe 返回值】`，实际解码/计数帧数 `【待填：值与方法】`。身份和技术参数见 `【待填：V2 最终技术检查 JSON 路径】`。不能用场景预期帧数代替编码文件测量。

本轮从该最终 MP4 提取了 `【待填：实际提取数量】` 张取样帧，覆盖 `【待填：时间或镜头范围、采样间隔及额外检查点】`；实际打开了 `【待填：接触表数量】` 张接触表与 `【待填：完整尺寸单帧数量】` 张单帧，已打开文件的明细和图像哈希见 `【待填：V2 视觉 QA 报告路径】`。具体结论为：`【待填：基于实际编码帧的字幕裁切、标签碰撞、遮挡、模型和数据读数检查结论；若有未决问题须保留】`。抽帧检查只覆盖被检查画面；它不能单独证明全片运动连续性、逐字字幕时序或主观听感。

声音检查以该编码文件解出的音轨为准。实测综合响度 `【待填：LUFS】`、真峰值 `【待填：dBTP】`；`【待填：其他确实执行的音轨/静音/失真检查及结果】`，见 `【待填：V2 音频 QA 路径】`。主观听审状态为 `【待填：实际播放并听过的时间范围与结论，或明确“未完成”】`。没有播放听审时，不使用“全片听审通过”或“旁白全程清晰”的措辞。

四种比例封面的静态原文件和 160、320、640 像素接触表已另行打开检查。主标题在 160、320 像素缩图中仍可辨认，未观察到标题、品牌与模型的碰撞；160 像素时品牌和栏目小字不保证逐字清晰。封面文件哈希、实际打开范围和工具缩放限制见 `delivery/covers/layout-report.json` 与 `research/revision-v2/covers-review.md`。如果封面随后重新生成，该结论须由新哈希的实际检查更新。

V1 的 `research/qa/final/` 仅对应旧版文件；V2 场景 still 和预览审查仅是制作过程的证据，均不替代本轮最终编码文件检查。论文页面、素材许可与可编辑工程随项目保留。

## 根据真实状态选择的结尾

- 只有必要检查全部完成且无未决阻塞问题时，可写：“在上述实际检查范围内，未发现阻塞交付的问题；验收边界与剩余限制已在报告中列明。”
- 如果存在缺项，应具体写：“已完成【实际完成项目】，仍未完成【缺项】，因此本记录不声明完整终片验收通过。”
- 若播放听审未完成，而技术测量已完成，应直接保留“未完成主观听审”；不能把响度测量等同于听感验收。
