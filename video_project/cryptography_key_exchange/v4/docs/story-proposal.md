# V3：没约过密码，消息怎么保密？

本轮重写围绕一张生日蛋糕订单。观众只需一直认出手机、订单、商家和中间的通路；没有夜城信使、金色轮子、模幂算式或需要记住的算法目录。冻结稿以 `src/story.json` 为准，`research/story-candidate.json` 留存首轮候选，不作为渲染入口。

## 故事的因果链

你在咖啡店给妈妈订蛋糕，备注“送到幸福路八号，别按门铃，我下来拿”。地址经过别人管理的路由器：怎样让它运送秘密，又看不懂秘密？先看到加密后的结果，再提出真正的难题——手机和网站从没约过密码，秘密从哪里来？一段逐步混色演示解释“各留一份私人材料，交换公开结果，再各自得到共同秘密”。之后补上“认准网站”和“改动就拒收”，最后订单送达，门铃没响，开场的生日惊喜得以保留。

冻结稿为 34 个 cue、1269 个汉字。以个人音色实际语速约 4.64 汉字/秒估计，旁白约 273 秒，留出自然停顿、动作观察与片尾，目标约五分钟；最终长度由真实 TTS 句长决定。

| 场景 | 观众此刻的问题 | 可见的动作 | 必须得到的答案 |
|---|---|---|---|
| opening | 地址会被别人看见吗？ | 输入一张具体订单；手机、路由器、网站建立空间关系 | 公共线路与私密内容之间存在矛盾 |
| encrypt | 为什么别人看不懂？ | 原文变为真实密文字节，两端能恢复，途中只能见密文 | 密钥控制还原过程 |
| exchange | 没约过密码，钥匙哪来？ | 黄→各藏红蓝→混色→交换→再加本地私色→同色 | 共同秘密可在两端分别产生，不必直接发送 |
| auth | 对面会不会冒名？ | 网址/证书/私钥签名相互核对，假证书副本不能签名 | 公开协商还需要认证，普通 HTTPS 通常认证服务器 |
| delivery | 看不懂的人能乱改吗？ | 密文字节 63→62；原包恢复，改包拒收 | 核验标记依赖密钥，篡改会导致验证失败 |
| ending | 生活中保护到哪？ | 加密订单到网站端解开；回到生日备注 | 保护的是传输这一段，网站仍能读订单 |

## 把动作留给眼睛

混色段只做一件事：解释双方为何能得到同一个结果。手机固定左侧、网站固定右侧，公共路径居中；私人红瓶和蓝瓶始终留在各自端。s14/s15只挑选私人颜色，s16才混色。s17交换的是混色杯，s19/s20分别加入本地私色，s21保留两只杯并排比较，至少停留一秒。颜色顺序改变，份额与材料不改变，最终同色。

不要把三个彩色方块摆出来就认为完成了演示。要看见瓶口、液面、流束与杯子接触的因果关系；颜色改变跟随流束到达，而不是随机闪光。每一步结束都让观众有短暂确认时间。相机可以弧线滑移，但关键步骤不能绕到左右角色互换，也不能裁掉尚需比较的另一只杯。

真实颜色可被估算或分解，颜色并不能证明安全。s23明确说“颜色只帮我们看懂步骤”；真正的密码运算依赖数学困难问题。不得增加“颜料绝对拆不回去”的旁白或画面。

## 独立审查结果

- 因果顺序完整：生活疑问→先看加密结果→钥匙配送矛盾→共同秘密→认证→篡改拒收→生活回收。
- 公共无线网场景使用“要是有人能截住”，不声称任意邻桌设备必然能够窃听。
- 普通 HTTPS 不是聊天端到端加密；结尾明确网站能读订单。为避免开新课堂，最终稿不再展开端到端分支。
- 没把 RSA 加密送密钥当成 TLS 1.3；混色只展示 DH 类结构，真实本地实验用 X25519、HKDF 和 AES-GCM。
- “确认彼此”已修为“手机认准网站”，避免把普通服务器认证讲成必需的双向客户证书认证。
- 认证密钥和加密会话密钥功能不同，画面不能把证书里的公钥直接变成那把共用加密钥匙。
- 篡改实验改的是密文字节，不可演成“看不懂却精确把地址八号改九号”，这不是本实验所证明的效果。
- 未做真实零基础观众测试；本项为独立编辑与科学核对，不能称观众理解率验证。

## 配音与屏幕文字

口播全部使用中文术语；不读 RFC、TLS、HKDF 等缩写。显示稿与实际口播稿分别留存，当前不需要同音字辅助。每次屏显只承担一个作用：网址、黄/红/蓝、密文、共同秘密、校验失败。字幕不承担算法解释全文以外的新负担。屏幕上的实例数字必须取自 `research/order-crypto-evidence.json`。

## 参考如何落地

实际访问与范围详见 `research/story-sources.md`。How HTTPS Works 提供了“同一消息遭遇偷看、冒名、篡改”的连续例子；Khan Academy 的混色段显示角色位置稳定、公共与私有物料分开能降低理解负担，其评论区也暴露“为什么最后同色”“旁观者为什么不能自己凑”的常见疑惑。本片用更长的逐步同屏操作回答第一个问题，用明确类比边界避免把第二个问题错误归结为真实颜料不可逆。
