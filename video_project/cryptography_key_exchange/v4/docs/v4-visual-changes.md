# 密码学 V4 画面修订

本次基于 V3 保留的生日蛋糕订单故事修订，没有改动 V3 成片和工程。主要针对用户指出的纸张、文字、阴影、连线与旁白问题。

## 画面

- 原厚圆角板替换为轻卷角薄纸，固定种子的细纸纹、纸边和粗糙漫反射。订单、旁观抄件、网站证书、篡改核验单均使用同一印刷系统。
- 纸内使用 Noto Serif SC，字幕与设备标签使用 Noto Sans SC；真实字节用等宽字体。字体为本机已安装的 OFL 字体，按实际影片字符制作 WOFF2 子集，随恢复包附许可证。纹理生成前等待字体加载。
- 标题、字幕和物体标签分区；开场三个设备标签移到各自设备前方。纸内认证标记放大。片尾订单先平滑离开画面右侧，再露出蛋糕；不再让相机回程把正文切掉。
- 网络线路减细，减少重复外管；进入颜料类比前沿路收回，身份验证完成后重新延伸。混色期间不再横穿杯子、瓶子或文字。
- 杯托重做浅凹曲面，杯子、颜料瓶、样品盘沿桌面两侧出画，结果芯片在对应两端接力；公开瓶和样品盘不再退到标题背后。
- 采用更高的棚光位置、VSM 过滤软阴影、较低阴影强度；透明文字和玻璃层不参加阴影投射。桌面减弱木纹对比，芯片引脚与焊盘使用金属反射。

## 连续帧发现与修复

在新纸张代表帧检查后又渲染了连续退场片段，发现物体移动而阴影仍停在旧位置。根因在 ThreeCanvas/渲染器阴影状态没有逐帧明确更新。已在 ThreeCanvas 声明 VSM 动态阴影，并在每个绝对帧更新时刷新阴影贴图。

修复后顺序渲染第 5770 帧与直接定位静帧做比较，平均像素绝对差约 1.77/255（两个 JPEG/H.264 编码路径不同）。实际查看末帧，杯托、样品盘、颜料瓶原位置没有残影。该比较只验证帧序相关的渲染回归，不代替美感判断。

## 声画对应

- s26 冒名证书退出改为新旁白的“拿不到”词锚点，避免提前拒绝。
- s31 按“恢复订单”“报错”的实际音频锚点出现两个实验结果；讲到失败时左侧纸面同步显示改动字节和拒收结果。
- 34 句新版语音与 126 条字幕采用真实时长；所有关键动作读取同一份词级事件时间线。

## 检查边界

已实际查看首轮 7 张纸张/阴影图、第二轮材质/退场图、全片 33 张代表画面及开场标签/实验结果的修正帧。另导出连续退场片段并在浏览器播放抽查，检查结果与完整最终编码的验收分开记录。

不把自动相机平滑检查、ASR 或抽帧记录写成连续全片主观观看/听审通过。最终文件编码、同步、响度和编码后图像的记录见 work/qa 与交付说明。

## 最终退场路线精修

编码抽帧放大后，进一步修复 s22 杯子横移时被服务器切入的画面。杯、杯托和私色瓶先移到设备前方，再沿两侧滑出；公开瓶与样本盘采用分离的前景路线。两端标签和“路上可见”标签在位移前轻收起，避免标签挤在手机侧。芯片保持原位接力。最终路线静帧 f5529/5559/5589/5619/5649/5700 已分别打开检查；最终 MP4 使用这版源码重新完整编码。
