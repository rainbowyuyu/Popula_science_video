# 密码学V3：一张生日订单

用户否决V2的粗糙模型及听不懂的叙事，本轮重写故事、配音、场景、材质和相机。

主线：咖啡店中下生日蛋糕订单，手机号/地址经过路由器为何不被读懂。一个订单贯穿手机、线路、商家服务器；先看明文与密文，再用颜色混合解释协商共同秘密，随后核对身份与防改动，回到订单。

画面：日光产品摄影，奶油灰背景、墨蓝设备与青绿强调；精细Blender手机/路由器/咖啡桌，Three.js连续机制演示。固定世界中移动相机，主体靠近且能读懂，不重用暗夜金轮装置。

分工：root负责入口、场景、相机、排字与渲染；story负责研究/候选稿；assets负责模型/贴图；audio负责TTS/混音。所有修改仅在v3，v2保留回退。node_modules只读继承DNA依赖，禁止穿越连接删除。

检查：先代表镜头→相邻短片→全片；故事逐句画面映射、模型材质/阴影、清晰度、关键文字、连续转场、实际音频长度、最终编码分别验收。技术通过不冒充全片主观听审。
