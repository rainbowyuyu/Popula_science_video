# 密码学 V4 纸张质感只读审查

日期：2026-10-15。范围：已交付 `delivery/密码学_没约过密码消息怎么保密_V4_1080p.mp4`，并交叉阅读 `World.ts`、`Film.tsx`、`Mixing.ts`、`Paper.ts`、`Design.ts`、`DocumentPrint.ts`、时间线和词事件。此次直接抽取并查看 20 张旧版成片画面，其中 39.000、47.400、210.200 秒另作 1920×1080 放大检查；这不是全片实时播放认证。

用户参考图的有效特征是薄的暖白哑光纸、细小自然弧面、清楚而克制的深青印刷、细金线，以及与纸的高度/曲率一致的柔和投影。参考图中的长条比例和版式不宜生硬套到全部证书；应统一纸材，再适配各自信息结构。

## 旧版实际观察

1. **主要问题是“正对镜头的平面信息板感”，并非厚塑料板。** 39 秒左右两张订单/抄件没有可读的表面细节。纸面整体亮度几乎一致，长边与屏幕边缘接近平行，只有顶部很小的起伏。`poseCard()` 全量复制相机四元数，导致即使相机运动也持续正视纸，难以表现参考图的斜视角与薄边。
2. **旧纸面略灰白、印刷十分均匀。** 纸本身已经是暖白，不能简单加黄或加粗噪点。应增强低频微弧面随光照的柔和变化，增加非常弱的纸纤维与哑光粗糙度，让高光宽而不发塑料光。现有 1200 像素纹理中大量小于 1.5 像素的随机点在成片缩放后几乎看不到，单纯提高点数不会获得明显纸感。
3. **翻面比正面更暴露造型。** 47.400 秒能清楚看到翻转纸的无印刷背面和弯曲边缘；它不是厚板，但大块纯色显得空。背面也应有同一纸纤维和细微色差，正反面轮廓应完全一致，不能在换面帧突然跳曲率或颜色。无需把正面文字镜像透过背面。
4. **投影已经比硬黑矩形柔和，但与“摆拍纸张”参考仍有距离。** 多数卡纸被举在空中，因此在桌面的影子离纸很远，不应假装成贴地接触阴影。若只升级材质，仍保留现有悬空示意的空间逻辑；可用轻微角度和起伏改善体积感，切勿绘制不随物体运动的黑色贴片。
5. **证书是全片最大的纸张验收点。** 210.2 秒中心证书可读，但仍是近乎均匀的白板。未勾选的行在旧版相当浅，升级后不能因纸色/透光继续损失识读。证书文字必须全部留在纸印刷层，底面纹理应在动态换图后保留。
6. **篡改/复原成对纸张需要一致纸材。** 249–268 秒有不同大小、不同明文/密文状态；原纸和校验单不应一张偏灰、一张偏黄，且动态更换 map 后不能退回旧纸底。红色拒收状态仍需突出。
7. **片尾有另一条渲染链。** `Film.tsx` 目前将真实论文 PNG 作为平面 DOM 图片，后面是一块纯色矩形；它不经过 `Paper.ts`。若不单独修改，片尾不会获得新纸感。应保持论文内容原样和图像占满纸页，通过细薄纸边、适量纤维合成与柔和分层投影统一，不要把真实论文重新生成成假文字。
8. **颜料瓶上的三张文字标签是另一种“纸制表面”。** `Mixing.ts` 的手机、店家、公开标签当前为平面底色 + `MeshBasicMaterial`；它们不应被做成悬空卷页，但可统一暖白哑光贴纸底。液体、签名圆章、芯片及浮空注释标签不属于纸张，不必强套纸材。

## 对实施者的具体建议

- 先统一 `Paper.ts` 的正面/背面 stock 与 geometry，再统一印刷的留白、深青墨、细金线；所有动态生成函数必须从同一个 `paperTexture` 底层输出。
- 不改 cipher 真实字节 `63 D8 BB 45 / 1E 30 7F 02`、认证前缀 `AD 23 EC 4E`、篡改 `63 → 62`、域名和证书意义。
- `children[1].material.map` 是现有动态换图契约，纸材实现时保持索引或显式改为命名查找；否则证书、抄件、拒收单会出错。
- 保持纸张清楚可读，只在 `poseCard` 中加入幅度有限、帧驱动的偏航/俯仰/滚转或稳定倾角，避免一直 billboard，也避免把全部卡片改成大角度桌面俯视。纸印刷表面最好保留接近漫反射的视觉，不加清漆强光。
- 纸张高于桌面时保留真正的投影。纸边和纸面不能互相投出深黑“自遮阴”条带；粗糙度/凹凸强度要受控，不能出现刷墙或牛皮纸纹理。
- 片尾单独处理，保持真实论文图像，所有阴影方向与同页其它元素一致。
- 升级验收除了代表帧，还要完成既有 `npm run check` 和该项目运动/投影检查；不需要改旁白、音乐或时间线。

本审查未更改视频源代码、音频或成片，只新增本报告及旧版对照图片。
