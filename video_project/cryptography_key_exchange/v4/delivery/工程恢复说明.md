# 密码学 V4 工程恢复说明

本工程对应《没约过密码，消息怎么保密？》，实际时间线为 305.100 秒、9153 帧、1920×1080、30fps。

## 使用已经完成的声音重渲染

解压到独立目录，安装 Node.js，并保证 ffmpeg 可在命令行调用，然后在工程目录执行：

```powershell
npm ci
npm run check
npm run stills
npm run render
```

首次渲染可能下载 Remotion 所需的 Chromium。渲染默认使用 Vulkan；设备不支持时可尝试 `node scripts/render.mjs --audio --gl=angle`，并重新检查透明材质、阴影和最终画面。

本包保留合成母带 `public/audio/master.wav`、独立旁白 `public/audio/narration.wav`、逐句原声和处理后音频。直接重渲染无需重新调用 TTS，也无需另找背景音乐原文件。

字幕、解说稿与 `src/story.json` / `src/narration.json` 对应；`文本交付核对.json` 记录了来源和输出哈希。公开稿使用“密钥”；同音朗读控制只保存在专用声音输入中。

## 修改文案或模型

改稿后应重新合成变更的整句，根据实际录音时长重建字幕、词锚点和镜头时间。TTS 脚本默认使用用户本机 `D:/python_project/tts`；私人参考声音和模型权重没有打入本包。外部环境路径需在迁移后按自己的位置配置。

Blender 模型和生成脚本均保留。已有 GLB 可直接用于渲染；重新生成模型需要 Blender，原环境位置为 `D:/blender/blender.exe`。两套字体与 OFL 许可位于 `public/fonts/`。

## 核对范围

最终验收报告位于 `work/qa/`。工程恢复包仅在最终成片格式、全文件解码、抽样音画同步、数值镜头检查和代表画面检查均完成后生成。

ZIP 旁的 `.sha256`、`.inventory.json`、`.verification.json` 记录整包及每个文件的校验值。打包程序会实际读回全部 ZIP 内容验证 CRC 和 SHA-256，并把解压源码执行一次 TypeScript 检查；该检查使用当前已安装的依赖，不等同于全新设备上的 npm 安装测试。

发音语境片段和等响度原声/轻处理 A/B 位于 `work/audio/pronunciation-evidence/` 与 `work/audio/ab-previews/`。自动转写和响度指标只能辅助复核；没有以它们代替主观听审。

旧稿、旧配音、node_modules、构建缓存、私密配置、外部服务日志和原始背景音乐录音均不收录。包内母带保留了本片所用音乐；公开发行许可仍应按原音乐权利情况处理。
