# 密码学 V4 · 制作与检查说明

影片：《没约过密码，消息怎么保密？》。故事从咖啡店给妈妈订生日蛋糕开始，跟随同一张订单解释加密、公开交换、身份核验和篡改拒收。

## 本次修订

- 使用用户本地 rainbow鱼 参考音色重新生成34句。密钥按用户要求使用 mì yào 的专用朗读输入；字幕、纸面与标准讲稿保持“密钥”。重新组织口语句式、停顿和126条语义字幕，每条最多22字。
- 订单、旁观抄件、证书与核验单改为薄纸，带轻卷角、纸边与细纸纹；纸内宋体，标题和字幕黑体，字节使用等宽字体。字体在生成纹理前加载，随工程保留OFL许可证。
- 提高主光位置，使用软阴影；文字透明层不投影。修复道具离开后阴影冻结的问题，木纹、陶瓷和金属反射重新平衡。
- 简化网络连线，混色解释时沿原路线收起。颜料杯退出时先走到设备前方，再滑向两侧；标签提前收起，避免杯子切入服务器及标签拥挤。芯片保持在同一端点接力。
- 身份卡的退出与“拿不到”对应；实际实验结果同屏呈现“篡改件→拒收”和“完整订单→恢复”。订单出画后蛋糕完整露出。
- 保留用户指定《Claude小曲2.0(Remix版)》，按乐句衔接循环，讲话时平滑降低音乐。未对人声强制加速或变调。

## 可核对的机制

教学实验实际运行 X25519 → HKDF-SHA256 → AES-256-GCM。显示的密文字节前缀、认证标记和63→62的单比特篡改来自保存结果。完整密文能还原原订单；篡改触发InvalidTag，不返回错误地址。颜色是步骤类比，影片没有把颜料混合作为真实加密，也不等同于完整TLS实现。

最终格式、文件哈希与数值结果见本段交付时追加的记录，以及 work/qa/encoded-final.json、av-sync.json、motion.json、visual-final.json。素材、模型、音频和来源台账保留在工程中。

旧版V3成片与恢复包保留。完成校验后只清理本片可重建缓存和退役中间文件，清理记录另列。共享node_modules连接和其他影片不在清理范围内。
