# 《让小偷送秘密》工程恢复说明

本片为 rainbow鱼「每天5分钟科普」密码学篇，1920×1080、30fps、9129帧，时长304.3秒。以一封交给不可信信使的信为线索，解释共同秘密、身份验证与认证加密。

恢复包包含源码、冻结的声音母带、模型、逐句配音和资料。**不改讲稿时，恢复渲染不需要TTS服务、私人参考音色、外部API或原始背景音乐文件。** `public/audio/master.wav` 已经包含本片配音和音乐；渲染脚本先输出画面，再把该母带封装进成片。

## 在独立新目录中恢复

1. 解压ZIP，进入其中的 `密码学_让小偷送秘密_工程` 文件夹。使用新的目录，避免影响现有工程的依赖连接。
2. 安装Node.js和FFmpeg。本片制作时使用Node.js **24.15.0**；`ffmpeg`、`ffprobe`需在PATH中。
3. 在工程目录用PowerShell执行：

```powershell
npm ci
npm run check
npm run stills
npm run render
```

依赖按 `package-lock.json` 安装。Remotion首次渲染可能需要下载Chrome Headless Shell；因此首次安装/浏览器准备需要网络，日后已有缓存时不依赖生成服务。默认使用Vulkan；如果新机器不支持，可以使用：

```powershell
node scripts/render.mjs --audio --gl=angle
```

画面输出为 `delivery/密码学_让小偷送秘密_1080p.mp4`。如只需检查一段，必须给独立输出文件名，避免覆盖全片：

```powershell
node scripts/render.mjs --frames=0-299 --output=delivery/开场检查.mp4
```

局部检查命令只输出画面；完整 `npm run render` 会自动配入冻结母带。`node_modules`、浏览器缓存和渲染bundle没有打包；这些内容由安装和渲染重建。

## 修改范围与依赖

修改镜头、灯光、文字位置和Three.js模型，可以继续使用现有母带。修改解说内容或语速时，需要重新生成对应整句，随后重建时间线、字幕、母带并复核音画同步；原有32句不能靠硬截断凑时长。

本地TTS工程默认在 `D:/python_project/tts`，私人参考音色和模型权重没有打包。仅在确实要重录时再读取该工程的 `RAINBOW_AUDIO_WORKFLOW.md` 等说明。背景音乐的原录音也没有重复打包；当前母带足够重新导出，若要重新编曲则需用户原文件。

若要重建Blender资产，当前机器使用：

```powershell
& 'D:/blender/blender.exe' --background --factory-startup --python scripts/build_night_city.py
```

现有GLB即可正常渲染，常规改字幕或运镜不需要启动Blender。模型是原创程序化夜城与Three.js教学示意；没有使用Lux3D、WaterPro或真实高斯扫描资产。Claude Opus组件调用尝试超时，partial没有进入成片代码。

## 验证

`npm run check`进行类型检查。运镜数值检查：

```powershell
node scripts/qa_motion.mjs
```

最终MP4完成后，可使用Python运行以下只读核验；`qa_av_sync.py`另需numpy、scipy与soundfile：

```powershell
python scripts/qa_final.py
python scripts/qa_av_sync.py
```

核验包括全片解码、9129帧与304.3秒、黑场/长静音、响度、真峰值，以及五个窗口的AAC与母带对齐。数值通过不等于替代完整主观审片。包内原始QA结果对应原交付文件；在新机器重新渲染后应重新运行。

论文页来自Diffie与Hellman（1976），协议依据为RFC 8446。小数字DH只是教学例；本地X25519→HKDF-SHA256→AES-256-GCM实验使用公开的固定教学输入，不能当作真实业务密钥。真实计算与艺术化机械示意见 `research/story-sources.md`。

## 恢复包的生成方式

打包脚本只收录明确的工程文件，不遍历根仓库、不跟随junction/symlink，不打包视频、node_modules、bundle、原始私人音色、外部模型权重、API凭据和服务调用scratch。它也不执行清理。

只读查看文件数量与大小估计：

```powershell
python scripts/package_delivery.py --plan
```

仅在最终成片QA通过后创建：

```powershell
python scripts/package_delivery.py --create
```

脚本要求 `encoded-final.json`、`av-sync.json` 和 `motion.json` 通过，并核对成片、母带和当前运镜文件哈希。ZIP创建后重新完整读取每个文件，核验CRC、大小和SHA-256；通过后才将临时包改为正式ZIP。旁边同时生成 `.sha256`、`.inventory.json` 和 `.verification.json`。已有输出不会覆盖，需要更换 `--output` 文件名。


## 渲染器恢复说明

工程包不包含浏览器二进制。首次渲染若找不到Remotion缓存中的Chrome Headless Shell，脚本会调用Remotion官方ensureBrowser下载对应浏览器；需要联网。当前Windows机器已有缓存。其它系统若不支持Vulkan，可用`node scripts/render.mjs --audio --gl=angle`并重新检查实际帧。字体使用Windows微软雅黑；跨系统需安装合法可用的中文字体并重新核对换行。
