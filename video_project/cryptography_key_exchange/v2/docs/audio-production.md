## 恢复与复现

源稿、所有raw/clean句源、处理JSON、模型参数、hash、种子、原曲路径与SHA必须保留；个人参考音色继续留在原TTS工程。完整环境版本在 `work/audio/environment.json`。
先运行 `voice_generate.py --plan` 校验缓存；无改稿应显示0待生成。需要重录时只重录相应整句，再按新实际时长重建时间线。当前冻结母带不要直接覆盖。

在本片目录使用 `D:/python_project/tts/.venv/Scripts/python.exe` 执行：

```text
scripts/voice_generate.py --plan
scripts/audio_prepare.py
scripts/asr_verify.py
scripts/audio_qa.py
scripts/mix_master.py
scripts/voice_delivery.py
```

最终视频存在并完成封装后，两个只读核验脚本默认使用 `delivery/密码学_让小偷送秘密_1080p.mp4`：

```text
scripts/qa_final.py
scripts/qa_av_sync.py
```

`qa_final.py`完整顺序解码并以小块读取文件哈希；`qa_av_sync.py`只读取五段共40秒AAC，与母带相关性对齐，容许偏移不超过1帧。两者不修改成片、母带或视觉源码。

两套QA还会独立锁定V2的304.3秒、9129帧、14,606,400样本。完整解码脚本检查实际解出的帧数、H.264/8-bit 4:2:0（含全范围yuvj420p）、AAC/48kHz/立体声、首帧时间戳和解码错误；同步脚本先用SHA-256确认待比较的母带仍是冻结版本，避免拿错误母带做出误导性的通过结果。

最终导出使用 `scripts/render.mjs --audio`。该入口先生成完整视频，再明确映射视频流与 `public/audio/master.wav`，以视频流复制方式封装、AAC 256 kb/s，时长取组合的9129/30秒。没有 `--audio` 的渲染不能直接视为完成交付；音频QA会拒绝缺少AAC或时长不符的输出。源曲只在混音阶段使用，最终不会重复混入第二条背景音乐。

开场与两个循环口试听在 `work/audio/preview-*.mp3`，4组等响度raw/clean对照在 `work/audio/ab-previews/`。
