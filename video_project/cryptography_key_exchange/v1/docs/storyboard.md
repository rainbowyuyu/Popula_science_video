## 镜头接力

- hook→exchange：手机订单卡沿线路折叠成盒子，拍摄方向不断。
- exchange→mixing：钥匙的圆孔遮挡接到公共颜料杯的杯口，同一桌面。
- mixing→math：杯口变成23刻度环，液滴变为余数珠；颜色逐步由直觉回归精确数字。
- math→attack：相机跟随公开8或19到线路中央，攻击分线器从画外进入。
- attack→auth：改过的消息直接抵达检查口；签名封印绑定本次传话。
- auth→encryption：通过身份验证的同一线路携订单回到手机端加密，派生机制只展示一遍。
- encryption→coda：恢复出来的“蛋糕少放糖”贴回开场手机，拉回咖啡桌，蛋糕灯光升起，原始论文和公式从桌边进场。

科学校对：mod环是乘法取余；色彩仅交换流程类比；23是可破解教学例；共享秘密须派生；签名身份私钥不同于会话密钥；认证标签检查失败要拒绝，不能画成自动恢复。
