## 运镜与接力

- `Camera.ts`的Hermite插值使位置与target在键点保持一阶连续，这比逐段硬切好；但每个新场景的关键点在`g.start+1.8`，约4.2秒的横向24单位转场与新旁白前1.8秒重叠。新物体常在讲解开始后才进入中心，需让新场景第一个明确动作等相机进入可读范围后再发生，或把位移提前到上一句末尾。
- `World.render`把`traveler`永远放在`pose.target.x-0.9`。它跟着摄影机目标跑，却没有实际接入任何场景订单/公开值/结果；这只是“镜头挂件”，不能证明连续数据旅程。建议改为真实包在相邻站点之间走同一曲线，并在站点物体遮挡处交接。
- 独立台座间距24，镜头都以z约13–19、fov40观看，过渡中间容易有几秒只见轨道、两侧主体都在边缘。应抽取全部边界前后90帧，重点看mixing→math与math→attack；可在过渡时后退略抬高或沿前景杯壁遮挡，而不是增加光点填空。
- `g.visible = abs(g.x-target.x)<42`是硬卸载阈值。正常直视下大概率在视野外，但需以实际相机视锥检查，特别是转向/模型阴影；不能单凭距离就称“不会突然消失”。
- 数学段目前约103秒，除c12/c13几次标记变化之外长时间几乎同构。修复c11、c15/16、c17、c20四个机制动作，比再加装饰性环绕更能改善观看。

## 已核查为合理的部分

- `aValues`、`bValues`中5的模23余数序列正确。
- 公共值5/23、8/19、私数6/15、共享2一致；Shared keys留在两端，没有被画成直接通过中线寄送。
- 混色两端最终被设置为相同终色，口播明确混色只是类比；不能在说明中把本实现称为颜料物理仿真。
- 所有运动由输入秒数及固定粒子种子控制，没有实际时钟和未固定随机源。
- 末尾“网站是否骗人需要另外判断”在脚本中保留，避免把证书当商业可信保证。
