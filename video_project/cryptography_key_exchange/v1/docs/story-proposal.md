# 密码学 · 连别人也能听见的悄悄话

主标题建议：**当着所有人的面，怎么商量一个秘密？**

封面短题：**全程被偷听 / 秘密怎么守住？**

一句话主线：在咖啡店给爸爸订生日蛋糕，浏览器与网站先公开约定秘密，再核实对方身份，最后才把订单交给一条既保密又能察觉修改的连接。

受众只需理解三件事：双方各自保留一点秘密；公开交换加工后的结果能得到同一个秘密；想防冒充，还要验证身份。全片用同一条从手机到蛋糕店的线路，不变成密码学名词目录。

| 11 | clock | 比如二十五除以二十三，余数是二。这个只留下余数的动作，叫取模。接下来每一步，都用同样的规则。 | 25 个珠子绕环，一整圈进入后景，余下2落点高亮；公式“25 mod 23 = 2”。 |

## 导演与科学校对要点

- 颜色杯只讲交换顺序和同结果，不把真实颜料的分离难度当密码安全证明。相同配方、相同质量权重才能收敛同色；勿分别对不同液体重复取均值造成视觉颜色不等。
- 第17句建议最终口播改成更精确的“先算五的十五次方，再做六次方；另一边次序颠倒。指数相乘，都是九十”。“乘十五层”虽通俗但容易把幂与乘法混淆，不建议原样配音。
- 23格圆盘用来解释取余，5^a 的运动是乘法取余序列，不能画成每轮加5。
- 私数6/15只存在端点；共享2从未穿过中间轨道。取余不等于单独保障安全，小参数实际穷举一次，承认其可破。
- 正向易反向难是解释框架；不声称数学证明永不可破解，不承诺没有参数、实现、侧信道风险。生产采用标准结构与实现。
- 中间人是主动替换，并非纯偷听自动获得密钥。证书与签名建立网站身份验证；证书不证明网站商业诚信。
- 协商材料要经过KDF得到对称加密密钥。身份签名用的长期私钥和会话交换私数、会话对称密钥使用不同形状。
- 第35句只有真实计算并保存结果后才可使用。教学脚本不能被当作可部署安全协议；应用实验标明机制演示。
- 片尾论文页直接截取已下载的 Diffie–Hellman 1976 原文；标题作者年份放纸外。RFC 8446可作为真实规范页；不要伪造学术论文外观。
