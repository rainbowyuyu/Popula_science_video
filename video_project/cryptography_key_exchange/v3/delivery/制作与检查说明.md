# V3 制作与查看说明

标题：没约过密码，消息怎么保密？

时长 5分00.5秒，1920×1080，30fps。故事从给妈妈订生日蛋糕出发，沿同一份订单讲清三件事：两端如何约定秘密、浏览器如何认准网站、传输内容被修改后如何被拒收。

## 本轮重做

- 重新写作34句口播，用用户本地TTS音色生成；90条字幕依据实际句源排版。
- Blender重建手机、路由器、服务器、杯具、木桌和蛋糕，使用真实白橡木PBR贴图和柔和日光环境。
- Three.js保持同一张桌面和两端角色；透视相机使用时间参数Hermite轨迹。混色、交换和拒收按实际语音动作词触发。
- 颜色仅用于解释协商步骤；最终数学系统与颜料不可混同。身份私钥与会话密钥分别用金色、青色表示。
- 真实执行X25519、HKDF和AES-GCM小实验，验证原订单恢复以及修改1位后拒收。画面只展示字节和认证标签的短节选，不是一套完整TLS实现。
- 指定音乐保留原曲，以乐句交叉衔接，按实际旁白做平滑避让。

## 工具实际使用

采用Blender、Three.js、Remotion、本地个人Qwen3 TTS以及Claude Opus原生组件协作。PigmentCup组件经审阅、颜色收敛和连续性修复后实际用于成片；未使用Qwen生成视频、Lux3D付费模型、WaterPro商业源码或真实高斯扫描。

## 检查边界

技术检查、抽帧观察、连续短片播放及主观听审分别记录在QA文件中。自动ASR核对不能代替完整的主观听审，正常播放成功也不能视为逐帧人工验收。详细结果随最终编码更新。

## 恢复制作

1. 解包工程，用锁文件安装Node依赖：npm ci。
2. npm run check；npm run stills；npm run render。
3. 音频母带已包含在工程，无须个人参考音色即可重新渲染。重新合成个人音色则需原机器的D:/python_project/tts与本人参考声源，包内不含该声源。
4. Blender建模源文件和脚本保留。纹理来源、哈希与许可在docs/models-textures.json；科学资料在research/story-sources.md。
5. V2旧交付保持原位作为回退，本轮不清理其他项目或共享依赖。

## 最终检查结果

- 完整解码9015帧，300.5秒，1080p30；无检测到的0.2秒以上黑场或1秒以上静音。
- 最终AAC为−16.05 LUFS、−1.41 dBTP；五个窗口共40秒与母带0偏移。
- 查看最终编码108个关键/接点帧、9张联系表，回修了密文卡突然返回、拒收卡再露出、结尾订单卡突然消失以及签印字体。
- 运动数值检查通过；仍未完成整片不间断主观观看与主观听审，不将抽帧/ASR写成该类验收。
