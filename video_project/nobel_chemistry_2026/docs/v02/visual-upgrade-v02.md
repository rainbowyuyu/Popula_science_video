# V02 机制动画升级与工程范围

全部改动隔离在 `src/chemistry2026v02/`，没有修改 V01、旁白源或时间线。`WorldV02.ts` 根据字词时间提取语义节点，不用姓名长度估算画面时间。

## 实际新增的解释动作

- 镜像：保留 V01 经审计的乳酸四面体、镜像及正确刚体旋转。在两方向对齐时，用同一原子投影坐标标出不能同时重合的 CH₃ / COOH 接点。
- Frank：前体沿轨道进入后生成左右产物；同类促进后续生成，异类组合通路减弱。
- 新增 catalyst：同一反应起点终点的两条能垒路径；催化中心完成一轮后保持存在；摄影机靠近配体环境，显示两条生成通路。没有编造速率或能量数值。
- Kagan：36 个配体标记表示大池中的 75%/25%；从池中抽取示例配体连续配位为 RR/RS/SS，分别呈现精确随机配对概率 56.25%/37.5%/6.25%。示例三组不是把有限四分子不放回配对。
- 非线性：16 个等权概率组合单元中，6 个 RS 失活；9 个 RR 和 1 个 SS 连续移入有效池。按口播显示配体 ee 50%、产物 ee 80%，最后显示 `y=2x/(1+x²)` 与 `y=x` 的位置关系。x 轴明确为起始配体 ee。
- Soai：真实 1,3-二氮嘧啶环在 C5 连醛；原羰基中心从平面过渡到正四面体连接方向。O / O–Zn–i-Pr / 水处理后的 OH 分阶段呈现。保留锌醇盐实体分支进入回路，游离醇不作为原位催化物回流。
- 自催化：每一批前体抵达转化点后才出现新产物；新产物沿连续轨道进入同一反应体系并保留。图符表示物质的叙事位置，不是测得的分子轨迹或速率。
- 独立试验：固定 37 瓶按 18 R / 19 S 显现；与预设极低偏差试验分开。
- 三轮放大：每轮补料后呈现 57%、99%、>99.5%；起点的粗粒度图符保持 12:12，精确条按 50.000025% / 49.999975% 绘制，避免放大初始肉眼偏差。
- 所有有机锌反应容器改为封口容器示意，不画开放水杯。

配体图符有四个不同颜色和大小的端点、固定镜像反射与深度排序；整体金/青色代表类别。它是解释配位组合的抽象图符，不是某个真实配体结构或经 CIP 规则计算的构型命名。正式乳酸镜像保留真实基团和化学键。

## 验证与后续复核

`node scripts/audit_visuals_v02.mjs` 调用实际场景代码，在父层 alpha 为 0、0.25、1 时检查有效透明度、有限坐标、save/restore 与父状态恢复；覆盖 23 阶段、14 场景。另检验精确比例、初始计数、37 次结果和乳酸镜像不变量、反应产物四面体夹角。

修复了五次缓动的浮点末位超出 [0,1] 导致负透明度的风险。透明度始终继承父层，交接不出现局部图元突然恢复全亮。

类型及数值回归通过后仍须由主工程进行真实字体下的代表样帧、动态片段、逐句音画与最终成片检查。本记录不声称已经完成后者。
