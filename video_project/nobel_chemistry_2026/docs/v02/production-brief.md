# 化学奖 V02：发音、教学因果与动态演示升级

以已交付 V01 为回退，独立保存 V02 源码、声音、时间线和成片。继续交付 1920×1080、30 fps 的完整预览，时长由修订旁白测定，约五分钟；本轮不输出 4K。

1. 核对获奖者、相关研究者官方姓名资料和可取得的发音证据。字幕保持正式拉丁拼写；TTS 朗读输入与显示文字分开保存。ASR 识别出正确名字不能作为发音正确的唯一证据。
2. 重新审查讲稿中的奖项、时间、手性、二配体模型、Soai 反应与三轮放大数据，补足必要因果。清楚区分构型、旋光、ee 和主要对映体比例；不增加无证据的成功结论。
3. 用连续对象运动展示配体组合、筛选、化学键变化与产物催化下一轮。保留 V01 的真实四面体、精确数据和论文页，新增变化与实际词时序对齐。
4. 保持深蓝、象牙白、低饱和金青与既有标题/品牌。文字稳定，主体不越出安全区；局部透明度必须继承父场景过渡，避免旧版接缝残留回归。
5. 保留个人音色与 Dawn。只重录需修正的句源，重建唯一母带、字幕及时间线，检查名字、轻声尾部、混语衔接、字幕和 AAC 峰值。
6. 代表画面及连续帧检查通过后完整渲染；最终 QA 和依赖快照完成后仅清理可重建缓存，保留 V01 完整成片及其重渲染依赖。
