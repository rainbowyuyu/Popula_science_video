# V03 人名与术语配音策略

## 画面姓名与口播姓名

字幕、论文页和来源栏保留官方拉丁拼写：**Henri B. Kagan、Kenso Soai、Louis Pasteur、Charles Frank**。为消除 V02 中“普通话句子 + 单独母语片段”的音色、底噪和呼吸断裂，V03 对含姓名的句子整句重新合成，配音输入采用中文近似读法：

- Henri B. Kagan → 亨利·比·卡冈（法语 Henri 的词典目标为 /ɑ̃.ʁi/；Kagan 的具体个人录音未取得，因此不把候选 IPA 写成官方结论）
- Kenso Soai → 肯索·索阿伊（日本学士院确认 `けんそう そあい`；中文近似保持 `so-a-i` 的三元音节奏）
- Louis Pasteur → 路易·巴斯德（法语词典支持 /lwi pas.tœʁ/ 的中文常用读法）
- Charles Frank → 查尔斯·弗兰克（英语姓名的词典读法）

## 化学术语

二异丙基锌、嘧啶、锌醇盐、对映体过量、偏振光等均随完整句子重新生成，不再用外部词片硬替换；显示公式和拉丁式样仍由画面负责，口播使用中文解释，减少字母逐个拼读造成的停顿。

## 验证边界

- 机器 Whisper 只检查漏词、数字、句尾和时间对齐；其对外语人名的拼写不是发音裁判。
- V03 没有任何 `pronunciationEdits` 词片替换，`audio/v03/tts-generation-v03.json` 可核查。
- 人工母语听审仍未完成；若发布前需要严格法语／日语音值，应由人工听辨后再决定是否替换整句载体。
