## 修正内容

- 原代码 `put()` 返回原子索引，后续把索引传给三维向量加法。已统一取 `A[index].p`，消除无效坐标。
- 乳酸包含 3 个碳、6 个氢、3 个氧，共 12 个原子；11 条拓扑连接，包含 1 条 C=O 双键，键级总和为 12。羧基两条 C–O 连接长度分别为 0.70/0.72 教学单位，O–H 为 0.45，使球体间的键可见。这是球棍教学模型，不是晶体测量坐标。
- 球、键与文字绘制恢复继承的 Canvas alpha，三个导出函数均 `save/clip/restore`，只在调用给定矩形内绘制。
- 第二个分子的几何真实执行 `x → −x`，随后只做行列式为 +1 的旋转。未计算 CIP，因此使用“镜像 A / 镜像 B”，不指定 R/S。
- 对齐过程围绕 H/OH 连接方向的平分轴旋转。只有实际完成对齐的阶段才出现说明；说明采用“连接方向对齐”，不将羟基内部转子构象声称为完全重合。
- 原子远近与键的 10 段切片共同按相机深度排序。每个内部接缝沿屏幕连接方向延伸 0.7 px，消除细缝；首末端不延伸，仍与端点球体一致。
- 分子文字固定在两侧外轨道，轨道跟随整体平移，短引线先绘、原子后绘、文字最后绘；重合阶段右侧重复 H/OH 说明自然退场。
- 晶体是凸的镜像截角棱柱，用于表达可辨认的镜像晶形，不是酒石酸晶格复刻。镊子逐次移动且不同时出现三把；顶部说明与镊柄运动范围分离。
- 溶液光学演示中光束始终直线传播；转动的是与传播方向垂直的电场方向。没有把 R/S 与正/负旋光作普遍对应。
- 可选烧杯场景使用固定编号与低速连续对流的球棍符号；反馈轨道与符号共用贝塞尔求值，不声称是真实分子动力学。

## 接入

```ts
import {drawChiralPair, drawCrystalSorting} from './OpusChemistryV01';
setOpusDrawers(
  (ctx, s) => drawChiralPair(ctx, s.elapsed, s.progress, 100, 330, 1720, 560),
  (ctx, s) => drawCrystalSorting(ctx, s.elapsed, s.progress, 100, 330, 1720, 560),
);
```

`drawReactionVessel(ctx,t,progress,x,y,w,h,ee)` 作为可选辅助，`ee` 输入范围为 0–1，对应主导手性占比 `(1+ee)/2`。本片主要反馈段可继续使用主工程的机制可视化。
