# V08 动态可视化升级记录

本轮只改帧驱动的 Remotion/Canvas 可视化，不改实验数字、论文图片和音频时间线。所有中间状态由 `State.time` 或镜头进度计算，未引入实时 CSS、无种子随机或逐帧重挂载。

## 画面升级

- `WorldV03.ts`
  - `orb`、`glowPath` 为粒子增加体积核心、边缘高光和多层发光尾迹。
  - 事件源加入轨道粒子、径向扇和连续脉动中心。
  - 中微子、三类信使使用固定锚点的连续尾迹；分叉点增加短暂冲击环。
  - 南极冰体增加体积光洗、入射射线和稳定的模块深度衰减。
  - 探测器前平面加入玻璃体积阴影，光学模块按深度改变大小和亮度。
  - Track 使用弯曲样条与二级粒子；Cascade 保留入射母径迹并显示三个方向的次级分支。
  - 2013/2014 统计柱按事件连续生长，保留 28、4.1σ 与 37、5.7σ 的事实区分，并增加低透明度背景曲线作为阅读引导。
  - 背景筛选增加大气粒子渐隐、上行径迹光晕和门扫描脉冲；候选源加入空间星点和源点呼吸。

- `EvidenceFigureV01.tsx`
  - 论文图页保持 `objectFit: contain`，加入小幅帧驱动推镜、水平视差和低透明度光扫；不改变图页尺寸、版权位置或字幕安全区。
