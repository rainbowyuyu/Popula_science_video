# IceCube 场景真实感升级记录

本轮视觉升级保留 V09 时间线和音轨，只调整 `WorldV05.ts` 的确定性 Canvas 画法，便于回退和逐帧比较。

## 改动

- **冰体**：加入低对比度水平冰层、深度衰减和缓慢移动的局部冰光。冰层仅位于内容安全区（`y >= 285`），不会穿过标题或字幕。
- **探测器**：光学模块由平面圆点改成带缆线、压力球轮廓、玻璃高光和向下光阴极的实体符号；位置继续共享 `projectDepth` 的同一 `x/z` 锚点。
- **空间关系**：加入冰面开口和五束下沉缆线，解释“冰面以下约 1.5 km”的空间入口；不将示意线当作真实工程尺寸。
- **Cherenkov 光**：锥体增加两条边界母线、多个椭圆截面和沿锥面传播的光子，保留 `cos(theta)=1/(n beta)` 的参数约束。

## 验证

- 改动为绝对时间驱动，无实时随机、阶段重挂载或重复闪烁。

## 解释边界

这些是依据 IceCube 公开结构和 Cherenkov 机制制作的教学示意，不替代 IceCube 的工程 CAD、真实事件数据或官方实验可视化。完整 V10 渲染应继续保留 V09 作为回退版本。
