# V11 逐句视觉契约

状态：最终源码已冻结，正式1080p已完成技术渲染与自动QA。此表的逐句契约仍待用户预览中的连续播放、逐句复听和审美确认；静帧/局部代理审阅不等于完整人工验收。

共17段、65条字幕句。30 fps，时间线计划7403帧。帧区间为起点包含、终点不包含，来自字幕名义时钟；字幕淡入淡出和最终音频偏差另验。

原图裁切及来源见 [figure-assets.json](figure-assets.json)，科学语义见 [paper-visual-audit.md](paper-visual-audit.md)。

最终运动学：007以解析积分保证dx/dt=105β，历史发射点在实验室坐标固定；粒子、冰介质、波前和光子共用跟拍相机。β=.995、n=1.3193时光子角约40.378°，画面约40°。恒速直锥只从8.421秒后出现，并与恒速历史球面相切。015方向三角沿实际轨迹反向投影展开。
