# V09 动态视觉升级（WorldV04）

本轮参考短视频常用的「先给尺度、再给机制、最后回到证据」节奏，保留 V08 的论文、事实和安全区，在 Remotion Canvas 中新增以下帧驱动视觉：

- 片头 `cosmicArrival`：一条连续的入射中微子轨迹，带体积化光带、光子尾迹、同一镜头内逐步显现的探测器光环。
- 冰体 `iceOrbit`：相机在同一锚点上绕过冰体，弦列、扫描平面和模块光点保持投影注册。
- 信使 `messengerSplit`：共享源点的三条路径增加冲击环与短暂残影，强调因果顺序。
- 级联 `showerVolume`：随机性固定、具有径向衰减和深度亮度的粒子体积，避免平面喷点。
- 统计 `confidenceBuild`：事件从基线逐个累积，后验曲线逐渐收紧；区分 28/4.1σ 与 37/5.7σ，并保留 event 32 背景 μ 子注记。
- 候选源 `focusSources`：三个候选方向终点加入低对比主星系椭圆和运动星点，作为方向线索的视觉隐喻。

所有新增动画由绝对帧时间驱动，无实时随机、重复挂载或片段内闪烁。绘制仍受 `y >= 285` 安全裁剪及证据窗口左侧裁剪约束，避免标题、字幕、论文图和来源互相遮挡。

建议抽查帧：120、390、1210、2420、3300、4000、4800、6000、7080；渲染脚本会覆盖对应目标帧。
