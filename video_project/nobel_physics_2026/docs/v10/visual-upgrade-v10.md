# V10 真实场景化动态升级

V10 以 V09 为基线，保留原旁白、字幕、数据和桥接视频，只更换 Canvas 动态层。

- 分层冰体和冰面入口让 1450 m 深度与 1 km³ 体积有空间依据。
- 14 条可见缆线、透视深度和带压力球轮廓的 DOM 让 IceCube 读作真实探测器。
- 碰撞场景把中微子、局部原子核碰撞、带电次级和 Cherenkov 光锥按时间顺序分开。
- Cascade 使用结构化次级径迹和局部沉积，Track 保持长径迹特征。
- 所有坐标通过同一 `projectDepth` 投影，避免模块、光锥与轨迹漂移。

Opus 5.5 提供设计审阅；代码由本工程 Remotion/Canvas 确定性实现。新增动画是教学重构，不冒充真实事件数据。
