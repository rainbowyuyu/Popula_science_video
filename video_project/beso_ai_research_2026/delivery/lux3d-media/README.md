# Lux3D 概念资产（独立媒体交付）

`studio-preview.png` 是用 Blender 5.1.2、factory-startup、单独灯光和正交相机生成的检查图；`studio-inspection.blend` 与 `inspect-lux3d.py` 用于后续镜头调整。

模型来自已完成的 Lux3D 任务 `4039808`，并在 `delivery/lux3d/lux3d-delivery.json` 中记录了实际 GLB 校验和 SHA-256。该资产用于产品发布片的工具链概念镜头，标签明确为“概念资产”，不参与 BESO、Zwind 或 WaterPro 的计算结果。
