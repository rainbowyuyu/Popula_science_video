# episode3v6：真实可装配亭子重制 brief

## 目标

当前 v5 的亭子是教学抽象体：构件分组可以移动，但没有一套可追溯的真实亭子构造图纸、构件编号和装配约束。本版以一座真实比例的四角木亭为唯一主角，所有榫卯、受力和风场画面都从这套构造派生。

## 选型原则

- 采用公开资料中有平面、立面或节点图的四角木亭/传统木构亭，不使用只提供外观照片的模型。
- 保留真实施工语义：台基/柱础 → 柱 → 金柱与檐柱连接 → 额枋/檩条 → 椽条 → 屋面 → 栏杆；每件构件有稳定 ID、材质和局部坐标。
- 榫卯讲解只使用主亭实际存在的连接：柱—额枋的穿榫/燕尾锁、檐枋交接的半搭接、栏杆或楣子的销榫。单独放大的节点必须与主模型中的构件共享几何和装配方向。
- 装配校验要求：每个部件有 `assemblyAxis`、`targetPose`、`contactFaces`；正向装配和反向拆解的间隙、顺序、锁止方向均记录在 JSON 中。

## 仿真边界

- 风场：保存 Zwind 工程流场参考的输入、网格和导出字段；若本机没有 Zwind 可执行程序，明确标记为“Zwind 参考/数据接口”，画面不能把教学 D2Q9 冒充 Zwind 实算。
- 结构：每个梁柱节点用对应局部坐标承受竖向、侧向和拔出工况，输出部件级反力、接触压力和 von Mises/木材压拉指标；动画只显示经过验证的结果字段。
- 含水：对柱、额枋和榫头使用同一材料参数的各向异性扩散，输出含水前沿、纵横向胀缩和节点间隙变化；显示放大倍数写入报告。
- 每个热力图必须能回溯到 `partId`、工况、求解器、网格和结果文件，避免“整亭颜色覆盖”替代部件仿真。

## 视频结构（暂定五分钟）

1. 雨后进亭：从真实图纸线稿切入，镜头穿过柱—枋节点，提出“没有角铁，为什么没散”。
2. 图纸到模型：平面/剖面/轴测三视图与部件编号叠化，随后真实构件逐件装配。
3. 三个真实节点：从主亭抽出柱—枋穿榫、檐枋半搭接、栏杆销榫；分别展示装配方向、锁止方向和反向拆解。
4. 力的回路：瓦/椽/檩/枋/柱/柱础逐件点亮，叠加部件反力与接触压力，而不是泛化箭头。
5. 风与水：Zwind 数据接口说明、迎背风压力、节点反力重分配；扩散结果驱动榫头间隙和局部压应力变化。
6. 收束：回到完整亭子，展示图纸、求解器、模型和误差/适用范围。

## 完成证据

- 图纸来源与许可/页码记录在 `real-pavilion-sources.json`。
- 模型部件清单、装配约束和几何审计记录在 `true-pavilion-assembly.json`。
- 风场、结构、扩散结果分别有原始输入、求解日志和 `partId` 映射。
- 新成片必须有逐场景抽帧、完整解码、音视频时长一致、无长黑帧和转场顺序审计；旧 v5 保留作回滚，不混入新 QA。
