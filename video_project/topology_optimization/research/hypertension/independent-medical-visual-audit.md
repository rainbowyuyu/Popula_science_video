# 高血压视频：独立医学与可视化复核

复核时间：2026-10-06。对象：冻结后的 `story.json`、`solve_pressure.py`、`physics.json` 和已导出的 BodyParts3D GLB。未改动冻结文案或求解器。

## 结论

文案主线通过，没有发现必须重新录音的医学错误。它从偶然测到高血压切入，解释动脉压力、心输出量与阻力、肾脏水钠调节、神经激素控制、大动脉硬化及规范测量；没有把高血压等同于血管堵塞，也没有承诺凭生活方式一定治愈。

求解器是成立的双元 Windkessel 教学实验，方程、单位和体积平衡一致。它不使用解剖网格求解局部血流，不产出患者预测或器官局部应力图。画面必须与这个范围相符。

## 必须落实的画面条件

1. **h019–h020 阻力对照**：比较条件是相同流量、长度、黏度。管腔变窄时更大的压力差维持同样体积流量；不要一边标“相同流量”，一边把窄管每秒通过的粒子数量减少。若粒子代表同等血液体积，窄段轴向速度应上升。红细胞大小和管径若为示意，不可把真实微米尺度直接当相同。
2. **h025–h027 水钠**：钠用已溶解的小符号或粒子表达，不用食盐晶体在血管内堆积。肾小管内显示滤液与水/Na⁺，周围毛细血管中显示血液；正常示意中红细胞不能穿过滤过屏障进入肾小管。回收箭头由管腔经上皮/间质流向毛细血管，剩余滤液通向尿液端。
3. **h030–h033 RAAS**：屏幕使用准确名称“血管紧张素 II”。肾脏提供启动信号肾素，肾上腺提供醛固酮；不要把二者都画成肾脏直接产生。可以简化中间酶促环节，但不可错置来源。
4. **盐→RAAS 的转场**：不能用“高盐直接开大 RAAS”作为所有人的统一因果链。正常高盐一般抑制循环 RAAS；盐敏感人群存在不恰当抑制及组织通路异常。当前文案只说“还会发出信号”，足够稳妥。画面用镜头移到另一条调节线路，而不是把上一幕盐粒直接连入启动开关。
5. **h038–h040 弹性实验**：保持相同输入流量和阻力时，降低顺应性 C 增大脉压，升高收缩峰、降低舒张谷；本实验平均压保持不变。不能把两条压力曲线整体向上平移，或写“平均压力上升”。
6. **所有模拟画面**：保留可读的“教学简化模型 / 机制示意”简短标识。禁止把全身动脉网格上的任意颜色宣称为 CFD 压力场；Windkessel 只产生一个集中动脉压力状态。若用此标量让全身动脉同步脉动着色，称为“动脉压力随时间示意”即可。
7. **测量画面**：袖带在裸露上臂、位置在肘上；手臂有支撑且袖带与心脏同高，背部有支撑，脚平放且不交叉。避免将袖带套在前臂或手腕。解说未给诊断阈值，避免在画面另加不同指南冲突的诊断红线。

## 求解器独立审计

方程：`C dP/dt = Qin − (P − Pv)/R`。

- C：mL/mmHg；R：mmHg·s/mL；Q：mL/s；两边均为 mL/s。
- 心率 72/min，周期 0.833333 s，每搏输入 70 mL，心输出量 84 mL/s = 5.04 L/min。
- 输入采用持续 0.31 s 的半正弦射血，其解析积分为70 mL，其余周期为0。
- Pv=5 mmHg，恒定静脉端压力；流量处方，不随后负荷变化。
- 30个周期进入近似周期稳态，积分器 `rtol=1e-8`、`atol=1e-9`、`max_step=.002` 合理。
- 源程序既检验周期终点压差，又检验输入输出与储存量，方向正确。

独立从已输出301个采样点积分：

| 条件 | 收缩/舒张 mmHg | 数值均压 | 解析均压 Pv + R×CO | 输入/输出 mL | 源程序守恒残差 mL |
|---|---:|---:|---:|---:|---:|
| baseline | 104.97 / 77.23 | 90.68 | 90.68 | 69.99871 / 70.00002 | −0.00122446 |
| higher_resistance | 145.18 / 117.39 | 131.00 | 131.00 | 69.99871 / 70.00042 | −0.00133206 |
| stiffer_artery | 124.14 / 61.54 | 90.68 | 90.68 | 69.99871 / 70.00001 | −0.00130337 |

残差约每搏量的0.002%，与离散积分和四舍五入一致。三种数值是选定参数的示例，不代表具体正常人/患者。baseline不必强行改成120/80。

半径实验采用理想稳态层流圆管：`R ∝ r⁻⁴`；半径比例1/0.9/0.8/0.7对应阻力比例1/1.5242/2.4414/4.1649，计算正确。真实小动脉存在非刚性、分叉、主动调节和非牛顿微循环效应，片中已说明简化模型。

## 解剖显示层建议

以下为视觉起点，需按实际渲染截图调整，不是医学参数。

| 镜头 | 主体 | 透视/隐藏策略 |
|---|---|---|
| 全身定位 | 心脏、动脉网络、两肾 | `bodySurface` 约0.04–0.10；`thoraxSkeleton` 0.12–0.20；静脉0.20–0.35。主体动脉保持清楚，避免红蓝网络都完全不透明互相遮挡 |
| 胸腔推进 | 心脏、升主动脉与弓 | 降低皮肤和前胸骨架，离开画框后隐藏；脑与两肾出画后隐藏以减轻渲染。除非讲解瓣膜，关闭心腔 FJ2422–FJ2425，不把腔体画成实心块 |
| 心脏剖面 | 心室壁、瓣膜、腔内流向 | 局部剖切或局部壁透明优于整颗心脏玻璃化；腔体节点按需要单独显示。通过半透明前壁仍应有足够背景对比 |
| 肾脏定位 | 两肾、肾动脉、腹主动脉 | 后侧约20–35°斜视可减少腹部结构遮挡；关闭胸廓；保留附近主动脉和肾动脉，静脉降至0.15–0.25或隐藏 |
| 肾小管微观 | 示意滤液管、毛细血管 | 真实 `leftKidney/rightKidney` 仅作外形空间锚点；放大示意有明确入口过渡，不能声称库内已有真实肾单位结构 |
| RAAS | 肾脏、肾上腺、动脉 | 突出两肾上方 `adrenals`，其他结构低对比；保持各信号起点和终点解剖位置一致 |
| 靶器官风险 | 心、脑、肾 | 主体维持实体材质，其余作为细轮廓或低透明度参照；不要用全部不透明动静脉网格挡住器官 |

透明材质应 `depthWrite=false`，必要时局部剖切减少多层透明排序伪影；不能以瞬间隐藏来替代镜头转场。器官位移、缩放和压力脉动都须围绕各自中心。已经在模型 README 中提醒所有顶点使用全局解剖坐标，节点transform为identity。
