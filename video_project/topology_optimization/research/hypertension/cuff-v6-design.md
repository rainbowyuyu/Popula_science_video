# V6 测压袖带与前臂支撑

依据实际画面 `output/hypertension/frame-8868.jpg`：旧袖带作为舞台根节点的独立圆筒，旋转仅取Z角，上臂却同时向前倾斜；两者没有共同长轴，导致圆筒浮离手臂。旧桌面仅到手腕下，肘部及近端前臂悬空，气管也靠手填坐标。

本次仅编辑 `World.ts` 的 `buildMeasure()`，不改全局舞台位置、人物躯干/座椅/双脚、片头模型、镜头或音轨：

- 肩点、肘点、腕点共同生成裸上臂和水平前臂；短袖在袖带上缘之前结束。袖带中心及四元数由同一肩肘轴生成，贴合上臂，下缘位于肘上。
- 袖带包含内衬、柔和包边、织物重叠片与细接缝；气管从袖带接头精确连接至仪器侧面接头。
- 前臂下新增薄软垫，桌面延伸至肘部。台面和仪器随支撑高度一起调整，保持物理接触。
- 新增世界锚点 `measureCuff`、`measureForearm`、`measureElbow`、`measureSupport`，供近景和标注直接读取几何位置。所有关键对象有 `measurement-...` 名称。

袖带世界中心 `[11.1742, 3.5993, -0.105]`，长轴 `[-0.3946, 0.7581, -0.5192]`。模型仍是说明规范姿势的中性教学人形，尺寸为场景单位。

验证：`npm run check` 通过；`scripts/hypertension/audit_measure_cuff_v6.mjs` 直接调用当前生产 `buildMeasure` 与 `buildMonitor`，结果见 `cuff-v6-geometry-qa.json`。袖带轴与上臂轴对齐为1，中心离轴误差2.15e-16；袖带内衬/上臂径向间隙0.004，下缘/肘空隙0.1098；前臂与垫顶差0.00154；气管端点与接头误差不超过1.8e-15，路径不穿前臂或桌面。此为几何审核，GPU视觉仍由根代理检查。推荐检查8868帧及h047/h048交接、h048近景。
