日期：2026-10-08。本文记录当前 `World.ts`、`CameraPath.ts`、`Film.tsx` 和 `timeline.json` 的 V8 开场审查结果。已完成静帧抽查与相机审计，并保留接触表 `tmp/intro-v8-contact2.jpg` 供复核。

## 当前实现基线

`loadAtlas()` 当前创建两个世界根：`introRoot.x=-12` 与 `measureRoot.x=+12`。两者都调用 `buildMeasure()`，因此视觉组件来自同一函数，但仍是两份独立实例。intro 版本保存 `introBody / introCuff / introForearm / introMonitor` 锚点，并隐藏时钟；measure 版本保存对应 `measure*` 锚点并显示时钟。`buildMeasure()` 会将 intro 屏幕设为 `mode='intro'`（0→152/94），final 屏幕设为 `mode='measure'`（146/92），两套场景都有同一套小显示器、袖带、上臂、前臂、支撑台和气管。

全局对象属性 `this.cuff`、`this.clockHand` 和 `this.screens` 会在第二次构建时被覆盖或追加。当前渲染未用 `this.cuff` 控制可见性，显示主要由根位置和相机决定；若 V8 改为单一根，必须重新确认屏幕 mode、时钟显示与 anchor 偏移，不能只删除 `introRoot`。

## 时间线与相机锚点

| 区间 | 旁白 | 预期画面与审查重点 |
|---|---|---|
| 0–0.60 s | 无口播 | 同一小人全景，桌、椅、脚、袖带和血压计建立尺度；标题尚未遮住关键部件 |
| 0.60–8.33 s / h001 | 袖带收紧、数字让人心里一紧 | 先展示坐姿全貌，再沿上臂靠近袖带；检查袖带包住裸露上臂，不压在短袖上，气管连到显示器 |
| 8.43–14.90 s / h002 | 没头晕，为什么高 | 从袖带沿气管或桌面平移到显示屏；数字、单位和字幕可读，显示器不被前景手臂遮住 |
| 15.00–20.90 s / h003 | 压力从哪儿来 | 从显示器拉回小人，再向左/画外移出，接入人体解剖；不能在回拉中出现第二个小人或空白背景 |

## V8 静帧抽查清单

必须保存各节点和边界帧，而不是只看章节中间帧：

```text
0, 17, 18, 135, 249, 250, 251, 252, 253, 351, 446, 447, 448, 449,
450, 526, 626, 627, 628, 629, 630, 692, 755, 756, 757, 758, 759,
830, 900, 901, 902, 903
```

其中 135/351/526/692/830 是各口播段中部，便于判断运动；249–253、447–450、627–630、756–759、900–903 是字幕/镜头/场景接缝。每帧需记录：

- 小人是否完整在画内；头、躯干、椅背、桌腿和脚是否保持成人比例。
- 袖带是否和上臂同轴、贴合且没有穿过短袖；前臂下方是否有支撑台，肘部不悬空。
- 气管是否从袖带连续通到屏幕，屏幕是否面向镜头、没有被手臂或字幕遮挡。
- `Brand`、Heading、Caption 与小人关键部件是否重叠；字幕遮挡面积应低于关键部件约 15%。
- 若 intro 与 final 使用同一 root，0–30 秒不能同时看见另一份坐姿小人；30 秒以后 root 位移需在镜头外完成。任何“变位置”都必须通过看不见的阶段或跟随镜头的平滑转移完成。
- 30.07 秒前后应保留人体外轮廓/胸口作为锚点，不能从小人直接切成独立心脏；检查 901/902/903 帧和 30.0–31.0 秒连续抽帧。

## 物理尺寸与 UI 约束

以 `buildMeasure()` 局部几何为基线：头高约 5.24、上臂由肩 `.(-.20,4.20)` 到肘 `. (0.03,3.03,.32)`、前臂到腕 `. (1.07,2.975,.49)`；袖带中心沿上臂 0.65 比例、宽 `.57`。V8 不应通过相机 FOV 变化让袖带看起来比前臂粗一倍以上，也不应把小显示器当成真人尺寸的大型血压计。
