# 第二集制作说明｜彩虹为什么是弧形

- 成片：`output/episode2/彩虹为什么是弧形_1080p.mp4`
- 规格：1920×1080，30fps，303.85 s（约5分04秒）
- 渲染入口：`npm run render:episode2`
- 静帧检查：`npm run stills:episode2`
- 实现：Remotion + Three.js 逐帧渲染；光路使用球面交点、Snell 折射、一次内部反射和出射向量；雨幕后景、观察者圆锥和偏向曲线由同一世界坐标渲染。
- 开场素材：Qwen Image 生成雨后公园情境图，仅作叙事氛围，不作为彩虹物理证据。任务与用途记录在 `research/episode2/qwen-rain-after.json`。
- 旁白：rainbow鱼 个人参考音色，Qwen3-TTS 本地生成；使用 `broadcast_voice.py` 温和处理，未变速、未变调。
- 配乐：`public/episode2/rainbow_arc_ambient.wav`，本片原创程序化氛围音乐；已修正峰值归一化，旁白段自动 duck。
- 片尾：约5秒，LaTeX 公式图、两张按已核对 DOI 书目信息制作的论文视觉页自然叠放。它们明确是书目信息视觉化，不冒充原始 PDF；验证范围和 DOI 记录见 `research/episode2/paper-sources.json`。

## 片尾来源

- Nussenzveig, H. M. (1977). *The Theory of the Rainbow*. Scientific American. DOI: 10.1038/scientificamerican0477-116
- Khare, V. & Nussenzveig, H. (1974). *Theory of the rainbow*. Physical Review Letters, 33, 976. DOI: 10.1103/PhysRevLett.33.976
