# 每天5分钟生活中的新知识：地铁进站与安全线

## 成片设计

从“车没到，风先到了”的候车经验出发，沿同一座三维站台进入隧道剖面，再依次观察车头、车侧、车尾、人体支撑区域与站台门。正文12段，片尾8秒。实际个人音色旁白决定时长：9212帧，30fps，307.0667秒，约5分07秒。

配色为深蓝灰环境、白色列车、琥珀安全线与青色气流；压力使用青色至珊瑚色。列车、车门、轮对、站台、盲道、旅客与行李均由Three.js可复现几何构建。摄影机位置和目标使用帧驱动的五次平滑插值。大标题先退出，近景以模型和短字幕为主。rainbow鱼图片Logo及文字固定左上。

## 真实使用的工具

- Three.js 0.180：程序化模型、材质、光照、镜头、剖面与动态数据展示。
- Remotion 4.0.526 / React Three Fiber：帧驱动成片、字幕、离线导出。
- NumPy / Numba：D2Q9格子玻尔兹曼二维简化绕流求解。
- Python数值计算：体积守恒分流、独立均匀风的气动力与力矩估算。
- Zwind：片尾列出的工程风场/受力仿真路线；本片公开成片的数值演示仍由D2Q9教学求解提供，便于把“工程复核路径”和“本片可复现数据”分开说明。
- 本地Qwen3-TTS-0.6B：经用户授权的rainbow鱼参考音色；原句音源独立保留。
- SciPy / FFmpeg：保守人声处理、原创音乐合成、混音与技术检查。
- Whisper：字幕辅助对齐与漏句检查。ASR不能证明所有读音或主观音质完美。
- Matplotlib MathText：从LaTeX公式源生成透明公式图片。

本片没有调用Blender、Lux3D、远程GPU、Qwen图片生成或全尺度商业CFD；片尾将Zwind作为工程仿真路线说明，同时明确本片画面所用的D2Q9教学场。本地CPU完成流场，本地GPU完成语音，远程计算授权已记录进科普技能，凭据不进入交付包。

## 模型的适用范围

流场为Re=20、二维圆端车体的低马赫数教学求解，不包含完整隧道、站台壁面、车顶、制动或人体。它用于说明绕流与尾流恢复，不预测某站的真实风速、湍流强度或安全距离。真实列车尾流可能具有明显非定常变化；本片稳态流线不能作为该湍流的数值预测。

随车坐标系来流为+x，车头x=-4；站台系速度为(u-1,v)，不能直接把随车流速称为旅客感受风速。镜头中的流线来自保存速度场的RK4积分；粒子为该场回放，非每一视频帧重新求解。

活塞效应分流遵守排开体积率与分流和相等，分流比例是假设示例。人体风力模型独立采用F≈½ρC_DAv²、M=Fh；同姿势、同迎风面积和近似固定阻力系数下，相对风速1→2倍对应气动力1→4倍。这不是把列车时速直接代入，也不是人体跌倒阈值。人物轻晃、迈步和支撑区域为机制示意。

安全建议依据运营机构公开规则：站在安全线远离轨道的一侧，不倚靠站台门，等停稳开门后先下后上，遵从现场标线与广播。安全线本身不会挡风，也不是绝对保证。

## 可复现入口

在完整工程根目录：

```powershell
npm ci
npm run check
python scripts/physics_metro.py
node scripts/render_metro.mjs stills
node scripts/render_metro.mjs
python scripts/qa_metro_final.py
```

渲染输出为`output/metro/metro_safety_1080p.mp4`。预生成流场及最终母带已提供，常规重渲染无需重新生成旁白或运行求解。求解数据接口与边界详见`research/metro/PHYSICS-README.md`，音色处理与配乐见`research/metro/audio-production.md`。

语音重新生成入口为`voice_metro.py`，依赖原机器`D:/python_project/tts`及其个人参考音色。参考录音与模型权重不随影片交付；已经合成的逐句原声与处理声完整保留。系统字体使用Microsoft YaHei；跨平台重渲染应配置授权可用的中文字体并重新检查排版。

本版旁白采用`research/metro/v2/story-natural.json`的63句自然稿，约1347字；实际音频与字幕时间线已同步写入`public/metro/v2`并激活到根目录。口播从候车时头发先动的生活观察进入，再沿车头、车身、尾流和人体平衡推进，避开模板化否定句。

## 来源与署名

真实论文页来自伯明翰大学开放仓储的Christopher J. Baker 2014两篇综述作者稿，使用CC BY资源。卡片只做整页缩放与轻微旋转，标题和作者年份独立放在卡片下方。完整来源、许可证记录、访问日期和实际阅读范围见`research/metro/sources.json`；其他网页只转述事实。NC-ND研究稿只在内部核验，不纳入发布包。

配乐《下一站·留白（疏朗版）》为本片独立合成的原创编排：两层柔和钢琴加低根音，每8秒换和弦，去掉木质点音、额外脉冲和持续鼓组，给人声留出呼吸，无第三方采样。4个平台的标题、简介与署名文本见`发布文案.md`（原稿为`research/metro/publish.md`）。本片未自动上传任何平台。

## 验证记录

数值验证见`research/metro/physics-audit.json`，人声/字幕见`research/metro/audio-qa.json`。最终MP4按新版时间线验收：1920×1080、恒定30fps、9212帧（约307.07秒），完整解码、黑帧、AAC响度与章节接缝均纳入检查；母带目标为48kHz双声道、−16 LUFS / −1.5 dBTP。报告见`research/metro/final-media-qa.json`。

实际视觉复查包含13个章节中间画面、12处接缝每处7帧、首末帧、480张转场时间序列缩图，以及风速HUD与片尾的1080p细节图。范围与发现见`research/metro/visual-review.md`；另提供48秒转场复查片。此为助手抽帧检查，不冒称完整人工实时观看或主观听审。

可编辑静态模型在`public/metro/models/metro-station.glb`，可导入Blender，含列车、站台、屏蔽门、人物和随身物件的独立层级；材质及贴图内嵌。它用于后续编辑，成片仍由Three.js源代码驱动。
