# V6：随模型的轻量标注与测量姿势修正

本轮保留 53 句旁白、9671 帧时长与原配乐。重点为正确指认画中对象，修正袖带贴合，改善肝区微观进入和袖带近景。

标注读取当前帧 Three.js 对象的真实变换、变形后的顶点或既有解剖坐标，经当前摄影机投影。锚点不夹到画面边界；目标出画或模型透明度降低时，文字和引线一起收束。同一标注的左右侧固定，文字位置连续跟随，避免经过屏幕中心突然换边。所有运动来自帧号，没有 CSS transition、真实时钟或依赖上一帧的平滑缓存。

主要对象包括心脏、主动脉、小动脉、平滑肌、管腔、肾脏、肾小球、肾小管、水钠回收路径、肾素信号起点、脑、肝脏、VLDL/IDL/LDL 颗粒、LDL 受体、动脉内膜、泡沫细胞、斑块、血栓与测量袖带。每次最多两条，大部分画面仅一条。名称随叙述出现，未把全部器官同时贴满标签。

字体统一 42px，以暖白小底衬、低饱和青色细引线和圆点连接；为片头标题、品牌、压力图、步骤提示和字幕保留固定安全区域。文字底边不超过 754px；不覆盖底部 787px 开始的步骤提示。平滑肌标注绑定上沿实际肌束顶点，避免引线横穿血流。

袖带与裸露上臂共用肩、肘和局部轴线，布套有内衬、包边与气管接口；前臂落于软垫/桌面，气管端点和桌面净空经过生产几何检查。见 cuff-v6-design.md 与 cuff-v6-geometry-qa.json。

相机采用同一连续轨迹。肝区进入微观时更早建立肝脏位置，并减少高速推进；袖带近景围绕实际袖带和前臂锚点构图。见 camera-v6-design.md。

检查分为源码/几何数值、实际静帧、最终编码抽帧与完整解码。没有做过的人工播放或主观听审不计入通过项。
