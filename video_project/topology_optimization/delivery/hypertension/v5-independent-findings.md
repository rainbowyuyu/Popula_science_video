## 1. P1：主动脉剖管在其他器官镜头中仍作为高对比物体出现

**实际证据**

- 帧 2818、2838、2880–2885（93.93–96.17 s）：讲解转向小动脉时，一截红色剖管从画面顶部垂下，露出平直切口，有时压到左上品牌附近。它比正在寻找的小动脉更醒目。
- 帧 3989、4014–4081（132.97–136.03 s）：退出小动脉进入肾脏时，同一截剖管仍悬在左上。肾的定位已经清楚，却附带一个显著、看似断开的零件。
- **帧 5529（184.30 s）**：讲血管紧张素/醛固酮时，剖管直接占据画面左侧高对比前景。
- **帧 7042（234.73 s）**：字幕已讲肝脏释放 VLDL，画面最显眼的仍是竖贯画幅的巨大半透明剖管；肝脏与 VLDL 反而退到难识别的背景。

**原因**

`World.ts:295` 的主动脉细节可见度是 `1-nearLipid*lipidScene`，所以它在肾脏、信号、小动脉段始终存在；仅在相机极接近脂蛋白时才压低。该模型对原主动脉局部比例本身有取样依据，问题是剖窗永久打开、高对比材质独立存在，成为所有附近镜头的外置道具。

**建议**

把“真实主动脉表面”与“观察剖窗”分开管理。离开主动脉观察时先闭合局部剖窗，恢复连续的原血管轮廓，再沿其分支滑移到肾脏；不在画面边缘保留平整截断的红条。进入肝脏时机位先走肝脏外侧的安全通道，再向组织推进，不能靠最终淡化主动脉来补救穿过其前景的路线。相邻语句需要主动脉上下文时只保留低对比原解剖血管，剖面不抢主体。

## 2. P1：小动脉微观进入仍像“缩小模型悬在巨型管道帘幕前”

**实际证据**

- **帧 2938（97.93 s）**：微观小动脉仅约占画幅宽度 16%，巨大的半透明血管和肾脏边界却铺满全画面。小动脉两端没有可读的、逐级缩小的父血管连接；它看上去是浮在背景之前的完整小零件。
- 帧 2922、2965、2996（97.40、98.83、99.87 s）显示这种状态持续数秒，直到近景占满后才获得清楚结构。
- 帧 3922–3989（130.73–132.97 s）反向退场时同样穿过巨大半透明解剖曲面。数值上连续，但尺度接力的视觉依据不够。

**原因**

微观模型根位置用 `leftKidney` 包围盒中心加固定偏移 `(-.068,.026,.092)`，没有从真实肾动脉末端/皮质小分支确定连接点与切线。镜头从 kidney 距离 .80 降到微观距离 .09，再降到 .026，采用目标直线插值和对数距离。把大血管变透明解决了遮挡，但没有把这条路线变成可理解的解剖旅程。

**建议**

在实际肾动脉分支上确定一个观察点和局部方向，添加短的连续分支过渡：父血管 → 更细分支 → 微观壁层。进入时沿该分支的切线/浅弧线前进，旧父血管从边缘离开；微观模型首次成为主体时应至少占画面宽度约 25–35%，避免几秒钟寻找一个小玩具。微观阶段不需要把所有巨大的原始血管都留成满屏透明幕，只保留最近的一条连接作空间证据。

## 3. P1：肾单位示意的尺寸与锚点把内部结构表现成肾外玩具

**实际证据**

- **帧 4522（150.73 s）**：红色“肾小球”环宽度约为可见肾轮廓宽度的一半；蓝色管与集尿管直接伸到肾外轮廓右侧。没有皮质剖层、放大取样区域或微观进入动作，观众容易把它理解为贴在整个肾外面的真实等比例零件。
- 帧 4697（156.57 s）维持同一物体关系，粗大彩色球与管路强调了玩具感，细节推近没有增加真实的内部空间解释。
- 帧 4522 左侧还有上一段的小动脉微模型残留在红色入流管附近，进一步形成不同缩放尺度的模型共处一处。

**原因**

`buildKidneyDiagram` 直接用肾中心 `+(.015,.015,.055)` 并统一缩放 .17；没有真实皮质定位，也没有让镜头穿过组织窗口逐步转换尺度。`updateRenal` 全段维持这一尺寸。小动脉 activation=1，使它在别的肾局部镜头中继续出现。

**建议**

先用肾的截面打开一个皮质窗口，标明入球/出球细动脉进入的区域；随后镜头对这一处推进，微观肾单位接管画面。肾单位与粗略整肾背景不能以当前两个尺度同等清晰地并置。内部管路终点与解释层保持一致，避免蓝色管子悬在肾外；离开小动脉观察时关闭其剖窗或让其先离开视野。示意放大允许，但应把倍率变化做成可见动作。

## 4. P2：信号路线在近景变成真实管径级别的粗管与巨球

**实际证据**

**帧 5529（184.30 s）** 中青色信号球宽度接近主动脉剖管的三分之二，金色路线像一根独立的实体管，几个金球横跨肾前。它们压住肾脏，连接方向也比器官本身更抢眼。此处想表达的是化学/神经信号，视觉却像腹内新增的粗大管道。

**原因**

`buildSignals` / `addRoute` 使用世界尺寸固定的 .014 管半径和放大 1.8 倍的圆球；镜头推到肾上方距离 1.1 时，仍显示整条长距离路线。同样的信号资产在全身远景可读，近景就过粗。

**建议**

全身视角只保留低对比细线和少量光点；进入器官近景后由“局部受体亮起 → 小动脉肌层收紧 / 肾小管回收增强”接过叙述。需要保留路线时限制其视屏粗细与数量，近景采用更细的几何层级，不让球大过相邻真实血管。信号应在目标处触发动作，而非只循环沿装饰性管线移动。

## 5. P2：多段主动脉机位重复，局部动作缺少真正的观察路线

**实际证据**

帧 1537、1854、2046、2236（51.23、61.80、68.20、74.53 s），以及帧 6578、6742、6881（219.27、224.73、229.37 s）都以几乎相同的正面斜竖直长管承担不同内容。距离和方位有变化，但内壁、径向受力和局部弹性的层级关系并未换一个有解释力的角度；前后章节容易感觉在观看同一个展示模型。

**原因**

CameraPath 多个节点仍围绕同一 vessel 中心，以小幅方位改变和近似相同的 roll 维持构图；目标点没有沿流入端、壁面受力截面、弹性层、病变处等局部锚点依次行进。每个 clip 的五次插值在节点趋近零速，叠加的全局微幅正弦轨道主要是漂移，无法替代观察任务。

**建议**

给这一套真实模型建立不同的具体观察锚点：沿轴顺流看到排血到达 → 侧绕一个截面观察法向压力和径向扩张 → 沿壁浅滑观察回弹 → 保持局部尺度退出到分支。后面的斑块镜头直接追踪壁内病变，避免再次重复整段斜管“产品照”。相邻镜头保留有方向的移动切线，减少每句都重新启动的小推拉。做到这一步之后才考虑更细微的 roll 和景深。

## 已成立的部分

小动脉与主动脉已经分别建模，近景本身（如帧 3120、3325）足够清楚；VLDL → IDL/LDL → 受体回收在帧 7070–7458 中的过程可辨；脂蛋白底座在返回主动脉之后已消失。这些机制和有效近景可以保留。V5 优先解决的是“到达这些近景的路径”以及“不同尺度解释层共处时的比例与可见性”。

以上结论来自列明实际抽帧和源码，不声称完整人工实时播放。此前 V4 的技术连续性检查通过不代表上述空间表现与审美已经满足本轮升级目标。

3. **肝 7034 的有效主体出现仍较慢。** 此帧 VLDL 约占画幅宽度 5%，整体透明、低对比；旁白已经说“送进血液”。7095 的大颗粒清楚，可以略提前到达这种倍率，或在释放动作开始前让观察窗口先稳定到可读尺寸。此项比旧的前景堵塞轻，但不能只因画面干净就忽略讲解目标太小。
4. **小动脉 3325 的压差卡片覆盖右上分支末端。** 未盖住管腔主要机理，不是当前优先阻塞；建议最终把图卡上移或让管道整体低移少量，避免示意箭头/分支被卡片切掉。

当前结论：V5 已明显改善尺寸与场景间杂物，不建议回退。仍应完成真实肾动脉桥接、微观镜头到达时间、信号焦点层级后再作全片验收。
