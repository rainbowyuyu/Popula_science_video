# 拓扑优化核心仿真代码说明

截图来自项目实际运行的 `scripts/simulate.py`，为了便于阅读，图片把不影响主线的初始化和重复索引代码折叠了；公式、求解器和更新逻辑保持原意。

## 1. 建立材料和网格

```python
nx, ny = 80, 40
E = 70000.0
nu = 0.3
vol = 0.35
penal = 3.0
```

设计域被切成 80×40 个 Q4 四边形单元。`E` 是铝的杨氏模量，`nu` 是泊松比，`vol=0.35` 表示最后只允许保留 35% 的材料。`rho` 是每个单元的相对密度，范围约为 0.001 到 1。

## 2. 计算单元刚度

`bmatrix(xi, eta)` 把单元节点位移转换成应变，`D` 是平面应力本构矩阵。代码在 2×2 个 Gauss 积分点上累加：

\[
K_e=\int B^TDB\,t\,dA
\]

得到单个 Q4 单元的 8×8 刚度矩阵 `ke`。

## 3. 组装结构和施加载荷

每个节点有水平、竖直两个自由度。左边一列节点被固定；右上角三个节点共同承受 100 N 向下载荷，每个节点分到 `100/3 N`。

## 4. 有限元求解

```python
fac = emin + (1-emin) * rho**penal
K = ...
u[free] = spsolve(K[free, :][:, free], load[free])
```

这是 SIMP 的关键。单元刚度乘以

\[
E(\rho)=E_{min}+\rho^p(E_0-E_{min})
\]

低密度单元会被强烈惩罚。组装全局刚度矩阵后，`spsolve` 求解：

\[
K u=F
\]

返回的 `u` 是每个节点的位移，`ce` 是单元柔度贡献，`res` 用来检查平衡残差。

## 5. 灵敏度过滤

直接更新容易出现棋盘格。代码用距离加权矩阵 `H` 把邻域信息平均到一起，平滑单元灵敏度，让结构更连续。

## 6. SIMP + OC 迭代

每一轮先求位移，再计算柔度对密度的灵敏度：

```python
dc = -penal * (1-emin) * x**(penal-1) * ce
```

随后用 OC（二分搜索拉格朗日乘子 `mid`）更新密度。更新同时满足：

- 每个单元变化不超过 `0.15`
- 密度不低于 `0.001`
- 总体积保持在 35%

循环 100 轮，材料会逐渐从低效区域转移到主要受力路径，最后形成视频中的支架形状。

## 7. 输出和校验

程序把每轮密度、位移、von Mises 应力、柔度、反力和残差写入 `simulation.json`。同时检查残差、反力平衡、双倍载荷线性、刚度矩阵对称性和体积分数。

Three.js 读取这些结果负责可视化；它没有重新计算拓扑优化。Remotion 再把 Three.js 画面、旁白和字幕逐帧合成为视频。
