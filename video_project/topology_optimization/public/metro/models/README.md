# 可编辑地铁站模型

`metro-station.glb` 是本片程序化模型的静态、可编辑导出，可在 Blender 的「文件 → 导入 → glTF 2.0」中打开。列车、站台、屏蔽门、人物和行李/婴儿车保留为独立节点与网格，材质及站台标识贴图内嵌。

本文件供后续编辑与复用，**不参与本次视频渲染**。成片继续读取 `src/metro/World.ts`、时间线及物理数据；导出没有改动这些源文件。

## 导出状态与层级

- 使用 `doors` 章节的稳定中间帧 **7441**；此时列车停靠、站台与屏蔽门已经就位，门保持关闭。
- `Train_ThreeCars`：三节列车及车门、座位、转向架等子节点。
- `Platform`：站台、安全线、盲道、候车设施、灯具与标识。
- `PlatformScreenDoors`：屏蔽门与可独立移动的门扇。
- `Passengers`：四个人物。
- `Luggage_Stroller`：行李箱与婴儿车。

为了保持模型易于编辑，未打包流场、压力图、受力箭头、远处隧道演示件或摄影棚辅助场景。列车下方独立布置的轨道也保留在程序化视频源中，没有纳入这个选定装配集合。

这是规范化的视频模型坐标，列车宽度约 1.3 个模型单位；不是实测地铁工程尺寸。GLB 无时间动画、旁白、运镜或灯光。这些由原视频工程驱动，不能把静态 GLB 当成完整视频工程。

## 复现

在已有工程依赖环境运行：

```powershell
node scripts/export_metro_model.mjs
```

导出器在独立的 `tmp/metro-export` 中构建浏览器脚本，使用现有 Three.js `GLTFExporter`，无依赖升级；不创建 WebGL 渲染器、不渲染视频帧。完成后关闭独立浏览器与本地服务。

导出后从磁盘重新读取 GLB，使用 `GLTFLoader` 检查节点、网格、三角形数量、有限坐标、包围盒与选定装配层级；同时检查 GLB 二进制头与内嵌 JSON，确认贴图无需外部 URI。完整结果及源文件哈希见 `research/metro/model-export-audit.json`。
