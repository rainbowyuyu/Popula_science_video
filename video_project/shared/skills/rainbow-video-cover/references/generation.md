## 提交闭环

1. 确认用途、比例、留白、参考图角色和使用权。按目标比例生成，不支持精确尺寸时用同宽高比较大图再缩小，禁止拉伸。
2. 每种构图通常先一个候选，再针对实际缺陷迭代。提交前预留预计最高费用，在途和可能计费失败任务均纳入上限。
3. 保存无凭据参数、模型、地区、种子、任务／请求 ID、状态与时间；没有返回的字段不编造。
4. 未知提交状态先查原任务／结果，不直接重提；异步用 ID 查询。明确失败后才在剩余额度内重试，限流退避，禁止无限重试。
5. 成功后立即保存原始结果，检查主体和留白再排字；改标题不重生底图。
6. 留下选中／弃用原因。预算预留与费用预估不是结算账单。

中文、rainbow鱼、Logo、术语与数值后期精确排版；生成负责物件、材质、空间。查所有留白与边缘，发现乱码先修，不能假称无字。编辑时区分待编辑目标、风格参考、保留主体和品牌资产，明确不变项。
