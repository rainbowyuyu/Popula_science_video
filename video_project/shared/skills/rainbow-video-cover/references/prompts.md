# 提示词与案例

按实际任务组织：用途与比例 → 内容承诺 → 主体及其关系 → 按优先级排列的辅助元素 → 共享空间／透视 → 风格光照 → 标题留白 → 禁止项。准确文案独立保存在排版配置里。

## 单期

> 16:9 科技纪录片电影封面底图。左约 45% 为自然深蓝黑留白，不放物体、字或亮线。右侧真实奶油色短毛猫近景，眼睛和毛发清楚明亮；外缘少量有序透明体素，后方三层无边框薄层以同一猫轮廓表现特征抽象，不遮眼。共同透视和香槟金／青色轮廓光，浅景深，只有一个主焦点。不要文字、字母、数字、屏幕边框、HUD、水印或公式。概念视觉，不是假称模型实测特征图。

猫仅适用于对应任务。扩散可换成噪声怎样形成同一朵花／地貌，语言可用序列与指代关系，不把同一对象套给全部章节。

## 竖版

> 9:16 纵向电影封面。上方约 30% 留暗部标题空间，主体占中部至约 80% 高度，下方安静。对象足够大，脸与手不贴边。沿用已选横版的对象和材质，重新安排纵向姿态、相机和背景，不是裁成窄条。无文字和品牌。

较短竖幅 3:4 另查标题、主体与底部，不能默认下裁就适用。

## 合集

> 1:1《AI 进化史》概念封面底图。上约 29% 深蓝黑留白，底部约 10% 安静。中下部弧形石质实验台，香槟金路径贯穿。左侧真实浅色猫及同图特征层，右侧优雅银色机器人作为大视觉锚点。中间噪声形成金青色山体；有序薄片与声波玻璃带连接语言和声音；山体及建筑一部分实体、一部分点云和线框；前景棋盘与细金色分支表示搜索，小工具连接机器人操作；细弧线表示候选轨迹。所有物件共享照明和视角，主次清楚，不遮眼、脸和手，不是六宫格。无文字、数字、公式、Logo、假代码、界面、水印。电影摄影材质，不要霓虹泛滥。

此为成功案例思路。太挤时保留大章覆盖，减少重复道具、增加层次，不用缩小标题补救。新系列重新映射主题，不强制六章或猫与机器人。
