# 验收与交付

## 原图

- 主标题准确、断行有语义，作者名／轮廓正确，无缺字方块和模型乱写的字。
- 标题、副文、Logo 不碰撞，不被亮线／主体遮挡；主角眼睛、手和关键机制有阅读空间。
- 单期的任务明确，合集覆盖大章；没有假实测数字、伪论文或产品背书。
- 手、眼、机械关节、棋盘和阴影没有明显错误。照片和机制共享空间，而非加滤镜的小图拼贴。
- 尺寸、比例和 RGB 格式实测正确，不只看文件名。

## 缩略图

看长边 320 px 和 160 px 两档，主标题与主体必须辨认得出；160 px 的小字可以次要，但不能承担唯一主题说明。灰度辅助检查对比。每个比例独立看，模板检测不能理解图像，保护区要按实际主体调整。

修复顺序：内容与主视觉 → 构图遮挡 → 字号断行 → 光色 → 装饰。只改一个主要变量；可重排解决时不额外付费生成。

## 文件

按复杂度保留 `artwork/` 原底图、`covers/` 正式 PNG/JPG、缩略图、`layout.json`、提示词、无凭据生成参数／台账、必要来源记录；不建空目录。JPG 通常质量 92–95、RGB/sRGB。保存可编辑材料，不打包模型、环境、旧成片或凭据。

最终回复直接展示最终成图，给 PNG／JPG 绝对路径链接和准确尺寸，简述实际工具；提示词可作为链接留档。未生成方案、未验证参考和候选必须标明状态。机器检查通过不等于审美必然通过，也不表示用户批准发布。
