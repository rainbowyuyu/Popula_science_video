# 风格与多比例

## 视觉基准

深蓝黑 `#050b11`、象牙白 `#f8efdb`、香槟金 `#dec298`、柔和青色 `#b4d5d4`。主标题 Noto Serif SC，字重通常 700–850；解释 Noto Sans SC，500–650；可替换为用户指定的授权字体。保证主体轮廓、眼睛和对象关系在缩图可辨。

标题可有轻微金色纵向渐变、柔和阴影，不加厚描边或强烈金属浮雕。英文与中文字距分别看；署名和 Logo 共轴、色彩一致，作者名不可译成“彩虹鱼”。

| 输出 | 常用尺寸 | 构图起点 |
|---|---|---|
| 16:9 | 1920×1080 | 左约 45% 文案，右主角；标题约 100–145 px |
| 4:3 横版 | 1440×1080 | 比 16:9 更紧凑；左侧短标题、右侧主体，或上方标题下方场景；标题约 80–110 px 起试 |
| 9:16 | 1080×1920 | 上部标题、中下部主体、底部保留操作遮挡空间 |
| 3:4 | 1080×1440 | 独立安排标题和品牌，不能只截短 9:16 |
| 1:1 | 1080×1080 | 上方合集名、中下部完整场景、底部短主题行；主标题约 110–140 px |

尺寸不是平台永久规范，实际以用户规格和当前上传入口为准。四周约 5% 留白是起点，重要文字避开竖屏右侧操作区和极底部。跨比例先查主体包围盒，保不住主体与留白就独立生成；禁止非等比拉伸人物、猫脸或 Logo。

## 已有封面适配 4:3

从无字底图重新排版，保留已确认的文案、配色与品牌；不裁切带字成品后强行拉伸。4:3 是横版，不使用现成 3:4 竖版冒充。默认只新增请求的比例，不覆盖原版。

- 16:9 底图保留全高时，4:3 只容纳原宽度的 75%。先定主体关系，再平移这个裁切窗口；居中或贴右裁切不能当作所有底图的默认值。
- 主体安全包括猫眼、耳尖、爪与手指的交接，以及实验道具；裁掉纯背景或次要边缘通常比压缩主体更合适。主体安全不代表文字安全，玻璃特征层、高光和轮廓线也要避开标题。
- 1440×1080 可从左右 72 px、两行主标题、30–34 px 副文开始。长副标题主动分行，标题按实际字数重排，不能把整张 16:9 字体和坐标等比缩小。若保留文字会挤压主角，先缩短副文或换构图。
- 正方形合集转 4:3，可在保留全宽的前提下选取原高 75% 的窗口；优先压缩顶部空场和底部空白，保住机器人头、棋盘与承载空间。上方标题可以左对齐，避免为维持居中而覆盖右上主体。
- 当主体与文字留白无法同时保全，再生成或扩展无字背景；实际新增调用才计入新增生图费用。原图裁切重排应记录为“既有底图适配”。

本系列已验证的窗口：总览 16:9 底图 `[.25,0,1,1]`，第一章 `[.17,0,.92,1]`，合集方图 `[0,.10,1,.85]`。这些只适用于案例原图；不同底图重新看图确定。新版须再次检查原尺寸、320 px、160 px 缩略图。

## 合集怎样全但不挤

先列大章、代表对象、视觉关系和优先级。2–3 个大对象建立主叙事，其余用远景、材质变化、路径或道具补充。不要给全部技术同样大的图标。

《AI 进化史》可用映射，其他系列按内容改：

| 章节 | 对象与变化 | 避免 |
|---|---|---|
| 看见与选择 | 猫、像素、同图特征层、平衡杆、棋盘与分支 | 把随机特征图当实测；围棋和四子棋规则混淆 |
| 生成与创造 | 噪声形成地貌、候选和反馈 | 无对象的粒子爆炸；概念图冒充实验 |
| 语言与交流 | 有序序列、连接、语言与声音结构 | 乱码、假代码墙、过量聊天气泡 |
| 空间与时间 | 实体与点云／线框渐变、多视角 | 把空间高斯误称真实物体粒子 |
| 推理与工具 | 分支收束、可观察工具和结果 | 伪造内部思维链、假指标 |
| 预测并行动 | 机器人、操作对象、候选轨迹 | 畸形手指和关节、无来源产品背书 |

封面是概念隐喻，不承担完整技术教学。主题覆盖由记录检查，视觉仍要一眼抓到片名与主体。

## 常见返工预防

- 亮光穿过文字：先换位置／构图，再用柔和暗部承托。
- 只套滤镜：统一主体视角、光源、接触阴影和承载空间。
- 生成出意外字母：局部编辑或重新生成问题区域，不用大黑块敷衍遮住。
- 3:4 中副标题盖眼睛：重新裁切、重排文字，不继续缩小字体。
- Logo 独自悬浮：让署名作为标题系统的一部分，同一对齐和材质。
- 主标题很大却没内容：先改文案，不用更多金光补救。
