# rainbow鱼 · 视频与合集封面

让人先看懂“讲什么、为什么想看”，再发现画面细节。延续深蓝黑、象牙白、香槟金与克制青光的纪录片风格，用一个空间容纳主体和机制；封面承诺必须由内容兑现。

本技能独立使用，不需要先加载完整视频制作技能。当前用户选择优先；六章、猫、机器人是《AI 进化史》的案例，不能机械套给所有未来视频。仅创建／修改技能时不启动生图或发布。

## 确定封面类型

从用户要求、脚本／成片说明、已选封面和品牌资产提取主题、完成范围、平台、尺寸与生成授权。已知信息直接沿用；普通设计参数可合理推断时先做，不逐项询问。

| 类型 | 观众先读到什么 | 画面组织 |
|---|---|---|
| 单期教学 | 一个具体任务或问题 | 一个主视觉，辅助机制只取本期内容 |
| 系列预告 | 系列要解释什么 | 两个能力端点与连接关系，准确说明计划状态 |
| 合集总封面 | 系列名与总体价值 | 2–3 个视觉锚点，其余主题以次要物件融入 |
| 现有封面小改 | 已确认的主题 | 保留其余内容，只改指定文字、比例或对象 |

“包含所有元素”先转为主题覆盖表：涵盖所有大章，按重要性取舍物件，不把每个缩写、论文、代码和章节卡塞上去。计划中的章节可以成为合集主题，不能说成已全部完成。

## 制作闭环

1. **内容与钩子。** 确认观众问题、正片能兑现的答案和主视觉；封面少字，详细术语放发布标题或简介。需要标题策略／平台案例时读 [内容与平台](references/content-platform.md)。
2. **构图与比例。** 为主体、标题与品牌划定区域；跨横竖幅先重构场景，确认裁切安全才复用底图。读 [风格与多比例](references/design.md)。
3. **生图与精确合成。** 生成有留白的无字场景；中文、作者名、准确数值和真实 Logo 后期排版。调用前读 [生成与预算](references/generation.md)，需要构思时读 [提示词案例](references/prompts.md)。
4. **手机检查。** 同时查看原图、长边 320 px 与 160 px 缩略图；小图先读出标题和主体，副文不能挡住眼睛、手或机制重点。按 [验收与交付](references/quality.md) 检查。
5. **交付。** 输出要求的每个尺寸，PNG＋高质量 JPG；保存底图、排版配置、提示词和来源／生成记录。直接展示成图与绝对路径链接，说明实际生成工具。上传平台、推送仓库、修改可见性或发评论不属于自动后续动作。

## 关键约定

- 署名严格为 **rainbow鱼**；使用 [用户矢量轮廓](assets/rainbow-vector.svg)，不能让模型重画成别的 Logo，也不擅自用于其他作者。
- 电影感来自构图、材质、光线、层次；去掉无意义 HUD、LIVE、小屏幕边框、密集小字、厚重浮雕和霓虹。重要文字大且清楚，不遮主角。
- 合集多主题共享透视、照明、桌面／地形／路径；不是六宫格拼贴或给现成小图套滤镜。
- 概念封面不冒充实测图、真实设备、论文或官方背书；确需数字与论文时采用核实的原件，不让模型编造。来源和生成事实留档，不强制全部挤到封面。
- 吸引力不能来自虚假战绩。查询平台时记录日期与来源，区分事实、样本观察和推断，不承诺“必爆”。
- 先少量候选，再针对主要缺陷修；改标题不重生底图。未知提交状态先核查，不重复付费。
- 技能没有密钥、永久预算或账号授权。当前会话已有授权继续有效，无需重复询问；新任务不能直接把历史预算当作批准。

## 离线排版工具

`scripts/compose_cover.py` 不调用生成 API，支持等比裁切、精确字体、手动分行、轻微渐变、Logo、主体保护区、文字冲突检查和缩略图联系表。依赖 Pillow；SVG Logo 另需 PyMuPDF。

复制 [正方形合集模板](assets/collection-square.json)、[16:9 单期模板](assets/episode-landscape.json) 或 [4:3 横版模板](assets/episode-4x3.json)，填入实际图片与字体。**4:3 默认 1440×1080，区别于 3:4 的 1080×1440。** 相对路径按配置文件目录解析。模板只是起点，必须看图后调整主体保护区与文字位置。

```powershell
python <skill>/scripts/compose_cover.py --config <project>/cover/layout.json --out-dir <project>/cover/output
```

字体必须明确提供，不静默换成不支持中文的字体；输出已存在时默认拒绝覆盖，同名重排可用 `--overwrite`。只生成本次所需比例。用法见 [排版工具](references/compositor.md)。
