## B站

标题：每天5分钟科普｜拆开632米上海中心：核心筒、巨柱、双层幕墙和阻尼器怎样一起工作？

一阵风从玻璃外衣吹过去，最后会把力送到哪里？
这期根据公开建筑剖面、设计方资料和施工方论文，重建一座可分层拆解的上海中心。沿着同一座模型，从桩筏基础往上，看核心筒、巨型框架、空中大堂、旋转幕墙和调谐质量阻尼器怎样相互配合，再回到真实建造的先后关系。

内容顺序：构件分组展开与原件聚焦讲解 → 回装 → 地下基础 → 核心筒 → 巨柱与伸臂桁架 → 双层幕墙与垂直分区 → 抗风形体 → 阻尼器 → 建造过程。

无需结构力学基础。看完后，希望你抬头看楼时，也能想象出它里面那条连续的传力路径。

制作：rainbow鱼。模型与动画采用Blender、Three.js、Remotion制作；结构计算实际调用Zwind的OpenSees组件；配音与制作流程使用AI辅助。

本片依据公开资料重建可拆解的教学模型，沿同一座GLB模型分组展开、聚焦原件并回装。987是模型语义分组数，含合并构件和教学环境，不是987个制造单件。主结构由6,037个节点、5,412个墙壳及1,852个梁杆构成，实际执行重力、双向静风及60秒完整自由度Newmark动力计算；楼面采用平面内刚性约束，地面固定。动画展示有符号的风致应力增量与放大48倍的整体侧移，阻尼器特写使用1倍运动比例。地下为独立单桩算例；绕流采用30 m/s均匀来流的三维平均流场，限于定性推吸、绕行及低速区，未将CFD压力输入结构求解器。各工况独立，未执行Diffusion反演。本片是公开资料约束的线弹性工程重建，不是竣工模型或实楼安全验算。完整来源、假设、核验记录和计算范围见《制作说明_V10.md》及项目V10计算说明。
