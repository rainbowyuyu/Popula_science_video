## 对画面的具体建议

1. 风荷载箭头附着于同一时刻变形后的实际加载节点。它表示合力 N，不能用任意立面点代替加载点，也不能把它标为表面风压 Pa。
2. 核心筒用截面弯矩展示两侧受压/减压或正应力包络；这个对称模型的净风致轴应力增量近零，直接用它涂核心筒会看不出受力。
3. 巨柱、角柱、伸臂及环带用固定色标的有符号轴应力增量。局部特写可用角色专属固定量程并写明单位；不要逐帧归一化。正增量也可能只是减少原有压力。
4. 优先特写 `M_Z04_C05_OX2` 伸臂（235.1 m 高、50 s）与 `M_Z05_C01_BX1B` 环带（309.8 m 高、59.1 s）；具体 mesh ID、坐标和时刻见 `visualization-contract.json`。保持几何、变形、箭头、相机锚点同步。
5. TMD 使用同一 `tmd.time` 上的相对运动、弹簧力、阻尼力和耗能。核心截面数据有自己的 `coreWindSection.time`（1 s），不能误用 0.05 s 的 TMD 时间数组。
6. 单桩依次呈现“桩头荷载—桩侧反力—桩端反力”；土体只画分层与界面反力，不画并未求解的连续土体体应力云图。

## 文件与复算

- `input-manifest.json`：原始脚本/输入的冻结快照、后端二进制 SHA 和生产文件复算前哈希。
- `frozen-project/`：14 个输入和脚本的原样副本。
- `logs/`：本轮四个求解阶段日志、阶段完成状态；`report-console.log` 为非权威的人类可读输出，不纳入哈希清单。
- `recompute-report.json`：数值差异、校验、时刻、边界和限制。
- `visualization-contract.json`：实际部件峰值位置与可视化规则。
- `output-manifest.json`：结果和证据文件的 SHA256 与精确路径。
- 大体积结果约 1.4 GB 位于 `C:/Users/zju/.codex/visualizations/2026/10/08/01a11ae1-4ffb-79e2-b2fc-3add8874f339/shanghai-physics-v8/`；D 盘只保留检索证据、输入快照、日志和报告。

入口 `recompute.py` 可依次执行 `tower`、`environment`、`pile`、`pilefine`，使用已冻结输入和显式 C 盘结果路径；`prepare` 仅首次冻结，已有清单时拒绝覆盖。然后运行 `build_report.py`。生产字段只读取，全部输出隔离保存。

本轮没有重新运行 CFD，没有把 OpenFOAM 表面压力耦合到结构荷载，也没有使用不适配上海中心的 offshore Diffusion 权重反演荷载。已有 CFD 仍限于先前验收的教学平均流场；不得把此复算报告当作工程级 CFD 或实楼安全认证。
