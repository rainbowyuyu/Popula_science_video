# V10：实际连接的墙壳—巨柱—伸臂模型

本目录是按公开结构资料自行重建并实际求解的弹性结构模型，不是下载的原作者模型，也不代表竣工设计或安全验算。输出保持隔离，由主任务审核后绑定视频。

## 实际完成的建模

- 核心筒采用四节点 `ShellMITC4` 与 `ElasticMembranePlateSection`，共享墙交点节点；九格、削角、十字形、上部三格形态按公开资料重建。没有中心等效梁。
- 八根巨柱、四根下部角柱用三维弹性梁；伸臂及环带为钢轴向杆，96个伸臂墙端直接接到墙壳节点。
- 实际楼层与公开加强层高程设置楼板平面约束；楼层重力分配到墙、柱，平面质量及极惯量加到楼板主节点。构件自重、结构质量单独计算且只计一次。
- 坐标为 Three.js Y-up，长度m、力N、质量kg、时间s。使用本地 `D:/python_project/os2zwind/bin/opensees.pyd`，OpenSees 3.8.0 / Python3.14；没有安装或切换备用求解器。

粗网格共6037节点、5412墙壳、1852梁杆；横向加密5m→2.5m后为11509节点、10824墙壳，梁杆数量不变。共计9个独立搭建高度重力工况、完整重力、X/Z双向风、正反向和半载校验。

## 计算依据与边界

几何来源、冻结参数和SHA256在 `inputs/parameters.json`，来自Su等2013公开图1—6及已有公开设计资料。仅读取公开几何重建，不读取用户EDB、ETABS模型或其他楼的FE模型。

未公开的截面插值、E值、楼面荷载、质量、桁架面积与控制层内的弦杆位置均是显式假设。墙体视为无洞口连续弹性板；没有钢筋、开裂、屈服、徐变、连接失效或几何非线性。239.4m切形处8个新斜墙底边内部节点通过墙壳向端部传力，没有显式转换梁/板，该处局部峰值不作设计结论。基础固定在地面，不计算地下室、桩筏土共同作用。旧独立单桩教学算例可单独保留，不能说成与本楼耦合后的沉降。

结构风载独立采用U500=30m/s、空气密度1.225kg/m³、Cd=1.2和注明的幂律风速分布，总水平力29.1893MN，基底倾覆矩9.55456GN·m。此荷载没有从未经定量认可的CFD压力反算；流场只作定性展示。

## 已执行验证

膜拉伸patch在1/2/4分网下的位移及应力误差小于2e-15。横向受弯壳条带的挠度随10/20/40分网稳定，最细网格与细长Timoshenko梁参考差0.483%；该参考是细长条带近似，不冒充有限宽板的精确解。三维悬臂梁基准相对误差3.46e-16。

重力及两个风向的基底力/矩平衡、132个水平切面的内外力平衡均实际核验；风向最大截面力相对残差低于1e-9。反向和半载位移、转角、墙壳合力及节点内力满足线性关系，保存数组的差为0。

横向加密后：X风峰值位移差0.114%，Z风差0.132%，重力墙节点位移差0.140%；第一周期9.08805s→9.09272s，变化0.0514%。这里验证整体响应的网格敏感性，不宣称接头局部应力收敛。没有为了凑周期调整E或质量。

## 动力与动画接口

实际整体Newmark法积分（gamma=.5、beta=.25），不是静态变形乘正弦。先收敛重力，再开始风荷载历史；动态输出全部是相对重力的增量。60s、dt=.05s、1201帧记录真实墙节点/梁节点位移与转角、杆件轴向应力及墙面纵向膜应力。原生壳四积分点合力以1s间隔另存，静力工况均保存原始积分点数组。

1000t TMD的X质量从支点扣除一次并放到独立运动节点；弹簧按本模型第一模态调谐，内阻尼比假定8%。全局Rayleigh质量阻尼也作用于TMD节点，导出中明确记录附加绝对速度阻尼及单独耗能；8%不表示装置总阻尼或真实安装常数。装置力、加速度、支点位移由同一步实际求解输出，复核质量运动方程。

动态工具检查修复了两个细节：本地求解器 `reactions` 只接受一个选项，`-dynamic` 已包含惯性/阻尼；Path序列增加 `-useLast` 防止末点浮点超界导致突然卸载。初次未完成数据仅存于 `coarse/dynamic-incomplete-v0`，禁止绑定或当作最终结果。

完整数据格式见 `EXPORT-INTERFACE.md`。生产形状导出位于 `export/`，不直接修改public。墙面采用四节点形函数和真实墙壳转角；楼板主节点仅提供已求解的平移/扭转，其固定的非平面DOF不得当成墙弯曲转角。墙应力和梁轴力分开定义，不把等效梁应力涂成局部墙体应力。

最终数值、哈希和动态验证以 `export/run-summary.json`、`coarse/dynamic/summary.json` 为准；没有完成文件时不得宣称动力导出已经完成。
