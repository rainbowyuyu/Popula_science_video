# 上海中心 V4 音频研究与片头衔接方案

状态：只读研究稿（2026-10-09）。

本稿基于 V3 冻结的 `public/master.wav`、`src/timeline.json`、48 句旁白、194 条字幕、现有《向云生长》配乐及 `research/visual-v3/audio-readonly-review.md`。本轮不修改 TTS、音频、字幕、时间轴、渲染素材，也不重新检索或替换配乐。任何建议在实施前都要先做短 A/B 试听，并通过实际听审决定是否重合成。

## 片头目标

V3 的第一句直接进入“六百三十二米的上海中心”，画面可以成立，但真实城市景观没有给观众一个落脚点。V4 建议从黄浦江边的真实上海中心景观开始：先让观众看见江面、行人尺度、交通和玻璃幕墙的反光，再把摄影机沿幕墙的旋转边缘带入同一座塔的 3D 拆解模型。叙述只提出一个可观察的问题，直到问题落下才揭开结构；不要在前几秒堆算法、模型或软件名。

## 推荐片头（需要新旁白，先做试听）

这是一个替换 s001 的候选稿，约 7–8 秒，显示文案仍可使用标准术语；不要把下面文字直接写入冻结时间轴：

> 从黄浦江边看，上海中心像一条向上旋转的曲线。风一来，这么细长的一栋楼，靠什么站得住？

建议把“旋转”读作 xuán zhuǎn，“风一来”的“一”在语流中轻读。句尾“靠什么站得住？”后留约 150–220 ms 的可听停顿，再让镜头和声音一起穿过幕墙进入模型。接原 s002「把玻璃外衣轻轻揭开，里面远比想象中热闹」，语义关系是：真实外观 → 玻璃外衣 → 结构内部；不需要再加“现在我们来看看”之类的制作口吻。

如果 V4 需要完全保持 V3 音频时长，可不改旁白：将真实景观放在现有 s001 的 0.40–8.03 s 下方，保留原句“六百三十二米的上海中心……”，并在“站得住？”后的空隙用幕墙反光 match cut 接 s002。此方案风险最低，但故事感和现场感弱于推荐新稿。

### 推荐时序（新旁白版本）

| 时间（建议，不是冻结时间轴） | 画面 | 声音与叙述 |
|---|---|---|
| 0.00–0.80 s | 江面与城市远景，上海中心在画面右侧，不急推近 | 真实环境底：很远的城市低频、轻水声；不进 BGM，不加冲击音 |
| 0.80–2.80 s | 轻微横移，行人/船只提供尺度，塔身反光逐渐占据画面 | 旁白第一句从环境中出现；环境自动让出中频，不要用突然静音切断城市感 |
| 2.80–5.70 s | 沿幕墙旋转边缘上移，玻璃分格和天空反射连续运动 | “曲线”“风一来”对应镜头上移和一条自然风声；BGM 以稀疏两拍/四拍铺底，仍比人声低约 17–19 dB |
| 5.70–7.70 s | 进入幕墙近景，玻璃反射转成同角度的 3D 外幕墙 | “靠什么站得住？”后保留 150–220 ms 呼吸空间；一个很短、无低频轰鸣的空气 whoosh 连接两种介质 |
| 7.70–10.20 s | 反射中的外幕墙沿原运动方向退开，内层楼板/钢梁自然显露 | BGM 在切入模型时恢复半拍；s002 从“把玻璃外衣轻轻揭开”接入，不能让结构突然出现 |

真实景观素材应有明确来源和许可记录；若使用生成画面，必须标记为情境素材，不能把它当作现场测量或结构证据。镜头中的上海中心高度、外形和周围城市关系要与 3D 模型保持同一朝向，避免真实塔身与模型的旋转方向接不上。

## 环境声与明亮画面的混音策略

### 分层

1. **城市底床**：极低电平的远处车流、人群和江面空气声。它只承担“这里是真实城市”的空间感，不应在旁白停顿处突然消失。低频交通隆隆先做高通（约 70–90 Hz 起点，按素材调整），避免与配乐和旁白混浊。
2. **近景江风/水声**：当镜头靠近幕墙时，增加窄幅风声和一层很轻的玻璃反射高频；不要使用暴风或灾难音效。风声的立体声宽度随镜头从远到近增加，切入模型时自然收窄。
3. **结构接力声**：幕墙打开、剖面露出和传力线出现时，使用短而柔的木/金属摩擦或空气 whoosh。每个声音都跟随可见动作，持续 150–450 ms；禁止无画面来源的连续粒子音和重低频冲击。
4. **模型内部底床**：进入结构模型后，把真实城市底床淡出但保留一丝空间尾音，用更安静的室内空气感承接。不要用“进入电脑世界”的电子故障音，避免把工程演示做成游戏界面。

### 相对电平与频段（实施前试听）

- 以当前 V3 母带约 −15.01 LUFS、−1.50 dBTP 为参考；若文本和镜头不变，不因“更明亮”而整体推高响度。
- 旁白活动区间与 BGM 保持约 16–19 dB 的平均差，沿用当前约 17.91 dB 的可读性结果。BGM 的 2–4 kHz 做轻微侧链避让，旁白进入前约 80–120 ms 提前压低，句尾约 400–800 ms 平滑恢复，避免逐字抽吸。
- 环境声在旁白下方再低约 8–12 dB；片头无旁白的 0.00–0.80 s 可短暂抬高，但应在首个字前自动回落。环境声也要测真峰值，不能因素材峰值尖锐而盖住字头。
- 真实景观的阳光画面通常高频更丰富；不要用高频增强代替明亮感。优先使用干净的 80–180 Hz 低频空间、温和的 250–400 Hz 去浑浊和少量 3 kHz 旁白避让，具体以素材频谱和试听为准。
- 不额外添加夸张混响。旁白保持现有个人参考音色和清晰辅音；环境声通过左右声道、近远层和镜头距离制造空间，不把声音处理成广播腔。

### BGM 节奏

当前《向云生长》为 88 BPM，适合结构逐层向上搭建。V4 若继续使用它，建议保留同一首曲的空间，不另换歌：

- 片头真实景观使用前 2–4 小节的稀疏织体（可只留钢琴/竖琴/短拨弦），不在第一帧落强拍。
- “风一来”处让轻微节拍进入；“靠什么站得住？”后在 150–220 ms 停顿中留出空气，再在模型揭开时回到完整和声。
- 0–30 s 只让鼓点/拨弦承担镜头推进，避免连续大鼓、铜管或低音合成器压住城市实录。
- 地下基础段可把配器收窄并降低约 1–2 dB；核心筒、伸臂和风段逐步增加高频颗粒；阻尼器段降低节拍密度，让“相对摆动”有听觉余地；施工段再恢复脉冲。每次变化以镜头动作和叙述因果为依据，不按章节机械换曲。
- 若确实重编片头，必须先保存新版本音频和 hash，并与锁定母带分开；不把调速或改名称为“新曲”，也不在未核实许可时替换当前曲目。

## 术语与口语自然化建议（只研究，不重合成）

以下建议来自 V3 只读报告中的文本观察。它们不是“ASR 拼写不一致就重录”的触发条件；只有人工/可验证试听确认字音或语义不自然时，才进入候选试听批次。

| 位置 | 当前句子中的问题 | 可试听的自然写法 | 说明 |
|---|---|---|---|
| s003 | 「每一部分都接着下一部分的力。」“下一部分”关系略抽象 | 「每一部分接到的力，都要继续往下传。」 | 让“从上到下”的传力方向更清楚，与 s016/s033 衔接 |
| s007 | 「桩和周围的土一起承担荷载」术语正确但入口稍硬 | 「桩和周围的土一起分担楼的重量，这在工程上叫荷载。」 | 先说生活词，再落术语；需核对画面标签是否同时出现“荷载” |
| s008 | 「厚达六米的混凝土筏板」观众可能不知道筏板是什么 | 「桩的上面，是厚达六米的一整块混凝土底盘，工程上叫筏板。」 | 保留 fá bǎn，避免用“伐板”作为观众文字 |
| s012 | 「钢材和混凝土一起工作：往下……往侧面……」连接词字幕较短 | 「钢材和混凝土一起工作：重量往下传，风的推力往侧面分开。」 | 若镜头能同时显示两条路径，语流更顺；需重新安排字幕，不在现片直接替换 |
| s014 | 「只靠中间这根硬骨头，离六百多米的目标还差一把力。」“目标”略像项目口号 | 「光靠中间这根硬骨头，还不够撑住六百多米的高度。」 | 更直接，避免“目标”被理解为要达到的指标 |
| s018 | 「把它们接起来的，叫伸臂桁架。」术语出现稍突然 | 「把核心筒和外圈柱子接起来的，是伸臂桁架——像六座小钢桥。」 | 保留 héng jià；“小钢桥”先给直觉图像 |
| s021 | 「环带桁架」与 s018 连续出现，术语密度高 | 「再绕外圈加上一圈环带桁架，零散的构件就连成共同受力的框架。」 | “一圈”帮助观众理解空间关系 |
| s024 | 「人真正活动的房间，包在更里面一层。」搭配略生硬 | 「人活动的房间，还在里面那层玻璃后面。」 | 需让镜头明确指向内幕墙，避免“包”与“幕墙”关系不清 |
| s027 | 「最终累计转过一百二十度。」偏书面 | 「从底到顶，它累计拧过一百二十度。」 | 仅在资料确认“底到顶”的累计定义后使用；不夸大为每层同角度旋转 |
| s035 | 「这位帮手，叫调谐质量阻尼器。」术语先于作用 | 「楼顶还悬着一块约千吨的重物，名字叫调谐质量阻尼器。」 | 先看见重物再命名；tiáo xié 需在词典/试听中确认 |
| s042 | 「巨柱通常落后核心筒六到九层，楼面再落后巨柱四到七层。」数字密度较高 | 「施工时，核心筒先走；巨柱落后六到九层，楼面再落后四到七层。」 | 保留数字，减少“通常/再落后巨柱”重复；jù zhù、luò hòu 需试听 |
| s044 | 「连伸臂也要等合适时机再锁定。」略像说明书 | 「伸臂也不能一装上就锁死。」 | 画面必须显示择时锁定，不能把示意说成实际施工步骤的全部 |
| s048 | 「桩、梁，和云里的重物，一起撑起……」可能让人误以为阻尼器承重 | 「桩把力交给土，梁柱托住楼层，楼顶的重物让摇晃慢下来。」 | 与 s038 的“阻尼器主要照顾舒适度”保持一致；是更准确的收束 |

## 关键多音字/术语清单

V3 已用 TTS 读音控制文本处理；V4 应优先使用可验证的词典/音素提示，字幕始终显示规范术语。不要把同音替换写进观众字幕，也不要仅凭 ASR 的近字重合成。

- 片头：`旋转` xuán zhuǎn，`高处` gāo chù，`细长` xì cháng。
- 基础：`浅层` qiǎn céng，`桩` zhuāng，`荷载` hè zài，`筏板` fá bǎn，`混凝土` hùn níng tǔ。
- 核心与框架：`核心筒` hé xīn tǒng，`伸臂桁架` shēn bì héng jià，`环带桁架` huán dài héng jià，`轴向力` zhóu xiàng lì，`转动` zhuǎn dòng。
- 形体/风：`累计` lěi jì，`旋转` xuán zhuǎn，`涡` wō，`晃动` huàng dòng，`步调` bù diào，`调谐` tiáo xié，`强风` qiáng fēng，`削弱` xuē ruò，`弯曲/曲线` qū。
- 施工/结尾：`爬升` pá shēng，`浇筑` jiāo zhù，`落后` luò hòu，`重新` chóng xīn，`藏` cáng，`重物/重量` zhòng wù/zhòng liàng。

重点试听而非自动重录的疑点：s006「浅层」、s008「筏板」、s012「往下」、s013「竖起/弯曲」、s014「这根」、s035「调谐」、s040–041「爬升/浇筑」、s042「巨柱/落后」、s043「三分之一高」、s044「伸臂/巨柱」。V3 的 `subjectiveListeningChecked` 与 `pronunciationListeningVerified` 仍为 false；本计划不把 ASR 结果包装成已完成听审。

## V4 实施前验收清单

1. 先录制真实景观 10–15 秒和新片头候选旁白，做只有环境声、只有 BGM、完整混音的 A/B；确认环境声不会盖字头。
2. 将真实景观、幕墙近景和 3D 模型做同向 match cut，确认风声、镜头速度和 BGM 强拍在同一动作上；不得靠黑场/淡入淡出隐藏断裂。
3. 对新片头旁白执行逐句 ASR 只是覆盖筛查；多音字由人工听审或可复核的音素结果确认，不能因“flags=[]”直接合入正式母带。
4. 若改写 s001 或其他句子，单独建立候选目录、保留旧 SHA，待试听和字幕重排完成后再决定是否生成 V4 时间轴。不要覆盖 V3 的 master、timeline 或字幕。
5. 最终混音保持人声清楚、环境声有空间、BGM 不抢中频；导出 AAC 后重新测片内 LUFS、真峰值、时长和首尾同步。音频试编码数值不能代替最终视频检查。
