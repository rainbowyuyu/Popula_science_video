# E2O-SEAOC2020 论文方法审阅

**结论：可借鉴“ETABS 数据提取 → 保留编号与连接 → OpenSeesPy 建模 → 分级交叉校核”的工作流；本文不能证明原 E2O 库已能完整转换上海中心的分层壳、组合巨柱和伸臂体系。** 本次仅阅读论文并核对页面，未运行作者算例、未审查代码、未修改 src。

## 转换方法与输入前提

- **p1、p5–7**：先有工程师建立的 ETABS 模型。CSI OAPI 的 `cDatabaseTables` 导出几何、连接、材料/截面、组装节点质量、重力加载等数据库表；ETABS 不能完整导出的非线性骨架参数由配套表格补充。Python/pandas DataFrame 整理后调用 OpenSeesPy 建模。不是由建筑图片或外观网格自动恢复受力模型。
- **p6–7**：节点 ID 与 ETABS `UniqueName`、坐标精确对应；逐行调用 `node()`，以类似方法生成弹性框架与零长度转动弹簧。节点、杆件和铰是显式连接关系，便于保持可追溯映射。
- **p5–6**：梁铰在 ETABS 中刻意建成独立 link，而非仅向 frame 指派内部铰，以显式表达铰位置与邻接节点。OpenSees 用 `Bilin`/modified IMK 双线性材料表示集中塑性；柱、节点域保持线弹性。串联铰弹性刚度设为梁刚度约三个数量级，以减少附加柔度。该设置是本文特定模型方案，不应不经检验套用到任意体系。
- **p5、p12**：“one click”指**按其建模规则准备好 ETABS 数据后**自动生成 OpenSees 模型，不能理解为任意 ETABS 对象/材料/约束均无损转换。

## 原例结构与实际校核

原例为 FEMA P-2006 第8章的 **5层周边钢抗弯框架**，217 ft × 217 ft 平面，首层16 ft、标准层14 ft 3 in；1985年建成，pre-Northridge WUF 连接、刚性楼板。中央列柱表示重力体系和质量；本研究**省略重力荷载**（p3–5）。输入仅展示 Modified Borrego Mtn RSN36 地震记录的1、3、5倍缩放（p5）。

| 校核层级 | 本文比较量 | 已验证的范围与限制 |
| --- | --- | --- |
| 模态，p7 Table 1 | 三软件前4个主导模态，累计质量参与率超过90%；第一周期 OpenSees/Perform3D/ETABS 为1.6378/1.6372/1.6340 s | 检查质量、弹性刚度和几何匹配；不是材料非线性已匹配的充分证明。 |
| 小幅线性时程，p7–8 Fig.9–11 | 屋顶质心位移、基底剪力、层间位移角 | GMSF=1，结构保持弹性，结果相近；本文没有给出通用数值验收阈值。 |
| 非线性静力，p7 Fig.8 | 梁铰弯矩–转角曲线与输入骨架 | 检查铰参数/分配；p8明言没有做循环推覆，不能据单调骨架吻合断言循环滞回相同。 |
| 非线性时程，p9–10 Fig.12–15 | 铰塑性转角、屋顶位移、基底剪力、层间位移角 | GMSF=3时梁铰尚未进入强度下降段；OpenSees切线刚度Rayleigh阻尼与Perform3D compound处理后较吻合，两者约10分钟。 |
| 更强非线性，p10–12 Fig.17–20 | 铰滞回、峰后及整体响应 | GMSF=5进入强度下降，两套滞回模型不同，作者**未取得良好的局部滞回匹配**；整体差异较小不等于局部正确。 |

阻尼需单独核验：初始刚度 Rayleigh 阻尼结合集中塑性可能产生虚假阻尼力；本文比较切线刚度和 Perform3D compound/pseudo-penalty处理（p2、p8–10）。modified IK针对延性宽翼缘钢梁，不能直接代表脆性WUF连接，需试验标定（p11）。Newton类求解也需收敛准则、步长与失败回退策略，OpenSees有这些能力不等于本文转换库已自动完成可靠性保证（p3）。

## 与上海中心的差别、可以采用的部分

| 项目 | E2O 本文已经演示 | 上海中心所需的额外处理 |
| --- | --- | --- |
| 核心受力构件 | 弹性钢框架 + 梁端零长度集中铰 | 核心筒及连梁的多层壳、钢筋方向/层厚/本构、组合巨柱、伸臂与环带、构件局部轴及真实连接；不能由梁铰替代。 |
| 体系范围 | 五层刚性楼板钢抗弯框架 | 超高层壳–巨柱–伸臂耦合；质量分布、楼板传力、刚域/偏置、边界和重力初始状态须保持。 |
| 非线性/加载 | 梁非线性；柱和节点域弹性；无重力荷载 | 若做实际轴力/侧移响应，需明确重力、轴弯耦合、P–Δ、材料及约束适用性；风压映射/流固耦合并非本文的地震算例内容。 |
| 自动转换能力证据 | 节点/弹性框架/集中转动弹簧 | **p13把支撑框架、剪力墙、RC框架、柱/节点域非线性列为未来工作**；原文没有证实已支持目标楼所需的分层壳与组合构件。 |
| 计算能力证据 | Rayleigh阻尼、此算例运行约10分钟 | **p13将模态阻尼、跨核模型分区并行、GPU求解列为未来工作**；不能把OpenSees平台的一般能力写成该E2O版本已具备。 |

上海中心目标模型的独立来源为 Lu et al. 2015 原文（已在 `../discovery/paper-links/` 核验）：PDF第32页记载53,006节点、48,774纤维梁、39,315多层壳，81个H纤维截面和148个壳截面。该模型规模/类别不属于E2O这篇五层钢框架的已验证对象。

可直接吸收的是：**保留源 ID 和坐标 → 显式记录每种对象/材料/约束的映射 → 不支持项停止并报告 → 核对质量与支座反力 → 模态 → 线性加载 → 单调及循环部件试验 → 整体非线性时程**。其中反力/循环等为针对本项目提出的补充验收建议，并非声称论文已全部实施。若没有上海中心原始 ETABS/结构数据，E2O不会补出缺失的工程输入。
