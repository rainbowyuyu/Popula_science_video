## 实现边界

- 保留 V10 成片、冻结 bundle、锁和计算结果。
- 原几何含 987 个语义组；语义组可能合并多根杆件，不能称为 987 个独立加工零件。
- 开场用独立相机覆盖，不改原 CameraPath 的样条，以免改变后段。
- 摄影机使用连续路径，模型位移以帧号决定，保留真实比例和身份。
- 照片为既有 CC0 原照的 Qwen 扩展素材，仅作情境，不作为实测或计算证据。
- 音轨和完整时长沿用已验收 V10：15,712 帧，30 fps，523.733 秒。
- 如复用 V10 后八段，逐段记录来源、SHA256、帧范围，不冒称重新渲染。

## 验收

1. 静帧检查：照片交接、最大分散、完整回装、各部件离位/停留/归位。
2. 连续开场序列：检查镜头速度、前后遮挡、标签、出入画路径和身份连续性。
3. 后段隔离检查和首段拼接处连续帧检查。
4. 新成片完整解码、音频包一致性、最终音频响度与时长检查。
5. 记录实际观看范围，不把抽帧审查写成完整实时观看。
