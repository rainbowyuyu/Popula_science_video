# 上海中心教学模型：图纸依据与重建边界

本模型服务于上海中心拆解科普。它依据公开建筑设计图、设计与监测团队论文重建，并接入实际执行的本地 Zwind/OpenSees 等效结构计算，展示空间层次、主体构件联系与传力机理。它不是施工级BIM、竣工测绘或安全评估模型。已核实参数见 `research/structural/verified-parameters.json`，完整证据与假设见 `docs/structural-evidence.md`，求解边界见 `research/structural/solver-review.md`。

本文已对齐 v7 final3 的生产输入；本轮最终 MP4 尚待编码与独立验收。最新状态以 `docs/UPGRADE_V7_STATE.md`、输入锁 `research/visual/v7-final-production-lock3.json` 为准。模型、结构与独立流场证据分别记录，不能用旧版本影片验收替代本轮。

## 模型参数中必须区分的近似

上表数值已在对应公开资料核实，但资料包含设计与施工阶段版本，并非完整竣工尺寸表。

当前模型分区采用 `[0, 33.45, 99, 173.70, 239.40, 314.10, 393.30, 465.40, 542.00, 580] m`：8道加强层标高来自Su Fig.1文字标注，580 m是结构高度；模型底部0 m是重建坐标基准，原图地面参考标为−1.00 m。这些值已替换早期的剖面像素估计。Su Fig.6标出的楼号/高度作为层高锚点，锚点之间仍采用插值。加强层标高不能直接当成全部伸臂上下弦标高；模型统一8.6 m桁架高度和区内落位仍为假设。

已核实的巨柱数量、截面端点、核心30 m网格/形态/墙厚范围、947根桩及52–56 m桩长范围、TMD的1000公吨质量，不再笼统归为未知参数。仍需区分下列重建近似：

- 巨柱精确轴线、局部截面方向、中间楼层截面与壁厚分级表、核心切角坐标及真实开洞；当前按公开图的拓扑和有限端点重建。
- 内部圆形楼面采用Chen 2013的直径83.6→42 m；Zhu稿为82.2→46.5 m，可能有定义或版本差异。当前选择Chen并保留冲突，不能称唯一竣工值。端点间线性收分是假设。
- 底部外轮廓、顶部收分、幕墙分格尺寸、普通楼层净高、桁架杆件截面和节点细节。
- 桩群坐标未取得；947根1 m直径示意圆柱采用52 m长度，是范围内代表值，不是逐桩表。
- TMD质量、12根25m吊索和125层位置已由2014年现场采访核实；2017年上海中心供图核实方形质量箱、圆形上盖与四组耳板。质量箱尺寸、精确楼层标高、局部锚具/磁极排布与实装调谐参数仍未获得。模型中心583.5m是避免与580m解析核心筒屋顶相交的几何布置，不能当成实测标高。
- 材料E/密度、楼面附加质量、梁杆等效刚度、风力系数等求解输入为明确记录的教学假设，不能写成实测参数。

特别注意：

1. 6个或更多外壳扇区只是动画拆解分组，不代表实际建筑有6条特定施工缝。
2. 整区抬升展示帮助看懂层次，不代表实际把几十层整体吊装。旁白s040–044交代爬模、钢构件、楼面与分块幕墙的施工关系。
3. 可视化核心筒保留多室墙、空腔及随高度的平面变化，不采用早期连续30→18 m收窄的空方筒；电梯/楼梯位置仅为功能示意。结构计算将该墙网截面等效为梁，并非逐墙板壳求解。
4. 受力示意中外柱的轴力一增一减；已有很大竖向压载时，减小的一侧未必成为净拉力，不宜一概标成一拉一压。
5. TMD应与承挂点连续连接；上海中心的涡流方案可展示重物下磁阵与地面铜板，未核实的细部不假装竣工构造。

## 动画与镜头检查

使用同一座塔和统一比例。外壳拆分要保留幕墙与核心结构的对应位置；讲中庭时恢复内层幕墙，仅移开影响观察的近侧外幕墙，让观众真实读出夹层间距。

地下镜头应始终能理解桩—筏—主体的相连关系。力箭头必须接触受力构件；机理顺序为楼板面载→梁→柱/核心筒→筏→桩土。伸臂镜头在实际桁架连接处给出轴力变化。

受力动态已接入实际执行的**本地Zwind/os2zwind → OpenSees 3.8.0等效线弹性有限元计算**，包括重力、示例风、施工高度分段模型和调谐质量动力响应。它有真实求解输出，但不是上海中心原工程有限元或实测应力。另有独立OpenFOAM v1912 simpleFoam / kOmegaSST平均流场，用于宏观绕行、侧方加速、下游减速及相对平均压力符号的限定科普展示；结构风载没有来自该CFD结果。生产流场许可、严格残差未达标和网格非独立等边界见 `research/physics-v7/final-educational-cfd-acceptance.json`。

结构预设风载的风速剖面指数参考Zhao 2011的B类地形100年10分钟均值U10=31.7 m/s、U500=50 m/s；本片结构教学工况采用缩放后的U500=30 m/s及预设脉动函数。独立CFD则采用均匀30 m/s入口与滑移地面，不能把两种输入混成同一流固耦合工况。截面、质量、连接和固定基底等假设见求解器报告。CFD画面使用“理想化平均流场”短标识，不宣称工程精度、局部压力峰值或已解析的瞬态涡流；主楼位移显示×48。色彩分别显示有符号巨柱轴应力增量（固定−6至+6 MPa）和无符号核心弯曲截面应力（固定0至6 MPa），使用独立图例，不冒充幕墙压力。Z04/C03斜腹杆细节采用单独标注的固定±15 MPa色标及6 m/MN力箭头映射，不改写全楼角色量程。显示插值不增加物理证据。

TMD质量采用文献的1000公吨，弹簧按本等效模型一阶频率调谐，内部阻尼8%为教学假设。其输出可以用来说明相对运动与耗能，但不作为实装装置性能预测。施工阶段计算是逐高度重新求解，没有复现差异收缩、徐变或伸臂锁定的历史内力。

`public/physics/environment-response.json` 保留与主楼同工况的TMD实际位移/速度/加速度/作用力、核心风弯矩及截面应力，以及历史静力单桩基线。当前单桩近景改用 `public/physics/pile-dynamics.json` 与 `pile-dynamics-provenance.json`：52 m长、1 m直径，先静力加载，再展示40秒独立动力响应和卸载衰减，位移显示×300。土刚度、阻尼、8 MN头载及规定的动力载荷均是教学假设，另计自重；它没有把整楼固定基底替换为桩土耦合，也没有将界面反力当作连续土体应力。详见 `docs/environment-physics-interface.md` 与 `research/physics-v7/pile/`；历史19项环境检查不能替代当前动力桩验收。

透明应服务于讲解：先显示路径/承挂/承力节点，再逐步打开前侧遮挡；避免整套结构低透明造成层层干扰。字幕安全区、关键标签和模型的投影关系要逐镜检查。


## 当前模型与计算的映射

`public/physics/structural-graph.json` 是可视化和本地Zwind/OpenSees共享的稳定结构映射：1541节点、1984杆件，单位为米，Y轴向上；节点另存 `xyzBlender`，渲染杆件通过 `meshIds` 连接。GLB清单保留 `structuralMapping`、`cameraAnchorsThree` 和 `focusBoundsThree`，以支持同一模型内的运镜、透明和部件拆解。

部件级响应索引 `public/physics/component-response.json` 将 705 个结构可拆分件关联到这 1,984 个等效杆件，按部件输出 1 秒时域应力、端点位移和峰值时刻，并保留固定的角色量程（伸臂、环带、巨柱、角柱、核心）。同一核心等效杆可被多个墙片引用，这是几何代理的预期重复；质量、应力和风荷载仍只按唯一求解杆件计一次。其余 282 个幕墙、连接、楼板和设备件在索引中显式标成教学几何，没有被伪造为求解结果。`scripts/physics/qa_component_response.py` 检查输入哈希、求解杆件覆盖、时轴和 CFD 门禁。

本轮数值检查包含悬臂梁解析算例、静力反力平衡、有限值检查和动力积分收敛；完整结果在 `public/physics/run-summary.json`。这些证明求解链与本例数值检查完成，不能替代原工程模型验证。公开文献的模态周期只作独立对照，偏差与假设均保留在审查报告。


## TMD与土体模型升级核查（2026-10-08历史记录及当前适用范围）

已实际打开并核对上海中心供图、Zhu塔冠剖面、Wu监测论文以及解放日报2014年现场采访。来源页、原图、SHA256和逐项依据在`research/tmd-v3/sources.json`。机械模型采用深色方形钢质量箱、圆形平台、四组板式吊耳与每组3根吊索；没有套用台北101金球，也没有把上方“上海慧眼”艺术品当作整个质量块。模型保留导出的PBR金属、混凝土和柔和蓝玻璃基础材质，并增加可导出倒角。
