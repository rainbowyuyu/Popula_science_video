# 上海中心 EDB → OpenSees：采用 E2O 方法的接入方案

2026-10-09。参考用户指定的 https://github.com/OpenSeesPro/E2O-SEAOC2020 ，源码已归档于 `research/tools/E2O-SEAOC2020/source/`，MIT LICENSE 原样保留。GitHub ZIP注释标识提交 `daa3bce61305642fd809d0a94ba08c348128360b`。

## 已明确的路线调整

E2O 用 ETABS 的 COM/API 读取已打开模型，再创建 OpenSeesPy 节点、构件和分析，不解析 EDB 二进制。因而有可用 ETABS 时，可以直接走 API，**无需先手工导出 E2K**；E2K仍可作为可追溯文本备份和离线适配途径。

这不解除 ETABS 依赖。`general_utilities.py:49` 使用 `GetActiveObject('CSI.ETABS.API.ETABSObject')`，README要求先运行ETABS并保持打开。当前用户明确没有安装ETABS；本轮没有运行原仓库算例或声称上海中心已转换。

## 采用的流程

1. 在能读取旧版9.x EDB且提供所需数据库API的ETABS环境中，打开归档副本。保存旧版转换日志、软件版本、工作文件哈希和原始单位；保留用户原件。
2. 先提取原始数据库表和原模型基准结果，再做语义映射。每份导出记录表名、字段、单位、行数、API返回码；缺失数据应报错，不用空表继续。
3. 建立原始ETABS对象/分析单元 → OpenSees节点/单元 → 影片构件ID的对应表。保留一对多的自动网格关系，不能将对象数量当作分析单元数量。
4. 先构建具有相同质量、刚度、边界和重力状态的弹性基准，核对模型连接、自重和总质量、支座反力、模态周期/振型、有效质量及代表性静力位移。不能仅凭前三周期相近就宣布转换正确。
5. 校验通过后再扩展适当材料非线性、指定风荷载和动力工况。流场荷载按实际坐标与面积映射，保留合力/力矩平衡；Diffusion未运行时不生成反演结论。
6. 使用校验后的结果驱动真实构件位移、应力/轴力颜色、传力箭头和三维标注。未转换的构件不挂上其他模型计算值。

## 上海中心必须补齐的映射

| 数据/机制 | E2O原例做法 | 本项目所需 |
|---|---|---|
| 文件读取 | 连接正在运行的ETABS，读取数据库表 | 兼容9.2 EDB的读取环境和转换日志；确认表API可用 |
| 材料 | 钢框架E/G固定常数 | 逐材料导出钢、混凝土、组合构件及修正参数，明确单位 |
| 墙与楼板 | 未实现壳/AreaObj转换 | 核心筒内外墙、楼板网格、厚度、局部轴、刚度修正与连通 |
| 梁柱/伸臂/环带 | 只处理截面角0°和90°，示例命名假设 | 任意空间方向、局部轴、端部偏心/释放、组合截面及构件命名 |
| 楼板约束 | 按同一Z自动设置刚性楼板 | 读取实际约束/刚性或半刚性楼板，避免改变原结构体系 |
| 质量 | 读取Assembled Joint Masses | 核对质量来源与对象节点/分析节点映射，防漏算与重复 |
| 非线性 | 示例Excel定义梁端Bilin铰 | 按真实材料和构件定义，不沿用FEMA示例铰参数 |
| 荷载/重力 | 原setup未调用add_nodal_loads；论文简化省略重力 | 原重力、自重、面/线/节点荷载、P-Delta与指定风工况完整复现 |
| 校核与记录器 | 周期对照，部分节点/铰ID固定 | 原对象ID稳定映射，构件覆盖率、平衡、位移、内力与时程检查 |

原仓库的适用范围声明是附带模型。论文算例为5层周边钢抗弯框架，墙/钢筋混凝土等扩展列为未来工作。不能把该库改一个文件路径就视为上海中心通用转换器。
