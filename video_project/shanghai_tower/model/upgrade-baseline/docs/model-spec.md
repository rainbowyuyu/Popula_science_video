# 上海中心教学模型：图纸依据与重建边界

本模型服务于约5分钟的拆解科普。它依据公开建筑设计图、施工方技术论文和风工程顾问资料重建，展示空间层次、主体构件的联系与基础机理，不是施工级BIM、竣工测绘或安全评估模型。

## 模型参数中必须区分的近似

地下33 m深、121 m连续墙内径、6 m筏厚和632 m总高为本次已核实尺寸。

九区边界约 `[0, 38, 100, 170, 240, 312, 387, 468, 559, 583] m` 来自公开剖面的像素比例观察，仅用于让层次与原图对应；不同分区的精确楼号/标高没有从完整尺寸图核实。

巨柱数量、截面；核心筒宽度30→18 m、壁厚；桩数947、桩长52 m、排布；底部外径与顶部收分比例；所有幕墙单元尺寸、楼层净高、伸臂节点；TMD质量和空间尺寸，凡未列入上表均为当前建模参数或教学近似，不应在字幕写成已确认的实楼参数。

特别注意：

1. 6个或更多外壳扇区只是动画拆解分组，不代表实际建筑有6条特定施工缝。
2. 整区抬升展示帮助看懂层次，不代表实际把几十层整体吊装。旁白s040–044交代爬模、钢构件、楼面与分块幕墙的施工关系。
3. 核心筒保留空腔和连续墙，不做一根实心方柱；电梯/楼梯位置仅为功能示意。
4. 受力示意中外柱的轴力一增一减；已有很大竖向压载时，减小的一侧未必成为净拉力，不宜一概标成一拉一压。
5. TMD应与承挂点连续连接；上海中心的涡流方案可展示重物下磁阵与地面铜板，未核实的细部不假装竣工构造。

## 动画与镜头检查

使用同一座塔和统一比例。外壳拆分要保留幕墙与核心结构的对应位置；讲中庭时恢复内层幕墙，仅移开影响观察的近侧外幕墙，让观众真实读出夹层间距。

地下镜头应始终能理解桩—筏—主体的相连关系。力箭头必须接触受力构件；机理顺序为楼板面载→梁→柱/核心筒→筏→桩土。伸臂镜头在实际桁架连接处给出轴力变化。

风与受力动态为一般机理示意，无真实上海中心数值边界、材料本构、网格或试验数据输入。不得标注为实楼CFD、有限元或实测热力图；屏幕可用“机理示意”“变形夸张”。TMD的示意频率和位移为教学表现，不是实楼定量预测。

透明应服务于讲解：先显示路径/承挂/承力节点，再逐步打开前侧遮挡；避免整套结构低透明造成层层干扰。字幕安全区、关键标签和模型的投影关系要逐镜检查。
