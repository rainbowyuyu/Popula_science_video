# 上海中心 · 附送交互模型

这是成片模型的轻量浏览页面，方便自由检查构件；最终MP4仍是主要交付。

在项目根目录执行：

```powershell
node scripts/build_viewer.mjs
node viewer/serve.mjs
```

服务仅监听本机，默认由系统选择空闲端口。打开终端输出的 `http://127.0.0.1:端口/viewer/index.html`。关闭终端或按 Ctrl+C 停止。也可以 `node viewer/serve.mjs --port=自行选择的端口`。

- 拖动旋转，滚轮/双指缩放，点击部件查看中文名称。
- “完整建筑”恢复装配，“看骨架”降低围护透明度，“地下基础”和“楼顶阻尼器”移动观察视角。
- 拖动“分层拆解”滑块，看外壳、楼层与主体之间的关系。
- “缓慢环绕”可随时开启或关闭，不播放配音或音乐。

页面直接读取 `../public/models/shanghai-tower.glb` 和相应清单，使用影片同一份987部件教学资产。模型以米制Y-up导入后缩放到0.01，不重新生成另一套外观。Blender模型与源文件仍在原项目位置。

公开资料教学重建；部分尺度、桩群、节点和内部空间经过简化。交互拆分不是实际整体预制安装顺序，不包含工程级有限元或CFD结果。来源见项目 `research/sources.md`。
